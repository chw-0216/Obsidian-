- **产出**：`04_每日刷题/YYYY-MM-DD_高难题.md` —— **每天 20:00 自动生成**
- **每份包含**：题目区 → 答案与解析（折叠）→ 易错点 → 考点溯源表 → **你的记录位（留空）** → 昨日错题回顾

> **为什么是 20:00**：早 09:00 已给《每日简报》；晚上出题，正好**当天练、当天记**。
> **★ 题量口径**：本目录每天出的 **5 题是「高难题精练」**，**不等于当天全部题量** —— 完整口径见 [[05_备考闭环与节奏]] §三。

## 二、★ 难度分级（本目录自用口径）

| 级 | 标记 | 含义 | 目标用时 |
|---|---|---|---|
| 中 | 🟡 | 常规题，方法清晰 | ≤ 60 秒 |
| 难 | 🟠 | 需两步以上推理 / 计算量大 | 60–90 秒 |
| 极难 | 🔴 | 真题里的「卡分题」，正确率常年偏低 | 90 秒为限，**超时即弃** |

> **本目录默认只出 🟠 / 🔴** —— 这才是「高难度」的意思：**不是偏题怪题，是真题里真正拉分的那一类**。

---

## 三、★ 做题规则（三条铁律）

1. **限时** —— **任何一题超过 90 秒就放弃**。练的是「判断该不该做」，不是「能不能做出来」。
2. **先写后对** —— 做完再展开解析，**不许边看边做**，否则练不出真实水平。
3. **当天记录** —— 做完立刻在本页 §五 记一行（日期 / 主题 / 正确数 / 用时 / 最大问题）。

## 四、错题本规则（决定长期上限）

1. **不抄题**，只写三行：**错因 / 正确思路 / 同类题特征**
2. 按**模块 + 错因**分类（如「资料分析 · 单位看错」）
3. **每周日复盘一次**，只翻错题本，不翻新题
4. **同一个错因出现 3 次** → 单独开一页专项

## 六、⚠️ 红线

1. **不得编造题目** —— 每题必须能溯源到**公开真题**（年份 + 卷别 + 题号）。
2. **不得编造答案** —— 同一题不同来源答案冲突时，**标「存疑」并列出口径**，不得强行给唯一答案。
3. **解析要写思路** —— 计算题**必须列算式**，不能只给「选 X」。
4. **不押题、不预测考点**。
5. 刷题记录**只放本库**，不与微信隐私数据混用。

### ★ 来源可信度分级（2026-10-09 实测后加）

| 级 | 来源 | 采信规则 |
|---|---|---|
| **A 可信** | 国家公务员局（scs.gov.cn）· 北京市公务员局 / 北京人事考试网 · 正规出版社真题集 | 可直接用 |
| **B 需验证** | 主流题库的真题原文 | 需与另一独立来源交叉 |
| **C 不可单独采信** | docin / doc88 / book118 / renrendoc / 百度文库等**用户上传**的「考生回忆版」「近三年高频版」 | **不得单独作来源** |

> **⚠️ 2026-10-09 实测发现**：搜「国考真题」返回的前排结果**几乎全是 C 级**。抽检一份《近三年高频版》发现：
> - 解析只写「**经分步核算，整体完工总时长为 15.2 天**」，**不列任何算式** —— 无法验证
> - 另有题目解析的推理链条**与题干条件自相矛盾**
> → 这类文档**大量为 AI 拼凑**。**规则：一道题必须在 ≥2 个独立来源中「题干 + 选项 + 答案」三者一致，才可采用**；只有 1 个来源的，列入「待核题」区，**不计入题量**。
