# ✍️ 申论能力拆解与训练法

> 申论 ＝ **主观题 · 约 180 分钟 · 5 道题**（4 道小题 + 1 篇大作文）· **全部答案在材料里**。
> **一句话**：申论**不是写作考试，是「阅读理解 + 要点提炼 + 规范表达」考试**。
> ⚠️ 题型与分值**以当年最新大纲为准**。

## 一、五大题型 —— 结构、给分逻辑、你的起点

| 题型 | 分值占比 | 给分逻辑 | 你的起点（待首测） |
|---|---|---|---|
| **归纳概括** | ~15% | **踩点给分**（关键词命中） | 🟡 待测 · 最该先练 |
| **综合分析** | ~15% | 踩点 + **逻辑层次**（是什么/为什么/怎么办） | 🟡 待测 |
| **提出对策** | ~15% | 踩点 + **对策可行性**（主体 + 动作 + 目的） | 🟢 优势（经济学训练） |
| **贯彻执行**（公文） | ~20% | **格式 + 内容**双扣分 | 🔴 预判短板（文体不熟） |
| **文章写作** | ~35% | **立意（总论点）+ 结构 + 论证** | 🟡 待测（艺术写作习惯需切换） |

> **★ 战略结论**：**小题（前四道）决定及格线，大作文决定上限**。
> 小题**全部可以在材料里找到答案**，练的是「**找得准 + 写得规范**」；
> 大作文**只有立意和结构是硬功夫**，文采反而是次要的。

## 二、★ 万能四步法（所有小题通用）

```
① 审题   → 看清「作答对象 / 作答范围 / 作答要求 / 字数」
② 定位   → 回材料圈定「哪几段相关」（不是全篇都相关）
③ 概括   → 逐句提炼关键词（动宾结构，不写长句）
④ 归纳   → 合并同类项 → 分层排列 → 写成「要点式」答案
```

**★ 三条铁律**
1. **答案在材料里** —— 自己发挥的句子**不给分**。
2. **要点式书写** —— 「**一、……。二、……。**」不要写成散文。
3. **字数卡死** —— 超字 / 少字**都扣分**。

## 三、逐题型要点

### 1. 归纳概括（最该先练）

- **问什么答什么**：问「原因」就别答「表现」。
- **关键词优先**：材料里的**规范表述**（政策词、动宾短语）**直接抄**，比同义改写得分高。
- **分层**：按「**主体**（政府/企业/个人）」或「**维度**（制度/技术/资金/人才）」分。
- **训练动作**：每周 **3 道**，写完后**逐条对照参考答案**，标出「**我漏了哪几个词**」。

### 2. 综合分析

- 常见问法：「谈谈你对『XXX』的理解 / 评析」。
- **固定结构**：**是什么（释义）→ 为什么（原因/意义/问题）→ 怎么办（对策）**
- **易错**：只写「理解」不写「分析」，层次塌成一段。

### 3. 提出对策

- **对策三要素**：**主体 + 动作 + 目的**（「**政府部门应……，以……**」）。
- **来源**：① 材料里的**现成对策**（直接抄）② 从**问题反推** ③ 从**经验迁移**。
- **判分点**：**针对性**（对得上问题）+ **可行性**（不空喊）。
- 🟢 **你的优势区**：经济学训练让你天然会写「**激励 / 约束 / 成本 / 外部性**」这类可落地表述。

### 4. 贯彻执行（公文写作）🔴 需重点补

- **常见文种**：**倡议书 · 建议书 · 讲话稿 · 工作方案 · 汇报材料 · 宣传稿 · 短评**
- **双扣分**：**格式**（标题/称谓/正文/落款/日期）+ **内容**（要点齐不齐）
- **训练动作**：**每周 1 篇**，先把 **6 种常用文种**的**格式模板**背下来（这是纯记忆题，投入产出比最高）。

### 5. 文章写作

- **立意**：从**题干 + 材料主旨**中提炼**一个总论点**（不跑题 = 拿一半分）。
- **结构**：**总—分—总**，分论点 **3 个**，每个分论点**独立成段**，段首**亮观点**。
- **论证**：**「观点 + 例证 + 分析 + 回扣」**四步；例证优先用**材料内案例**，其次**时政素材**（→ 查 [[00_申论素材总库]]）。
- **你的可迁移素材**（⚠️ 见 §五红线）：
  - **社会美育实践**（澜沧支教 / 乡村美育工作站）→ 可用于「公共文化服务」「乡村振兴」「共同富裕」
  - **AIGC 与影像技术**（北京台实习）→ 可用于「科技赋能文化」「新质生产力」
  - **经济学视角**（区域经济 / 发展经济学）→ 可用于「区域协调发展」「有效市场与有为政府」

## 四、长期训练节奏（配 12 个月窗口）

| 阶段 | 时间 | 动作 |
|---|---|---|
| **预热期** | **2026-10（现在）** | ★ **先摸基线** —— 每天 1 道小题手写，不求快 |
| **打基础** | 2026-11 → 2027-03 | **只练小题**：每周 3 道归纳概括 + 1 篇公文 · **手写** |
| **补短板** | 2027-04 → 2027-06 | 综合分析 + 提出对策 · 每周 1 篇**完整大作文** |
| **强化** | 2027-07 → 2027-09 | **每周 1 套完整申论**（180 分钟限时）· 大作文限时 60 分钟 |
| **冲刺** | 2027-10 → 考前 | 真题复盘 + 时政素材成册 + **练字**（卷面分真实存在） |

> **★ 每天最低量**：**1 道小题**（20 分钟）。**必须手写** —— 打字练不出卷面和字数感。
> **★ 素材从哪来**：写作时**只查 [[00_申论素材总库]]**（按主题分类，每日由《每日简报》自动追加），不要回头翻按日期命名的日报。
> **★ 周六**：《每日高难题》那天出的是**申论高难题 1 道大题**，优先从**当天素材**取题 —— 正好用来练「当天素材 → 当天成文」。

## 五、⚠️ 红线（本节）

1. **申论素材只用「公开可讲」的经历** —— **井邻商业信息、央美内部人事、他人隐私一律不进对外材料**。
2. **不得**把个人私密经历（情感 / 债务 / 家庭）写成申论素材。
3. **不得**编造数据或政策表述 —— 素材必须**有出处**。
4. **不得**用「艺术类写作」的抒情笔法写申论 —— **申论要克制、规范、以材料为据**。
5. 备考信息**只放本库**。
