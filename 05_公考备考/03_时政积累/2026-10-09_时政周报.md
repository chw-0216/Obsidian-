## 一、★★★ 必备框架：「十五五」规划（2026–2030）

> **纲要 2026-03-13 发布**（《中华人民共和国国民经济和社会发展第十五个五年规划纲要》）· **2026 年 ＝「十五五」开局之年**。
> **这是未来五年所有申论题的总背景，必须先记熟。**

### 1.1 20 项主要指标 · 五个方面

| 方面 | 指标数 | 关键内容 |
|---|---|---|
| 经济发展 | 3 | GDP **增长保持在合理区间**、各年度视情提出；为 **2035 年人均 GDP 比 2020 年翻一番、达到中等发达国家水平**打好基础 |
| 创新驱动 | 3 | ★ **全社会研发经费投入年均增长 7% 以上** |
| 民生福祉 | 7 | 就业 · 收入 · 教育 · 医疗 · 健康 · **「一老一小」** |
| 绿色低碳 | 5 | ★ **单位 GDP 二氧化碳排放累计降低 17%** |
| 安全保障 | 2 | 粮食 · 能源生产能力 |

### 1.2 四大战略任务（背这四个词）

1. **推动高质量发展** —— **发展新质生产力**是内在要求
2. **做强国内大循环** —— 坚持**扩大内需**这个战略基点
3. **推进全体人民共同富裕** —— 中国式现代化的本质要求
4. **统筹发展和安全** —— 安全是发展的前提

### 1.3 ★ 必须记住的硬数字

| 指标 | 目标值 |
|---|---|
| 研发经费投入 | **年均增长 7% 以上** |
| **数字经济核心产业增加值占 GDP 比重** | **12.5%** |
| 单位 GDP 二氧化碳排放 | **累计降低 17%** |
| 劳动年龄人口平均受教育年限 | **提高到 11.7 年** |
| **人均预期寿命** | **提高到 80 岁** |
| 养老机构护理型床位占比 | **提高到 73%** |
| **粮食综合生产能力** | **1.45 万亿斤左右** |
| 能源综合生产能力 | **58 亿吨标准煤** |
| 重大工程 | **6 方面 109 项** |

> **★ 记忆法**：**7% → 12.5% → 17%**（创新 / 数字 / 绿色）· **11.7 年 → 80 岁 → 73%**（教育 / 寿命 / 养老）· **1.45 万亿斤 → 58 亿吨**（粮食 / 能源）
