# 摄影学习收获 · 2026-10-28

设备：佳能 EOS 5D Mark IV，24–105mm 镜头。以下根据本人今天的学习记录整理；操作参数是起点，需要结合现场调整。

## 翻拍照片或平面作品

- 站在作品正中间，镜头对准作品中心，相机高度随作品中心调整，尽量让相机平面与作品平面平行，减少透视变形。四周稍留边，检查上下、左右边缘是否平行。
- 静态拍摄先尝试 1/50 秒、F4 或 F5.6，再根据光线和清晰度调整。1/50 秒手持仍可能因抖动而模糊，可稳定相机或使用三脚架。
- ISO 先从较低值开始，光线不足再提高，尽量控制在 1600 左右或以下；6400 可能带来更多噪点和细节损失。模糊还可能来自抖动、对焦不准或快门过慢。
- 观察 −3 到 +3 的测光刻度，先以 0 附近为参考，再看照片实际亮暗；刻度在中间不保证所有画面曝光准确。

## 操作顺序

1. 摆正相机、调整高度和距离，完整拍入作品。
2. 选择 M 手动曝光模式：设置快门 1/50 秒、光圈 F5.6，ISO 从较低值开始。画面太暗可提高 ISO 或增加光线；使用三脚架时也可尝试放慢快门。太亮可降低 ISO 或加快快门。
3. 半按快门对焦，按到底拍摄；回放并放大，检查细节清晰度、边缘透视、反光和亮暗。

## 白平衡与色温

- 按 WB 按钮，或在 Q / 菜单中找到白平衡，选择 AWB 自动白平衡，先拍一张观察白色是否自然。
- 若明显偏色，可选 K 色温模式，从约 5000–5500K 试拍比较：照片偏黄可降低 K 值，偏蓝可提高 K 值，每次小幅调整。
- 混合光源可能造成局部偏色；尽量使用一致的光源并避免反光。相机屏幕颜色仅供参考，要求准确时可用电脑和白纸或灰卡辅助检查。

## 5D Mark IV 背屏实时取景

1. 机背取景器右侧找到 START/STOP，将外圈开关拨到照相机图标。
2. 按 START/STOP，背屏显示实时画面；半按快门对焦，再按到底拍照。
3. 可用放大按钮检查对焦细节；再按 START/STOP 退出实时显示。
4. 若无法显示，检查是否处于照片模式，并在菜单中确认实时显示拍摄已启用。以上按键步骤尚未现场验证。
