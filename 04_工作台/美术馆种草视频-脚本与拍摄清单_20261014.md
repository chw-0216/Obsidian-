## 一、★ 通用结构（两条片子共用 · 30–45 秒）

```
0–3 秒   钩子    一个具体的画面或一个反常识的问题（不要 logo、不要「大家好」）
3–10 秒  是什么  一句话说清这是什么展（给硬信息：展期/在哪层）
10–30 秒 看点    2–3 个具体看点（每 5–8 秒一个画面，不罗列全部）
30–40 秒 行动    怎么来（预约方式 / 展期 / 开放时间）
```

★ **三个铁律**
1. **前 3 秒必须有画面冲击**（你摄影强项，这里用得上）
2. **一条片子只讲一个「点」** —— 不要写成「展览全景介绍」
3. **竖屏拍摄时预留上下安全区**（字幕区），主体放中间

## 二、★ 片子 B：寻星展（先拍这个 · 在展中）

**展名**：寻星——系外行星主题科普艺术展
**位置**：央美美术馆 · 一层
**上线**：2026-09-22

### 2.1 分镜脚本（竖屏 · 约 40 秒）

| 秒 | 画面 | 字幕 / 口播 | 备注 |
|---|---|---|---|
| **0–3** | ★ **一个「星球」的特写**（展品细节 / 星球模型 / 光影），缓慢推近 | 「**你抬头看到的星星，其实长这样。**」 | 钩子 · 用你最擅长的**浅景深特写** |
| **3–8** | 拉远 → 展厅全景（人在看展的背影，逆光） | 「央美美术馆一层，**寻星——系外行星主题科普艺术展**」 | 交代是什么 · 一句 |
| **8–16** | 看点 ①：**主展品**（最有视觉冲击的那件）· 缓慢横移 | 「**把 1000 光年外的东西，搬进了一间展厅**」 | 看点一 |
| **16–24** | 看点 ②：**互动 / 可参与的部分**（如果有）· 手入画 | 「（这里放你现场看到的最具体的一个细节）」 | ★ **必须现场看了再写** |
| **24–32** | 看点 ③：**人 + 展品的关系**（观众在看/在拍/在讨论）· 中景 | 「（一句让人想来的一句话）」 | 这里可以放马钰泽的镜头 |
| **32–40** | 出口 / 门牌 / 预约二维码（如有）· 定格 | 「**9 月 22 日起 · 央美美术馆一层**」+ 预约方式 | 行动指令 |

★ **字幕风格**：**大字号 · 居中偏下 · 一行不超过 12 字**（竖屏可读）
★ **BGM**：**环境感 / 太空感**（低鼓点 · 少旋律）—— 剪映音乐库搜「宇宙 / 氛围 / 纪录片」
★ **不要**：加片头 logo · 加「大家好我是…」· 加转场特效堆叠

### 2.2 马钰泽怎么用（如果约到了）

| 用法 | 说明 |
|---|---|
| ✅ **可以** | 他**真实看展**的反应镜头（他懂天文 → 反应是真的） |
| ✅ **可以** | 短采访 1 句：「你看到这个展的第一反应是什么？」（**真实回答**，不写台词） |
| ❌ **不要** | 让他「演」成一个不认识天文的随机路人 |
| ❌ **不要** | 写台词让他背 |

★ **一句话口径**：**「我请了一位天文社的朋友来看这个展」** —— 这句话**真**，且比「假装观众」好看得多。

### 3.1 如果是「回顾型」（预备脚本 · 约 35 秒）

| 秒 | 画面 | 字幕 |
|---|---|---|

## 四、拍摄清单（出门前对着勾）

### 4.1 设备

| 项 | 说明 |
|---|---|
| 机身 | ★ 你的相机（RAW 强项）→ **拍照 + 拍视频双线** |
| 手机 | ★ **竖屏视频主力**（稳定器 / 手持） |
| 稳定 | 稳定器 或 手持稳定姿势（**不要走着拍**） |
| 光 | 展厅多为人造光 → ★ **关掉自动白平衡**，手动定 |
| 收音 | 若采访 → **领夹麦或手机贴近** |

### 4.2 每个展必拍（8 类）

- [ ] **空镜**：展厅全景（横 + 竖各一条）
- [ ] **细节**：展品特写 ≥ 6 张（不同景别）
- [ ] **人**：观众看展（背影 / 侧脸 / 手）≥ 4 条
- [ ] **动**：镜头缓慢推 / 移（**每条 ≥ 5 秒**，给剪辑留余量）
- [ ] **字**：展签 / 前言 / 展名墙
- [ ] **空间**：入口 / 走廊 / 出口（交代「在哪」）
- [ ] **竖屏专拍**：★ **不要拿横屏裁**，直接竖拍
- [ ] **素材备份**：当天导两份

## 五、剪映操作要点（30 分钟内能出片）

| 步 | 做法 |
|---|---|
| 1 | 新建 **9:16 竖屏** 项目 · 帧率 **30fps** |
| 2 | 按分镜**先摆顺序**，不调细节（**先粗剪再精修**） |
| 3 | 字幕：**「文本 → 智能字幕」** 或手打 · **字号拉大** · 位置**居中偏下** |
| 4 | BGM：音量 **-18dB 左右**（别盖过环境音） |
| 5 | 转场：**只用「叠化」或不用** —— ★ **不要花式转场** |
| 6 | 导出：**1080×1920 · 30fps · 码率「推荐」** |
| 7 | ★ **导出后自己完整看一遍**（声音 + 字幕错位是最常见的坑） |
