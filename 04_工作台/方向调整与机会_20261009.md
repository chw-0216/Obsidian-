## 一、方向调整（3 条 + 1 条待你拍板）

### 调整 1 · 6 个项目 → 2 主线 + 1 对位线

| | 内容 |
|---|---|
| **现状** | 井邻 / 数字人 / 植墨 / GestureSynth / 美术馆 / 分析流水线 —— **6 个并行，全部平铺，无优先级，0 结算** |
| **依据** | 库里已裁定：**「三线不关闭 = 三线都无法证明」**；6 个项目 = 0 条可结算现金流 |
| **调整后** | **主线 A · 组织接入**：美术馆媒体部实习 → 中期汇报作品 → 事业编 / 公考<br>**主线 B · 现金变现**：家教（最快）+ AIGC 接单 + 摄影<br>**对位线 · 政策**：植墨（唯一与北京文旅十五五对得上）<br>**冻结**：GestureSynth、分析流水线扩张 |
| **为什么不是砍到 1 个** | 你的风险结构（零收入 + 在读）需要**双轨对冲** —— 一条要身份（稳），一条要现金（快） |

### 调整 2 · AIGC 生成 → AIGC + 成片交付 ★ 最急

- **依据（技能真相表）**：AIGC 影像强（ComfyUI / 即梦 / Nano Banana）· 摄影强（Capture One），但 **视频剪辑 PR / AE 不熟练（剪映为主）**。
- **而美术馆媒体部实习的岗位名就是**「**拍摄及视频制作助理**」。
- **政策侧**：文旅数字化 / 融媒体 / AI 影视 要的都是「**能交出成片**」的人。
- **判断**：你强在「出素材」，卡在「交片」。**这条不补，实习、接单、政策风口三件事会同时卡住。**

### 调整 3 · 个体创作者 → 有组织的交付者

- **依据**：政策传导链断在「组织」（政策 → 承接方 → 岗位 → **✕** → 你）；外环 44% 是「维护」不是「接入」。
- **动作**：优先接**有组织壳**的活（剧组 / 实习 / 项目制），而不是纯个体接单。
- **为什么**：组织壳同时给你三样东西 —— **署名 · 履历 · 下一次机会**。

### 调整 4 · 考公方向必须你拍板（不由 AI 定）

⚠️ **2027-10 报名只剩 12 个月**；5 个方向都留 = 5 个都不够。按数据匹配度排序（**供你拍板，非结论**）：

| 序 | 方向 | 匹配依据 |
|---|---|---|
| 1 | **文化 / 文旅 / 宣传系统** | 央美硕士 + 社会美育实践 + 摄影影像能力 |
| 2 | **美术馆 / 画院 / 艺术机构事业编** | 专业对口 + 美术馆媒体部实习在办 |
| 3 | **宣传口 AIGC / 融媒体岗** | 北京台 AIGC 实习 + 影像技术栈 |
| 4 | 发改 / 财政 / 统计系统 | 区域经济学 + 金融学 + CPA/CFA |
| 5 | 高校行政 / 辅导员 | 党员 + 硕士 + 教学与组织经验 |

⚠️ **北京定向选调年龄可能已超**（硕士一般不超 27 周岁）→ **不要把一年押在它上面**；国考 / 京考年龄上限一般 35 周岁，不受此限。

## 三、长期（12–36 个月）值得投入的 4 件事

> **这 4 件不是并列清单，它们互相咬合**：公考给身份 · AIGC 给钱和能力 · 植墨给项目 · 方法论给叙事。

### 1. 公考（2028 年度国考 / 京考）—— 倒计时 12 个月

- **为什么**：唯一**确定**能「接入组织」的路径；年龄上限 35 不受限；**京内生源**有利。
- **现在做什么**：行测模块专项 + 申论手写训练（12 个月打基础期）。
- **注意**：**2027 年度不能报**（2028-06 才毕业），今年这批只作**真题模考**。

### 2. AIGC 影像全链路交付能力 —— 现在就要开始

- **构成**：生成（已有）→ **后期成片（补 PR / AE）** → 报价 / 交付。
- **为什么**：政策风口（AI 影视 / 文旅数字化 / 融媒体）全都要这个；也是**接单报价的依据**。

### 3. 植墨（丝网版画 + 文旅）—— 政策唯一对得上的个人项目

- **护城河**：母亲家学（央美版画系教授）+ 你自己的制版 / 落地经验。
- **政策对位**：北京文旅「十五五」+《文化遗产保护传承"十五五"规划》。
- ⚠️ **井邻商业信息不进对外材料**（陈晔 10-02「你不需要给井邻做广告」＝划界）。

### 4. 社会美育方法论 —— 你的差异化叙事

- **素材**：澜沧支教 + 井邻工作站 + **经济学视角**。
- **为什么**：这是你「央美硕士 + 经济学」双背景**唯一不可替代**的产出，也是申论「社会美育 / 公共文化服务」的专属素材。
