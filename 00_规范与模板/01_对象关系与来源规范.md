# 对象关系与来源规范

[[00_规范与模板/00_字段与状态规范|字段规范]] · [[00_规范与模板/02_写入责任与路径登记|维护分工]] · [[04_工作台/当前任务|当前任务入口]]

## 关系骨架

目标 → 项目 → 行动 → 交付物与反馈；人物参与项目或事件；事件关联来源；结论引用支持证据与反证；建议依赖结论；决策记录候选、选择理由与后续行动。

| 关系 | 表达什么 | 不代表什么 |
|---|---|---|
| `projects` / `people` / `resources` | 归属或涉及的已确认对象 | 提到某人不等于其负责；同名不等于同一人 |
| `supports` | 对某判断提供支持的证据 | 自动证明因果或永久成立 |
| `contradicts` | 与判断冲突的材料 | 已自动推翻整条结论 |
| `depends_on` | 行动或建议成立的前提 | 泛泛相关 |
| `superseded_by` | 指向明确替代版本 | 删除旧版本 |

链接列表须使用库内实际路径。ID用于稳定身份和数据库关联，链接用于导航；后续由工具维护ID→路径映射。本批不建立新数据库、不批量生成关系。

## 来源与可追溯性

每项关键事实或推断旁保留：来源文件或数据集、精确定位、时间窗口、读取覆盖、记录性质和核验状态。

| 来源 | 最少定位 |
|---|---|
| 原始聊天 | 数据集标识、会话标识、消息ID或时间范围；只在必要时显示最少片段 |
| 用户口述 | 日期、原话或已确认的转述；与系统解释分开 |
| 文档或报告 | 文件路径、章节/页码、版本；报告引用的原始材料另列 |
| 统计结果 | 数据集、窗口、单位、过滤与去重规则、计算版本 |
| 网页资料 | 原始URL、标题、发布日期/访问日期及适用条件；过时政策另核验 |

多篇报告转述同一来源不算独立证据。原文或媒体不可读时记录覆盖缺口，不用摘要冒充全文核验。机器生成时间不等于事实发生时间。

## 分析完整性

结论至少区分：问题与范围、观察事实、解释、支持证据、反证、替代解释、置信理由、未知项和改变结论的条件。未检索反证写“未检索”，未找到写“本次范围未找到”，不写“没有反证”。

置信程度使用高/中/低/未知并写理由，不制造精确概率。人物关系按时间和场景记，不能自动推断敏感属性、隐藏动机或固定人格。真实选择理由只能由本人提供。

## 修订与复用

新证据先定位受影响的判断，再检查关联建议和行动；标待复核，不无声覆盖旧裁定。保留修订原因、旧版本定位和生效时间。

同一资料可被多个项目引用，不复制成多个“真相源”。对外复用另查公开范围、人物授权与贡献证据；库内存在材料不代表获准发布。
