## 三 · Fritzing 是什么

**开源电子设计工具（EDA），Arduino 教学的标配配套软件。**
三个视图 —— **面包板（Breadboard）/ 原理图（Schematic）/ PCB 布线**。
用途是把面包板上的接线画成图，交作业、写文档、做 PCB 都靠它。

**0.9.3b 是官方最后一个完全免费的版本**（2016 年发布，官网后续版本转为付费下载）。

- 本机是 Windows 11 → **只需要 `.zip`**，`.dmg` 是给 Mac 的
- 解压即用（免安装），不需要装到系统里

### ⚠️ 为什么没用安装器（过程记录）

1. **winget 装不动** —— `winget install ArduinoSA.IDE.stable` 跑了 7 分钟只用了 10 秒 CPU，临时目录空，卡死。已终止。
2. **官方 .exe 安装器拒绝执行** —— 返回 exit code 2。安装包 manifest 是 `asInvoker`（不需要管理员），排除权限问题；沙箱环境无法运行它。
3. **改用官方便携版 ZIP** —— 下载 → 解压 → 直接可跑。**已验证二进制正常**（`Arduino IDE.exe --version` 返回 Electron v20.14.0）。

> **★ 一条重要经验**：从带 `NODE_OPTIONS` 的 shell 启动 Electron 类程序（Arduino IDE / VS Code / 各种 IDE）会**直接崩溃**，报
> `Cannot find module .../node-language-shim.cjs`。
> 原因：`NODE_OPTIONS=--require=<某 shim>` 被 Electron 继承，预加载失败 → 进程退出。
> **解法**：启动前 `set NODE_OPTIONS=`（`启动Arduino.cmd` 里已经这么做了）。
> 正常双击不会遇到这个问题 —— 只有从被污染的终端启动才会。

### ⚠️ 待办：串口驱动（插板子前必须先解决）

本机 `DriverStore` 里**只有 Windows 通用串口驱动 `usbser`，没有 CH340**。
而国产 Arduino 套件（**「交互盒子」大概率就是**）几乎都用 **CH340** 芯片做 USB 转串口。

**症状**：插上板子后，Arduino IDE 的「端口」菜单里**什么都不显示**，或者设备管理器里出现一个带黄色感叹号的未知设备。

**解法**：装 WCH 官方 CH340 驱动
- 官网：http://www.wch.cn/downloads/CH341SER_EXE.html
- 装完重新插拔板子 → 端口菜单会出现 `COM3` 之类
- 官方板（Uno R3 原装）用 2341:0043，Windows 自带驱动能认，不用额外装

**怎么确认是不是 CH340**：插上板子后看设备管理器 → 端口(COM和LPT)，或看板子上 USB 口旁边那颗小芯片丝印。
