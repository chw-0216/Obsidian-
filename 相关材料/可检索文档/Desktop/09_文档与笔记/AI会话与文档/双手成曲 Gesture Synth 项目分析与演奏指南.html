01 / REFERENCE

已经找到你给出的原项目

目标是 Eric Wei 的 Gesture Synth。作者的公开仓库直接链接到你提供的 gesture-synth-weld.vercel.app，可以从它的真实演奏逻辑继续做本地复现。

原仓库以 MediaPipe 追踪双手，用 Web Audio 合成声音：左手选择和弦，右手控制和弦形态、音量和音色。当前本地版是保留作者署名的中文改编，保留核心映射，加入入门引导、录音回放和更平滑的音画切换。

范围本次结果

与线上版本的差别线上页面另有 Strings、Horns 等选项，公开仓库未提供对应实现；本地三种音色为振荡器合成音。

本地版不是原站最新版的逐像素镜像。声音控制以公开源码为依据，页面做了中文和交互整理。

02 / FIRST SESSION

启动和开始演奏

这次已经启动本地服务，点击文档上方“打开本地演奏”即可进入。以后重启电脑，先在项目文件夹双击 START.cmd。不要直接双击项目里的 index.html。

C:\Users\wardc\Documents\New project gpt\AI-archive\apps\gesture-synth
  1. 先点击“先试试声音”，按界面按钮或键盘 1–7，熟悉和弦与色彩。按钮再次点击会停音；键盘松开即停，空格也可停音。
  2. 回到入口，点击“开启摄像头演奏”，允许这一本机页面使用摄像头。画面只在本机处理，不需要麦克风。
  3. 选择 C 调、温暖合成器。双手分开，手掌面向镜头，从左右手各伸一根手指开始。
  4. 初次练习可把“演奏方式”改为“单手入门”。此时左手选和弦，音量固定，和弦形态由顶部菜单选择。
  5. 结束时点击“结束演奏”释放摄像头。需要彻底停止网页服务，再双击项目中的 STOP.cmd。

录制自己的演奏

点击“录制演奏”开始，再点一次停止。随后可“回放”或“保存录音”。录制的是合成器输出；不录人声或摄像头视频。录音在当前页面里暂存，刷新前请保存；保存位置由浏览器的下载设置决定。

03 / GESTURE MAP

左手选和弦 右手控制声音

左手手指与级数

左手形态级数C 调根音
1 根手指IC
2 根手指IID
3 根手指IIIE
4 根手指IVF
5 根手指VG
食指与小指VIA

特殊的 VI、VII 形态优先于普通手指数。向内倾手腕选择大三和弦，向外倾选择小三和弦；例如 VI 配合外倾得到 Am。保持手势会持续发声。

右手形态与表情

右手动作声音变化
1 指原位和弦
2 指第一转位
3 指大七或小七和弦
4 指属七或减七和弦
额外伸出拇指整体降低一个八度
上下移动上移增大音量 下移减小
左右倾斜调节滤波和明亮度
握拳或移出画面声音渐弱停止

右手的 1–4 指计数不含拇指。若左右手反了，在“设置”中开启“交换左右手”。可选的左手上移升半音、下移降半音默认关闭。

表中的 C、D、E 是和弦根音标记。当前引擎一次产生一组和弦音；屏幕底部会显示实际音符，例如 C4、G4、C5、E5。

04 / PLAY A SONG

用连续和弦完成一首歌

先确定歌曲的主调，再按自己的和弦谱按拍切换手势，右手控制渐强、渐弱和音色。完整演奏需要包含和弦顺序、持续时长与休止。单靠识别手势种类，不能自动补齐整首歌曲。

整曲引导练习

应用顶部“整曲提示”提供原创和弦伴奏练习曲《小旅程》：16 小节、4/4 拍、80 BPM。屏幕逐小节提示和弦与左手姿势；匹配后开始四拍计数，换到下一和弦继续，全程约 48 秒。可用手势演奏，也可用按钮预演。

C→G→Am→Em→F→C→F G C G Am Em→F C G C

整曲按 C 调编排。I 与 V 是大调；VI 与 III 的手腕向外倾，得到 Am 和 Em。练习模式自动将音量拉到最大。原来的“试听一段”仍可播放四和弦循环，先听节奏与和声。

与 Yesterday 参考的关系

你提供的视频主题适合作为演奏方法和视觉风格参考。当前版本可以完整演奏原创和弦练习曲，也可以按自己的和弦谱演奏其他歌曲伴奏；没有把一段自动播放包装成实时手势演奏，也没有宣称已经复现视频中每一个音符与音色。

若要逐音演奏 Yesterday 主旋律，还需要单音模式：手指组合决定音高，捏合触发新音，松开控制音长，保留另一只手负责伴奏。再配合节拍器与曲目进度提示，才能同时覆盖主旋律和伴奏。本地版没有内置受版权保护的原曲谱面。

声音规则的关键细节

级数偏移沿用原版的 [0, 2, 4, 5, 7, 9, −1] 半音；VII 根音位于主音下一个半音，屏幕音名仍是对应调的第七级。原位使用开放排列，如 C4、G4、C5、E5。四种右手形态改变这组音的排列或七音，拇指再整体下移十二个半音。

本地以连续振荡器和平滑参数变化衔接和弦；模型先尝试 GPU，不可用时尝试 CPU。摄像头推理约每 30 毫秒最多运行一次，只处理新视频帧；实际速度由设备决定。

遇到问题时

  • 打不开页面：双击 START.cmd，确认打开的是 http://127.0.0.1:4176/；端口占用时不要随意结束其他程序。
  • 没有声音：先点“先试试声音”触发浏览器音频，确认未静音；双手模式需要两只手都有有效形态，右手也不能放得过低。
  • 摄像头无法使用：检查浏览器授权，关闭占用摄像头的软件，回到入口重试。
  • 识别不稳：补足正面光线，两手不要交叉或遮挡；先练单手模式，再加入右手表情。
  • 大小调或左右手反了：先检查“交换左右手”，观察界面状态，再试手腕两个倾斜方向。
