## 四、修复方案

### 🟢 立即（已生效，0 成本）
**不要再用资源管理器打开微信缓存目录**，尤其是 `cache\<月份>\Message`。需要看那些图片就直接在微信里看。

### 🟡 立即可做（若必须浏览该目录）——关闭缩略图
资源管理器 → **查看** → **选项** → **查看** 选项卡 → 勾选 **「始终显示图标，从不显示缩略图」** → 确定。
这样打开该目录就不会触发缩略图生成，也就不会踩到 `nvui.dll`。

### 🟠 根治候选（推荐）——更新 NVIDIA 驱动
驱动已 4 个月（2026-06-11）。`nvui.dll` 的异常属驱动侧缺陷，**更新驱动是最可能根治的一步**。

- 用 NVIDIA 官方驱动（不要用 Windows Update 的版本）
- 若更新后仍崩：用 **DDU** 干净卸载后重装

### 🔴 兜底——关闭 NVIDIA 的 shell 集成
停用 `NVDisplay.Container` 服务，或移除 NVIDIA 桌面右键菜单集成，让 explorer 不再加载 `nvui.dll`。
代价：失去 NVIDIA 桌面右键菜单项。

> ⚠️ **不推荐**走「退出 WPS / 华为云空间」这条路：它们只是调用链上的参与者，**关掉 App 并不会从 explorer 卸载已注入的 in-proc DLL**，而且实测**华为云空间 App 根本没在运行**，此路无效。

| 怀疑对象 | 结论 | 依据 |
|---|---|---|

## 六、若再次复现怎么办

1. 先看 `%LOCALAPPDATA%\CrashDumps\` 有没有新的 `explorer.exe.<PID>.dmp`；
2. 用 `tasklist /v /fi "imagename eq explorer.exe"` 看是**哪个窗口**在崩（标题会告诉你是哪个文件夹）；
3. 若确认又是 `nvui.dll` → 直接走方案 C（更新驱动）；
4. 若换成了别的模块 → 把新转储给我，重新解析异常参数即可定位。
