## 第 2 步 · 看清楚浏览器开的是哪个账号（关键）

看弹出页面**右上角的头像/邮箱**：

### 情况 A：显示的是账号 B ✅
直接点页面上的 **授权 / 同意** 按钮 → 跳到第 3 步。

### 情况 B：显示的是 `aaron.haowencai@gmail.com`（账号 A）❌
**先不要点任何按钮**，按下面做：

1. 鼠标点到浏览器**地址栏**，按 `Ctrl` + `A` 全选，再按 `Ctrl` + `C` 复制这串网址
2. 在当前浏览器窗口按 **`Ctrl` + `Shift` + `N`**（打开**无痕窗口**）
   - 无痕窗口不会带任何已有登录状态，是最省事的隔离方式
3. 在无痕窗口的地址栏 **粘贴**（`Ctrl` + `V`）→ 回车
4. 现在页面会让你登录 → 输入**账号 B** 的邮箱和密码
5. 登录后再点 **授权 / 同意**

### 情况 C：页面显示未登录 / 让你选账号
直接选**账号 B** 登录后授权即可。

> 💡 **为什么不能用原来的窗口**：Codex 靠浏览器里现成的 ChatGPT 登录状态来判定"你是谁"。如果浏览器里是账号 A，就算你在页面上输入账号 B 的邮箱，也可能绕一圈还是授权成账号 A。

## 卡住了怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击后窗口一闪就没了 | 脚本报错 | 窗口里其实有 `pause` 会停住；若真的一闪而过，说明 Node 运行时被移动了，看第 4 章资产清单核对路径 |
| 窗口显示 `Required path is missing: ...` | 某个必需目录被移动/删除 | 按报错里的路径核对，缺什么补什么 |
| 浏览器没自动弹出 | 默认浏览器被拦截 / 没设默认 | 回到命令行窗口，看有没有打印网址；有就手动复制到浏览器打开 |
| 浏览器弹出来了，但显示的是账号 A | 浏览器复用了账号 A 的登录态 | 走第 2 步的「情况 B」：复制网址到无痕窗口 |
| 授权成功但窗口显示 `Not logged in` | 回调没走完，或窗口被提前关了 | 重新双击 `Login-B.cmd`，全程别关窗口 |
| 想换成别的账号登录 | 已有凭据 | 删 `C:\Users\wardc\.codex-cli-b\auth.json`，再走第 1 步 |
| 提示 `--device-auth` 相关错误 | 你的账号没开设备码登录 | 用默认的浏览器授权即可，别用菜单选项 2 |

## 三条红线（别踩）

1. **不要用 `codex logout` 来"换账号"** —— 那会清除服务端保存的凭据。换账号只删本地 `auth.json`。
2. **不要把 `C:\Users\wardc\.codex-cli-b\` 这个文件夹拷贝给别人** —— 里面有你的登录凭据。
3. **两个窗口不要同时改同一份 PPT** —— 可以读同一批素材，但输出请用不同目录或不同文件名。
