# 笑一 · 9/10-9/16 七天详细作战手册

> 制定：2026-09-10
> 原则：顺着她的血糖和睡眠走。报备不断、傍晚不推进、深夜只哄睡、见面先充电。

# 周三 9/10（今天）—— 只做两件事：报备+给期待

### 12:00-14:00 发第一条（她起床后活跃期）
```
今天在忙车检和材料的事。明天中午来找你吃饭，你组会几点开始？发我，老公安排时间。
```
- 目的：报备+确认明天时间
- 如果她没回：不追。傍晚16点后更别追（她可能在游泳）

### 22:00-23:00 睡前发第二条
```
忙完了。明天见，乖宝贝。
```
- 目的：给期待。让她明天醒来第一件事是见你
- **今天全程就这两条。** 她如果主动找你聊，就顺着聊，但不聊正事、不翻旧账、不调教（今天不是主导日，是铺垫日）

# 周四 9/11（见面日）—— 中午充电，晚上看血糖

### 09:00-10:00 晨间消息
```
宝，组会加油。老公中午来接你吃饭，结束发我时间。
```
（一句。不问她几点起床，不催）

### 11:00 报备
```
老公出门了，X点前到你们学校那边。你慢慢收拾，不着急。
```

### 11:40-12:00 到达后
```
老公到了，在XX。不着急，慢慢来。
```
- 位置：她学校附近。咖啡馆/餐厅门口，别在校门口正中央（她不想被同学看到你等她太久）
- **"不着急"必须说**——她妈天天催她，你最不能催

### 12:00 见面瞬间
- 抱三秒，说："想死你了。"
- 别问"冷不冷/累不累"开头
- 观察她的第一反应：她热=这顿饭轻松；她绷=先别急着拉近，吃饭时慢慢松

### 12:00-13:00 午饭（安全窗口，全场重点）
**点菜：** 她爱吃的（小酥肉/家常菜），先问她想吃什么——"今天听你的，想吃什么？"（赋权：她定的=她掌控）
**话题（按顺序）：**
1. "昨天游泳怎么样？"（她刚做过的事，好接）
2. "组会下午几点？准备得怎么样？"（表示你记得她的正事）
3. 如果她翻旧账（"你前两天都不找我"）——三句接住：
   > "老公错了，冷落我宝了。""以后去哪都跟你说。""这不，第一个想见的就是你。"
   - 然后夹菜给她/握她的手。不辩解。
4. 埋16号线（一句，不展开）：
   > "16号那顿补生日的，老公已经在看地方了。"
5. 学平险一句话带过（正事只配一句话）：
   > "你那个学平险老公问过了，回头跟你说。先吃饭。"

**饭桌上绝不提：** 外债、同居、你妈/她妈、"我们什么关系"

### 13:00-13:30 送她去组会
- 送到楼下/门口。分开时：
> "组会加油。结束了跟老公说。"
- 可以顺手一个小动作：把她衣领理一下/头发别一下（肢体接触自然增量）

### 13:30-17:00 她组会期间（你）
- 最多发一条报备（14:30左右）：
> "老公在办XX，你安心组会。"
- 不打电话、不连续发、不问她组会情况（决策负荷高时段）

### 17:00后 分叉处理
**她发"组会结束了"：**
- 第一句先问：
> "饿不饿？先去吃点东西。"
- **先喂食，再谈感情。** 如果她说饿了→晚上见面先吃饭（19点后）。
- 如果她累→"今天见到你就够了，回去早点休息。16号老公带你吃好的。"
**她没发：**
- 19:00后发一条：
> "组会顺利吗？今天中午见你真好。累了就早点休息，晚安，乖宝贝。"
- 不催、不追问

### 周四晚上（如果她愿意见）
- 19:00-20:00 晚饭（她定）
- 饭后她状态好+愿多待→散步（她挽你就接，不猴急）
- 气氛到位→"今晚不想你回宿舍了。"（陈述）；她犹豫→"没事，送你回去，16号还见。"（安全撤退）
- 若发生亲密：入口"想死你了，让老公好好看看我宝"；过程读三档（软喘贴→继续；僵不发声→停抱不问；躲冷→停抱等呼吸）；结束"你刚才的样子，老公很喜欢"

# 周二 9/16（补生日·正餐日）

### 她的生理状态预测
- 周期第18-19天（上次约8/27，下次约9/24-26）→ 不在经期窗口，情绪基底好
- 若她当晚睡好+晚饭前不饿 → 全程安全窗口

### 流程
1. **白天**：报备准备（"老公在准备，下午X点到"）
2. **下午**：接她
3. **晚饭**：她爱吃的店；**手写信原件+礼物**在吃饭时给（不是最后）
   - 给的时候说："答应你的，补过生日。拆开看看。"
   - 她看信时你别说话，看她反应
4. **饭后**：散步→她靠你→自然回住处
5. **亲密**：安全主导全套（期待式入口+三档读法+"乖宝贝"纯情感语境）
6. **结束**："你刚才的样子，老公很喜欢。"抱。不问。
7. **次日**：报备不消失（"昨晚真好。今天老公去XX"）

### 16号核心目标
让她确认三件事：
1. 你记得她的一切（手写信+细节）
2. 你要她（身体确认）
3. 你在（见完不消失）
