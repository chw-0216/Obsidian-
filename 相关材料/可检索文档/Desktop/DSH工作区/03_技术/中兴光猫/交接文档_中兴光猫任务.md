### 1. ZTE 光猫登录协议（已完整破解并验证）

登录页 `http://192.168.1.1/`，登录流程：

```
1) GET http://192.168.1.1/
   提取 JS 变量：Frm_Loginchecktoken").value = "<token>"   ← 每次刷新 token 都变

2) 生成 8 位随机数 pwd_random（范围 10000000–99999999）

3) 计算 UserPW = SHA256(密码原文 + pwd_random)，小写 hex
   （密码原文直接拼接随机数字符串，sha256.min.js 输出小写）

4) POST http://192.168.1.1/  （表单编码，不是 JSON）
   Username=<用户名>
   Password=<上面算出的 hex>
   UserRandomNum=<pwd_random>
   Frm_Logintoken=0
   Frm_Loginchecktoken=<第1步的 token>
   action=login
   Right=

5) 成功标志：响应 32608 字节框架页 + 会话 Cookie：
   SID=<64位hex>；_Tokens=<20位左右字母数字>；_TESTCOOKIEHTTP=1
   失败标志：响应仍是登录页(~8KB)，3次失败后响应尾部出现
   "您的错误登录次数已经达到三次，系统将延时进行校验" → 锁定
   （锁定只能等几分钟或重启光猫解除）
```

### 3. 已解密的提交加密机制（重要，改配置/改密码时用）

`/js/code.js`（已保存）定义：
- `EncodeKey(key, iv)`：用硬编码 RSA 公钥（见文件）加密字符串 `key+"+"+iv`（16位随机数 key 和 iv），结果为表单隐藏字段 `IF_ENCODE` 的值
- `EncodePara(data, key, iv)`：AES-CBC 加密提交数据，**AES key = SHA256(key)，IV = SHA256(iv)，ZeroPadding**，输出 Base64
- 即：**带修改效果的表单提交 = 明文表单 + IF_ENCODE 字段（RSA(key+iv)）+ 关键字段用 AES 加密**
- 页面里 `setEncodePara()` 会自动往 form 加 IF_ENCODE

### 4. 本机环境注意事项（影响所有 HTTP 操作）

## 四、任务执行建议（给下一个 harness）

### 目标1+2：永久禁止华为（非荣耀）/三星手机接入
- 首选：管理页 → 无线 → MAC 过滤/接入控制（黑名单模式），把**当前在线的**华为/三星设备 MAC 全部加入黑名单

  - 华为（Huawei）常见前缀：00:E0:FC、48:46:FB、98:FA:E3、20:08:ED、AC:85:3D、BC:76:70、D4:6E:5C、34:29:12、70:72:3C、FC:48:EF、A4:5E:60、04:00:0E（可查 IEEE OUI 库获取全量）
