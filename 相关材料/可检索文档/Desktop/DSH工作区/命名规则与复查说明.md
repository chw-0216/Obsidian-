# DSH 命名规则与复查

当前格式：类别｜对象·用途；UTF-8 最长 80 字节。当前 17 个前缀：母亲、笑一、陈晔、姜涛、中传、美术馆、校友会、存储、人物、导师、学业、项目、工具、配置、历史、测试、重复。

标题保留人名、项目名、工具名；不放账号、密码、令牌或内网地址。用途改变后手工更新。

运行 node dsh-check-names.mjs 会读取当前工作区成员和缓存，只检查标题是否缺失、泛化、格式异常、过长或命中已知敏感模式。结果写入同目录 naming-check.json。异常只输出会话 ID 和原因，避免再次散播敏感标题。

先读异常会话再决定新标题；检查脚本不自动猜测用途、不修改会话。需要跨设备时用 DSH_STATE 指定状态目录。未设置月度自动任务。

本轮结果：129 条全部通过。检查范围仅标题，不能证明历史日志中没有凭据。
