# 使用手册：笑一关系档案 + 一键工具

> 本手册告诉你：9 份文件分别是什么、什么时候用哪个、怎么组合最高效、以及一键更新工具怎么用。

---

## 一、桌面上的两个工具

| 工具 | 作用 |
|---|---|
| **更新聊天记录.bat / .ps1** | 双击即自动：开启 API → 拉取笑一全部聊天 → 覆盖 `Desktop\2` 的 json/md/txt → 关闭 API。约 1 分钟 |
| **WeFlow一键修复.bat / .ps1** | WeFlow 报 -105 错误时一键修复（重命名锚点目录） |

## 二、`Desktop\2` 里的 9 份文件

### 数据层（会变，靠工具更新）
| 文件 | 内容 |
|---|---|
| 笑一-聊天记录.json | 原始数据（字段全），供程序分析 |
| 笑一-聊天记录.md / .txt | 人读版（时间正序） |

### 结论层（静态快照，人工更新）
| 文件 | 一句话定位 |
|---|---|
| **终极全景档案.md** | ⭐ 总入口，所有结论的整合版 |
| 笑一-WPRISM侧写报告.md | 她的深层心理侧写（穿透判断/发动机/三模型/内心独白） |
| 她的完整画像.md | 她的心理行为画像（家庭/特质/称呼机制） |
| 深度分析-潜在问题.md | 10 项风险清单（你的焦虑、资源不对称等） |
| 总档案-全部信息汇总.md | 十部分速览（含 WeFlow 技术、周期日历、裁决） |
| 深度研究-材料包.md | 给 Gemini 等外部 AI 的匿名材料（含研究问题） |

## 三、什么时候用哪个（按场景查表）

| 你的问题 | 看哪个文件 |
|---|---|
| "她到底爱不爱我/图不图我" | 终极全景档案 → 第四部分（W-PRISM 三模型 0.80/0.12/<0.03） |
| "她为什么会这样" | 笑一-WPRISM侧写报告 → 第 1/3/4 节 |
| "她最近是不是淡了" | 先跑 更新聊天记录 → 让 AI 重跑指标 |
| "我哪里做得不对" | 深度分析-潜在问题 → P3/P7/P8 |
| "我要提交给 Gemini" | 深度研究-材料包（已匿名） |
| "想快速查某个结论/周期/日期" | 总档案 或 终极全景档案 |

## 四、组合使用的最佳流程（三步）

1. **更新数据**：双击 `更新聊天记录.bat`（数据到最新）。
2. **读结论**：打开 `终极全景档案.md` 找结论。
3. **要新分析**：把最新 json + 你的问题一起给 AI，让 AI 基于新数据重跑，并把新结论写回档案。

## 五、工具使用注意

- `更新聊天记录.bat` 运行时会**临时关闭并重启 WeFlow**（约 1 分钟），运行前先确认没有正在进行的微信导出任务。
- 若 WeFlow 报 -105（红字"离线访问回拨状态损坏"），先双击 `WeFlow一键修复.bat`，修好后再跑更新。
- 两个工具互不冲突，但别同时双击。
