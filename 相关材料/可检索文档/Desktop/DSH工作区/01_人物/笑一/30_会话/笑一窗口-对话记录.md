### 核心发现：推理 token 问题

**流式测试暴露了关键数据**：

```

reasoning_tokens: 34
actual_output: 3
```

V4 Pro 是推理模型，"say hello in one word" 这种简单请求它都要先思考 34 个 token，最终只输出 3 个 token！**推理 token 和输出 token 都从 `max_tokens` 里扣**，所以：

- 如果 Harness 请求 `max_tokens=4096`，推理吃掉 3000+ token，实际输出只剩不到 1000
- 之前对话里 "输出被截断" 就是这个原因——推理 token 把输出预算吃光了
