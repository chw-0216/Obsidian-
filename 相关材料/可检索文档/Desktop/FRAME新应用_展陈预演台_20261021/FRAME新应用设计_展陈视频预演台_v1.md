## 4. 推荐方案：FRAME · 展陈视频预演台

### 4.1 目标用户与场景

- 用户：在美术馆/画廊拍宣传视频的实习生、独立导演、策展团队；
- 场景：进入一个真实展厅，需要快速确定「站哪、用什么焦段、竖屏还是横屏、每个镜头拍几秒、拍完怎么对照」；
- 交付：一套可带到现场执行的**镜头卡**，以及拍完后的**实拍对照与复盘档案**。

### 4.2 六个新模块

| 模块 | 做什么 | 复用/新增 |
|---|---|---|
| **① Venue Builder 场地** | 输入展厅长宽高；用墙体/立柱/球体等代理搭出空间；支持入口、长廊、主展墙预设 | 复用 Spatial Studio 的 objects；新增 `venue` 数据和预设 |
| **② Lens Kit 镜头校准** | 按 5D Mark IV（36×24 传感器）+ 24–105mm 计算 FOV；显示等效焦距、机位高度、水平/垂直画幅、9:16 与 16:9 安全框 | 新增焦距↔FOV 计算；复用 camera3d |
| **③ Shot Board 镜头板** | 每个镜头：AI 分镜图 / 裁切原片 / 3D 预演缩略图 / 机位参数 / 焦段 / 时长 / 运动方式 / 风险 / 状态 | 新增 `shots[].plan` + 参考图字段 |
| **④ Shot Pack 导出包** | 一键 ZIP：每镜头 PNG+JSON、`shotlist.csv`、联系表；可直接给 OpenShot/剪映做分镜参考 | 复用 Export Frame；新增 CSV/联系表 |
| **⑤ Review 评审** | Audience Mode 只读展示镜头板；通过/待改/驳回状态；评审批次与修订号 | 复用 Audience Mode + 版本号 |
| **⑥ Asset & Archive 档案** | 登记 12 张分镜板、58 张裁切原片、实拍帧；路径核验；预演 vs 实拍并排 | 复用 Assets + Attempt 历史 |

### 4.3 数据模型增量（示意）

焦距与 FOV 的关系：

```
vertical FOV = 2 × atan(24 / (2 × focalMm))   // 全画幅 36×24，竖拍时 24mm 为竖向尺寸
horizontal FOV = 2 × atan(36 / (2 × focalMm))
```

### 4.4 工作流：先用寻星展做试点

1. **建场地**：输入长廊长度/宽度/层高、入口位置、时间线墙、立柱、星球悬挂范围；全部标 `provisional`。
2. **挂参考**：导入 12 张 AI 分镜板与 58 张裁切原片，登记到 Assets，选择 Board 08 作为 20 秒主分镜。
3. **建 6 个镜头**：按 Board 08 的 01–06 建镜头卡，写入焦段、时长、机位高度、运动方式。
4. **校准镜头**：按 5D IV + 24–105 计算 FOV；竖屏 9:16 为主，同时可切 16:9 看横版。
5. **导出 Shot Pack**：PNG+JSON+CSV+联系表，带到现场按卡拍。
6. **拍完对照**：把实拍帧导入 Assets，和预演图、AI 分镜并排；状态改为 approved / reshoot。
7. **评审**：Audience Mode 给陈老师/馆方看，只读，可标注；修订号留档。
8. **交付剪辑**：CSV 镜头表交给 OpenShot/剪映，按镜头号与时长铺时间线。

### 4.5 技术实现路径

- 新建 `js/exhibition.js`：Venue Builder、Lens Kit、Shot Board 的计算与 UI；
- 扩展 `data/project.js` 的 scene：加 `venue`、`shots[].plan`；
- 复用 `SpatialStudio.cameraFrom` / `capture` / `Export Frame`；
- 新增导出器：`shotlist.csv`、`contact-sheet.jpg`、`shot-pack.zip`；
- 新增测试：焦距↔FOV、画幅换算、CSV 字段、venue 数据校验、参考图路径核验；
- 不引入外部依赖，保持纯本地、无 CDN。

### 4.6 MVP 范围（建议 1–2 周）

**做**：

- 场地尺寸 + 基础墙体/立柱/球体；
- 焦距↔FOV 校准（24–105mm，9:16 / 16:9）；
- 镜头板字段 + 参考图缩略图；
- Export Frame + `shotlist.csv` + 联系表；
- 用寻星展 Board 08 做 6 镜头试点。

**不做**（明确写进 README，防止 scope creep）：

- 骨骼动画、人物动作、关键帧、多机位时间轴；
- 720° 全景、外部 3D 模型导入；
- 视频导出（这是爱奇艺强项，不在 MVP 争）。

### 4.7 V1 / V2

- **V1**：全景/照片背景、实拍 vs 预演并排、Review 批注、版本快照、9:16/16:9 双安全框。
- **V2**：简单机位运动关键帧 → 由本地 ffmpeg 生成 animatic MP4；资产库；多人评审；与 OpenShot/剪映工程互导。

### 4.8 验收指标

| 指标 | 目标 |
|---|---|
| 单镜头预演卡生成时间 | < 3 分钟 |
| 现场按卡拍摄的镜头一次通过率 | ≥ 70% |
| 因机位/焦段错误导致的补拍 | 下降 50% |
| 陈老师/馆方评审一轮反馈时间 | 从 1 天降到 2 小时 |
| 每次修改可追溯 | 100% 有修订号与备份 |
