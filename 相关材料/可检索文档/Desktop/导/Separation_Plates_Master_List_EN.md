# 4. OUTPUT STANDARDS — APPLY TO ALL PLATES

| Item | Requirement |
|------|-------------|
| Film | 1-bit black and white, **1200 ppi**, actual size 100% (turn OFF "fit to page" and any second screening) |
| Before printing | measure the 100 mm test line to confirm scale |
| Registration | corner crosses + crop marks, identical on every plate |
| Halftone (scene plates only) | AM screen, approx. **45 LPI**, different screen angle per ink (e.g. 45° / 75°) |
| Solid-form plates (animal frames) | **no halftone** — pure 1-bit |
| Outside the frame | frame text, registration crosses and test line are **not part of the artwork**; tape them off after exposure and before inking |
| White lines and eye holes | these are **non-inking areas** (cut-outs); if you switch to a hand-cut stencil, add bridges |
