## 八、⚠️ 技术风险提醒（重要）

你说"用显影药水在温度下负片变成正片"——**这里有个技术要点必须确认**：

**普通的"显影液+定影液"只能得到负片，做不出正片。** 负转正（反转冲洗）通常需要**完整反转流程**：

```
首显 → 停显 → 漂白 → 清洗 → 二次曝光 → 二次显影 → 定影 → 水洗 → 干燥
```

也就是说，除了显影液、定影液，还需要**漂白液**，并且需要**二次曝光**（把胶卷拿出来见光）。

**建议**：
1. 确认你买的是**反转冲洗套药**（黑白反转套装），不是普通显影定影
2. 或者确认商家/扫描店能代做反转冲洗
3. 你提到的"冰醋酸"是停显用的，方向对，但流程不止这两步

**这个点如果搞错，胶卷一冲就是负片，白跑一趟。** 胶卷到货前先把套药确认清楚。
