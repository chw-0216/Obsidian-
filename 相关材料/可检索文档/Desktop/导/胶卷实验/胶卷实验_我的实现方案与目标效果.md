# 一、一句话愿景

**用一条"谁都能上手"的手工流程，把一张普通照片变成有银盐颗粒、印刷网点、纸纤维和在地气味的实物作品。**

关键词：**特殊质感** + **低门槛可复制** + **在地性**

---

# 二、我想实现的效果（成品长什么样）

## 2.1 成品描述

一张 A4/A5 大小的实物：
- 画面是**怀柔/洞台村的在地场景**（村民、院墙、工作站、山上）
- 图像有**可见的银盐颗粒**，不是数码的平滑感
- 经过**像素化处理**，形成"数字—手工"混合的网点质感
- 印在**硫酸纸或手工纸**上，能看到纸纤维
- 边缘是**手动撕的**，不规则、有毛边
- 色调**可调**：暖棕（怀旧/植物染料感）或冷蓝（氰版/蓝晒感）
- 隐约有**植物染料煮出来的气味**

## 2.2 我要的"特殊质感"具体是什么

这个词我一直在说，拆开是三层：

| 层次 | 具体来源 | 视觉/触觉表现 |
|------|----------|---------------|
| **影像层** | 胶卷银盐颗粒 + 反相后的高反差 | 颗粒感、不是数码的"塑料平滑" |
| **处理层** | AI像素化 | 网点/马赛克感的"印刷味" |
| **材料层** | 硫酸纸/手工纸 + 撕边 | 纸纤维、透光、毛边 |
| **嗅觉层** | 植物染料（洋葱皮/栗子壳/柠檬） | 淡淡的气味，提升"在地感" |

## 2.3 和普通照片的区别（差异化在哪）

| | 普通数码照片 | 我这套流程 |
|---|---|---|
| 质感 | 平滑、锐利 | 颗粒 + 网点 |
| 载体 | 屏幕 / 相纸 | 硫酸纸 / 手工纸 |
| 边界 | 齐整裁切 | 手工撕边（有触感） |
| 气味 | 无 | 植物染料气味 |
| 门槛 | 要懂摄影 | **流程化，不会照相的人也能做** |
| 唯一性 | 可无限复制 | 手工变量（撕边、染色）→ 每张略不同 |

# 三、我想怎么实现（技术路径）

## 3.1 主流程

```
① 拍摄
   索尼 f501 胶卷相机，拍在地场景（怀柔/洞台村）
        ↓
② 冲洗（标准黑白负片）
   显影（D-76，20℃，9—11分钟）
   → 停显（冰醋酸）→ 定影 → 水洗 → 晾干
   = 得到负片
        ↓
③ 数字化
   爱普生透扫 或 送扫描店 → TIFF（2400dpi，关自动色阶）
        ↓
④ 负转正
   PS 反相（Ctrl+I）→ 色阶黑吸管点胶片基底 → 调对比
   = 得到数字正片
        ↓
⑤ AI处理（关键差异化步骤）
   像素化 + 色温/色调调整
        ↓
⑥ 输出
   打印在硫酸纸 / 手工纸
        ↓
⑦ 手工收尾
   手动撕边 → 成品
        ↓
⑧ 叠加在地性
   植物染料气味／染色
```

## 3.2 每个环节我的选择理由

| 环节 | 我的选择 | 为什么 |
|------|----------|--------|
| 相机 | 用老式索尼f501（家里的） | 零成本启动，老机器本身有年代感 |
| 冲洗 | 标准黑白（不做化学反转） | 成功率优先，先要结果 |
| 扫描 | 数字反相而非放大机 | 放大机已坏、修比买贵；数字可控性强 |
| 处理 | AI像素化 + 调色温 | **这是"特殊质感"的核心来源** |
| 载体 | 硫酸纸/手工纸 | 和版画工坊调性一致，纸感强 |
| 边 | 手工撕 | 对齐"拾景纸刊"的边界触感美学 |
| 在地性 | 植物染料气味 | 呼应工作站已有的植物染料系统 |

## 3.3 为什么不做放大机路线

- 家里那台放大机 1998 年买的，**镜头擦不出来、玻璃碎了**
- 修比买二手还贵
- 即使修好，**现场制作中间流程难把控**
- 她 9/24 已经说了"**那闲鱼卖了吧**"

**结论：数字化路线 + 打印输出** —— 可控、成本低、可复制。

# 四、"可复制"是我最在意的点

我对她说过：
> "**就是不会照相的人也可以通过这流程获得特殊质感的照片**"

这句话是整个项目的灵魂。意味着：

| 传统摄影 | 我这套流程 |
|----------|-----------|
| 要学曝光、构图、冲洗 | 固定相机、固定参数、固定时间 |
| 靠技术 | 靠流程 |
| 门槛高 | **游客/村民都能做** |

**所以我的目标不只是"我做出1张"，而是"跑通一条别人也能复制的流程"。**

这样才能变成工作站的**新体验品类**——像丝网印刷一样，游客能上手、能带走东西。

2. ✅ 流程能**完整复述**（我能一步步教别人）
3. ✅ 成本在 **500—700元** 区间内（我报给她的数字）

**没做到这三条，就是没成：**
- ❌ 出来的东西和普通打印照片没区别
- ❌ 只有我自己能做，别人学不会

## 10.8 一个可以立刻做的动作（不用等胶卷）

**先用现成的数字照片验证后半段流程：**

```
挑1张井邻CR2 或 云南JPG
  → Capture One / PS 打开
  → PS 反相（模拟负转正效果）
  → 像素化 + 调色温
  → 拿去打印店打硫酸纸
  → 撕边
= 一张"手工影像纸刊"小样
```

**好处**：
1. 不用等胶卷，**今天就能验证"像素化+纸感+撕边"这个效果链**
2. 提前知道打印店/硫酸纸吃墨情况
3. 胶卷到货后只需补"冲洗"这一段，主线已经验证过

**这是当前最高性价比的动作。**
