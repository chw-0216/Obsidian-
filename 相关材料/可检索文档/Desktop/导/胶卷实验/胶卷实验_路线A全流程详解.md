# 第1步：装片（暗袋内操作）

**环境**：完全黑暗（暗袋拉好拉链，或暗房）

1. 暗袋内取出胶卷暗盒
2. 用开罐器（或硬币）撬开暗盒盖
3. 取出卷芯，找到片头
4. 把片头卡进**片芯**的卡槽
5. 用拇指轻推胶片，让片芯**来回微转**把胶片卷入（不要硬拉，会划伤）
6. 卷完后把片芯放进**显影罐**，盖好盖子
7. **盖子盖好后，就可以开灯了**（罐子防光）

**⚠️ 失败点**：
- 片芯没完全干 → 胶片粘连（片芯必须彻底干燥）
- 硬拉胶片 → 划痕
- 暗袋漏光 → 整卷报废

# 第2步：拍摄

**建议主题**（有叙事性，别乱拍）：
- 井邻工作站（外观、空间）
- 版画工坊（制版、印刷）
- 村民/生活场景
- 现场活动（领导视察、体验者）

**操作**：
1. 索尼f501装卷（注意ISO设置，f501可能是DX自动识别或手动）
2. 记录每次拍摄的光圈/快门（方便后面校色参考）
3. 拍完不要自己倒片进暗盒（留到最后或直接进暗袋）

# 第3步：配药（冲洗前30分钟）

## 3.1 配 D-76（粉剂）

1. 用**40—50℃的纯净水**约800ml
2. 缓慢倒入药粉，边倒边搅（先倒小袋，再倒大袋）
3. 搅到完全溶解（无颗粒）
4. 补纯净水到1L
5. **静置30分钟**后再用（刚配的药活性不稳）

## 3.2 配停显液

- 冰醋酸原液 : 水 = **1 : 40**（例：25ml冰醋酸 + 1L水）
- ⚠️ 是**酸倒入水**，不是水倒酸

## 3.3 配定影液

- 按产品说明（快速定影通常是1:4稀释）

## 3.4 控温（最关键）

**把显影液、停显液、定影液都放到20℃。**

方法：
- 用一个大盆装20℃水（加冰块或热水调），把药瓶泡在里面
- 每10分钟测一次温度
- 环境温度高时（如夏天），可用水浴维持

**温度偏差的影响**：
| 温度 | 时间调整 |
|------|----------|
| 18℃ | 延长约20% |
| 20℃ | 基准 |
| 22℃ | 缩短约15% |
| 24℃ | 缩短约25% |

**新手建议：死守20℃，不要试图用时间补温度。**

# 第4步：显影（核心步骤）

## 4.1 预浸（可选）

- 倒入20℃清水，浸泡 **1分钟**，倒掉
- 作用：让胶片均匀吸水，避免显影不匀

## 4.2 显影操作

以 **D-76 1:1 稀释、ISO400 胶片** 为例：

| 项目 | 参数 |
|------|------|
| 温度 | 20℃ |
| 时间 | **约9—11分钟**（按药液说明书，HP5约11分钟、Tri-X约9分钟） |
| 搅动 | 前30秒连续轻搅，之后**每分钟搅5秒**（2—3次倒转） |

**操作顺序**：
1. 计时器开始
2. 药液快速倒入罐中（15秒内倒完）
3. 盖上盖子，**前30秒连续轻柔倒转**
4. 之后每分钟：倒转2—3次（约5秒），静置
5. 时间到前15秒开始倒出药液
6. 药液可回收（D-76 1:1 是一次性，原液可重复用）

**⚠️ 失败点**：
- 搅动太猛 → 显影不匀、气泡痕
- 搅动不足 → 显影不均、边缘效应
- 温度漂移 → 密度不对
- 倒药太慢 → 显影时间不准（前15秒要倒完）

---

# 第5步：停显

1. 倒入停显液（冰醋酸稀释液）
2. 搅动 **30秒—1分钟**
3. 倒掉（停显液可重复用几次，直到变色）

**作用**：立刻中止显影，防止过冲。

**没有停显液**：用清水冲洗3—4次（每次换水搅动30秒），但效果不如停显液。

---

# 第6步：定影

| 项目 | 参数 |
|------|------|
| 温度 | 20℃左右（宽容度较大） |
| 时间 | 快速定影 **3—5分钟**；普通定影 5—10分钟 |
| 搅动 | 前30秒连续，之后每分钟5秒 |

**判断定影是否够**：
- 定影中拿胶片对着安全灯/暗红光看，乳白色消失变成透明 = 定影完成
- **定影时间是"透明时间"的2倍**

**⚠️ 失败点**：定影不足 → 胶片日后发黄、影像褪色（不可逆）

---

# 第7步：水洗

| 方式 | 时间 |
|------|------|
| 流水冲洗 | **10—15分钟**（水流别太猛冲胶片） |
| 用去水渍剂前的换水法 | 换水5—6次，每次1分钟 |
| 用海波清除剂 | 可缩短到5分钟 |

**水温**：尽量接近20℃，避免骤冷骤热（会造成药膜龟裂）

---

# 第8步：去水渍 + 晾干

## 8.1 去水渍
1. 倒掉水
2. 倒入去水渍剂（Photo-Flo 1:200）
3. 浸泡 **30秒**
4. 直接取出（**不要冲洗、不要擦拭**）

## 8.2 晾干
1. 从片芯上取下胶片
2. 上端用夹子挂起，下端夹配重
3. 挂在**无尘、阴凉、通风**处
4. 晾 **2—4小时**（不要用吹风机热风）

**得到：一条黑白负片** ✅

# 第9步：扫描

## 9.1 两种路径

| 路径 | 条件 | 成本 |
|------|------|------|
| 自己扫 | 爱普生带透扫单元（胶片夹） | 0元 |
| 送扫描店 | 扫描仪不能扫胶片 | 50—100元/卷 |

## 9.2 扫描参数（自己扫）

| 参数 | 建议 |
|------|------|
| 分辨率 | **2400 dpi**（135胶片；要大幅打印可3200） |
| 位深 | 16位灰度（或48位彩色） |
| 输出格式 | **TIFF**（不要JPG，别丢信息） |
| 锐化 | **关掉**（后期再做） |
| 自动色阶 | **关掉**（后期再做，保留最大信息） |
| 除尘 | ⚠️ 数字ICE对黑白片**无效**（银盐反射），只能手工除尘 |

## 9.3 扫描前除尘（重要）
- 用气吹吹掉胶片上的灰
- 用防静电布/无绒手套操作
- 灰点在黑白片上会非常明显

**得到：负片的数字文件（TIFF）**

# 第10步：数字反相（负转正）★核心

## 10.1 Photoshop 基础法

1. 打开扫描的负片TIFF
2. **反相**：图像 → 调整 → 反相（Ctrl+I）
   - 黑白负片**没有橙色遮罩**（那是彩色负片），所以直接反相效果就好
3. **定黑点**：图像 → 调整 → 色阶
   - 用**黑色吸管**点负片边缘**未曝光的胶片基底**（最透明那条边）
   - 这一步是关键，它把"胶片基底"定为纯黑
4. **定白点**：用**白色吸管**点画面中最亮的高光区
5. **调中间调**：拖动中间灰滑杆，调对比

## 10.2 曲线精修
- 曲线（Ctrl+M）：提亮暗部、压低高光，做出胶片感
- 不要拉太狠，保留层次

## 10.3 去灰除尘
- 污点修复画笔，逐个修掉灰点
- 或用"蒙尘与划痕"滤镜（谨慎，会糊细节）

**得到：数字正片**

# 第11步：AI像素化 / 质感处理（你的差异化卖点）

## 11.1 为什么做这步
你对她说的卖点：
> "用显影药水有个优势可以用AI修复照片做像素化效果"
> "打印出来这种特殊像素化的照片，可以调节色温"
> "不会照相的人也可以通过这流程获得特殊质感的照片"

**这一步是把"洗照片"变成"作品"的关键。**

## 11.2 三种像素化做法

### 做法① 经典像素风（最简单）
1. 图像缩小到原尺寸的 1/8—1/16（如 2400dpi → 300px宽）
2. 用**最近邻（Nearest Neighbor）**放大回原尺寸
3. 得到硬边像素块

### 做法② 马赛克滤镜
1. 滤镜 → 像素化 → 马赛克
2. 单元格大小 8—20px
3. 配合"锐化"强化块面

### 做法③ AI生成（最出效果）
- 你有ComfyUI经验，可以用：
  - 图生图 + 像素艺术模型（pixel-art LoRA）
  - ControlNet 保持原图构图
- 或 Topaz Gigapixel / Magnific 等放大+风格化工具

## 11.3 色调处理（"调节色温"）
- 黑白照片加色调：图像 → 调整 → 色相/饱和度 → 勾"着色"
  - 暖棕（sepia）：色相30—40，饱和10—20
  - 冷蓝（cyanotype感）：色相200—210，饱和10—15
- 或双色调（Duotone）：黑+暖棕 / 黑+深蓝

## 11.4 输出准备
- 分辨率：印刷用 **300dpi**（按成品尺寸换算像素）
- 格式：TIFF 或高质量JPG
- 色域：sRGB（普通打印）或 AdobeRGB（艺术微喷）

# 第12步：打印输出

她说过"**对打印机没要求**"，所以：

| 选择 | 适用 |
|------|------|
| 普通喷墨打印 | 快速看效果 |

**建议**：先普通打印1—2张看效果，满意后做1张艺术微喷定稿。

# 附：这条流程的"可复制性"（她关心的点）

她说这个流程的价值在于"**不会照相的人也能操作**"。所以你要把它整理成**傻瓜流程**：

1. 用固定相机、固定参数拍（不用懂摄影）
2. 按固定时间冲洗（药水套装配方）
3. 扫描 → 一键反相 → 一键像素化（做成PS动作/AI工作流）
4. 打印

**把它做成"一键化"的体验产品**，就是工作站的新体验品类。这也是为什么她要你先"实验一下"——跑通了，就能变成游客项目。
