# 第二部分 · 全流程（13步）

```
第0步 物料准备 → 第1步 装片 → 第2步 拍摄 → 第3步 配药
→ 第4步 显影 → 第5步 停显 → 第6步 定影 → 第7步 水洗
→ 第8步 去水渍晾干 【得到负片】
→ 第9步 扫描 → 第10步 数字反相【得到正片】
→ 第11步 拾景zine转化【得到纸刊作品】
→ 第12步 打印 → 第13步 交付
```

## 第1步：装片（暗袋内）
1. 暗袋内取出胶卷暗盒
2. 撬开暗盒盖，取出卷芯
3. 片头卡进**片芯**卡槽
4. 来回微转片芯把胶片卷入（别硬拉）
5. 片芯放进**显影罐**，盖盖 → **可以开灯**

**失败点**：片芯没干→粘连；硬拉→划痕；暗袋漏光→报废

## 第2步：拍摄
- 建议主题：井邻/工作站/版画工坊/村民/活动现场
- 记录光圈快门
- **拍有叙事性的内容**——后面要做纸刊，素材质量决定成品

## 第3步：配药
- **D-76**：40—50℃纯净水800ml → 倒药粉边倒边搅 → 补到1L → 静置30分钟
- **停显液**：冰醋酸:水 = 1:40（酸倒入水）
- **定影液**：按说明（快速定影约1:4）
- **控温**：三盆药水都泡在20℃水浴里

**温度补偿**：18℃延长20%；22℃缩短15%；24℃缩短25%。**新手死守20℃。**

## 第4步：显影（核心）

| 项目 | 参数 |
|------|------|
| 温度 | 20℃ |
| 时间 | D-76 1:1 约9—11分钟（HP5约11分，Tri-X约9分） |
| 搅动 | 前30秒连续，之后每分钟搅5秒 |

1. 计时器开始，15秒内倒入药液
2. 前30秒连续轻柔倒转
3. 之后每分钟倒转2—3次
4. 时间到前15秒倒出

**失败点**：搅动太猛→不匀/气泡；温度漂移→密度错；倒药慢→时间不准

## 第5步：停显
- 倒入停显液，搅动30秒—1分钟，倒掉
- 无停显液：清水换水3—4次

## 第6步：定影
- 快速定影3—5分钟（普通5—10分钟）
- 搅动同显影
- **定影时间 = "透明时间"的2倍**

## 第7步：水洗
- 流水10—15分钟，水温接近20℃
- 水流别太猛

## 第8步：去水渍 + 晾干
- 去水渍剂泡30秒，直接取出（不冲洗不擦）
- 上夹挂起，下夹配重
- 无尘阴凉处晾2—4小时，**不用热风**

**✅ 得到负片**

## 第9步：扫描

| 参数 | 建议 |
|------|------|
| 分辨率 | 2400 dpi（135胶片） |
| 位深 | 16位灰度 / 48位彩色 |
| 格式 | **TIFF** |
| 锐化 | **关** |
| 自动色阶 | **关** |
| 除尘 | ⚠️ 数字ICE对黑白片**无效**，需手工除尘 |

## 第10步：数字反相（负转正）
1. PS 打开TIFF → **Ctrl+I 反相**
2. 色阶 → **黑吸管点胶片基底**（未曝光的透明边）→ 定纯黑【**关键**】
3. 白吸管点最亮高光 → 定纯白
4. 中间灰滑杆调对比
5. 曲线精修 + 污点修复除尘

**✅ 得到数字正片**

## 第11步：拾景zine 转化 ★（见第三部分）

## 第12步：打印
- 建议：硫酸纸 / 手工纸（贴合版画调性）
- 300dpi，sRGB

## 第13步：交付
拍成品照（正面全图 + 细节 + 负片对比），发她一句话：

> 老师，显影液跑通了，这是出来的效果。

# 第三部分 · 拾景zine（Gathered Scenes Zine）集成

## 1. 这是什么

**「拾景纸刊」**——作者 **Zeejay0** 开发的一套**为 Codex 编写的生图 Skill**（AI agent 技能）。

- 仓库：https://github.com/Zeejay0/gathered-scenes-zine-skill
- 热度：⭐ 5185、Fork 504
- 作者自营站：**https://zeejayzine.com/**（作者称接入 GPT5.6+image2 模型，**国内环境可用**）
- 核心定位：**把普通照片，变成值得停留的一页纸刊作品**

**它的核心思路**（不是套模板）：
```
一张照片 → 阅读现场 → 提取关系 → 选择创作路径 → 重新装订成一页
```

**五条视觉原则**：
1. **真景为锚**——真实场景是作品的事实基础
2. **插画成场**——插画扩展照片没说完整的空间
3. **色彩成结构**——高纯度色彩负责平衡、方向、重心
4. **纸面会呼吸**——留白参与叙事
5. **边界有触感**——撕纸、纤维、干墨、印刷误差

> 这套语言和你的**丝网版画/植物染料**调性高度契合（都是"纸 + 墨 + 手工误差"的美学）。

## 2. 两条创作路径（选一条）

| | **实景拼贴** | **影像蒸馏** |
|---|---|---|
| Skill名 | `scenes-gathered-zine-v1-3` | `scene-distillation-zine-v1-3` |
| 适合 | 保留原照片与现场身份 | 要独立成立的原创插画 |
| 照片角色 | 成为海报中的**真实视觉锚点** | 只作语义/情绪来源，**不进入成品** |
| 方式 | 摄影+抽象插画+结构性色彩+手撕边界 | 提取命题/张力/隐喻，重新创作 |
| 结果 | 真实克制的**纸感拼贴海报** | 表达优先的**极简编辑插画** |

**你的场景建议**：
- 想保留"井邻/村民/工作站"的真实感 → **实景拼贴**
- 想做成可复制的插画风格产品 → **影像蒸馏**

## 3. 创作流程（5阶段）

| 阶段 | 发生什么 |
|------|----------|
| 01 观察 | 找核心主体、空间关系、方向、重量、安静区域 |
| 02 取舍 | 保留让场景成立的最少信息，移除无关细节 |
| 03 转译 | 轮廓/路径/光影/情绪 → 纸上形状与色彩结构 |
| 04 编排 | 摄影+插画+文字+边界+留白形成观看路径 |
| 05 成页 | 输出平面、克制、有触感的纸刊作品 |


```
  ↓
```

# 第四部分 · 时间表与风险

## 时间表

| 阶段 | 耗时 |
|------|------|
| 物料到齐 | 1—2天（看胶卷） |
| 拍摄 | 半天 |
| 冲洗（含晾干） | 2.5—3小时 |
| 扫描 | 30分钟/卷 |
| 反相修图 | 1—2小时 |
| 拾景zine转化 | 1—2小时 |
| 打印+拍照 | 1小时 |
| **合计** | **约2—3天**（物料齐后） |

## 五个最容易失败的点

| # | 失败点 | 预防 |
|---|--------|------|
| 1 | 装片划伤/漏光 | 暗袋操作、片芯全干 |
| 2 | 温度失控 | 水浴控温，死守20℃ |
| 3 | 搅动不当 | 前30秒连续，之后每分钟5秒 |
| 4 | 定影不足 | 定影=透明时间×2 |
| 5 | 扫描没关自动色阶 | 全手动，保留最大信息 |

## 三个硬卡点

| 卡点 | 影响 | 解决 |
|------|------|------|
| **胶卷未到货** | 全流程停摆 | 催货/换现货 |
| **扫描仪能否扫胶片** | 决定自扫还是送店 | 今天确认 |
| **拾景zine授权** | 决定能否商用 | 实验照用；商用先取得授权或用自研工艺替代 |
