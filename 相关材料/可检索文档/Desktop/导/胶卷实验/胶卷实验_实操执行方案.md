## 一、先搞清楚：有两条路，成本差很大

### 路线A：数字负转正（推荐，先走这条）

```
正常冲洗出负片 → 扫描 → 数字反相成正片 → AI像素化处理 → 打印输出
```

- **化学难度**：低（标准黑白冲洗，网上一堆教程）
- **成本**：胶卷+药水 500—700元（你报的区间）
- **优势**：就是你说的"色彩可控""AI做像素化""对打印机没要求"
- **出结果速度**：快

### 路线B：化学反转冲洗（真正的"负片变正片"）

```
首显 → 停显 → 漂白 → 清洗 → 二次曝光 → 二次显影 → 定影 → 水洗
```

- **化学难度**：高（温度±0.5℃、时间精确，新手容易翻车）
- **额外需要**：**漂白液/反转套药**（不是只有显影+定影！）
- **优势**：真正的反转片，物理上是正片
- **风险**：一次失败就废一卷

### ⚠️ 关键提醒

你之前说"**用显影药水在温度下负片变成正片**"——这句不准确：

> **普通"显影液+定影液"只能做出负片。** 要化学反转，必须加**漂白液**并做**二次曝光**。你提到的"冰醋酸"只是停显，方向对，但流程远不止这两步。

**建议：先走路线A拿到结果（她要看成果），路线B作为进阶实验。**

## 三、执行步骤（路线A，逐条照做）

- [ ] 把药水凑齐（显影+停显+定影）

### 第1步：拍摄
- [ ] 索尼f501装卷
- [ ] **拍一个有叙事性的主题**（建议：井邻/工作站/版画工坊/村民），别乱拍
- [ ] 拍完记下拍摄参数（光圈快门），方便后面调

### 第2步：冲洗（约2—3小时）
- [ ] 暗袋里把胶卷装进片芯、放进显影罐
- [ ] **显影**：20℃，按药液说明书时间（D-76 1:1 约9—11分钟），前30秒连续搅动，之后每分钟搅5秒
- [ ] **停显**：冰醋酸稀释液，约30秒
- [ ] **定影**：按说明（通常5—10分钟）
- [ ] **水洗**：流水10—15分钟
- [ ] **晾干**：阴凉无尘处挂干

**得到：一条负片**

### 第3步：扫描 + 负转正
- [ ] 扫描负片（1200—2400dpi，透扫）
- [ ] 数字**反相**（PS：图像→调整→反相；或用负片转换插件）→ **得到正片**
- [ ] AI处理：像素化/质感/色温（你的差异化卖点）

### 第4步：输出

## 四、路线B（进阶，A跑通后再试）

如果想做真正的化学反转：

1. **首显**：20℃，按反转套药说明
2. **停显+水洗**
3. **漂白**：把首显出来的银盐漂掉
4. **清洗**
5. **二次曝光**：把胶卷从罐里取出，见光（均匀曝光，别晒糊）
6. **二次显影**：把剩下的卤化银显影出来 → 正片
7. **定影 → 水洗 → 晾干**

**提示**：这一步最容易失败。建议先拿一卷废片试手。
