# 一、总要求（先给模型这段作为全局设定）

**主题**：井邻｜共印一座村庄

**场所**：北京怀柔渤海镇洞台村 · 井邻乡村美育工作站
真实元素：灰砖墙、木桌、老式门窗、院子、枝叶、悬挂的作品、网框与刮板

**色彩（严格三色）**
| 色 | 用途 |
|----|------|
| **纸白 / 暖白**（#F2EDE3 系） | 底色，带纸纹 |
| **深绿 / 墨绿**（#1F4A3C 系） | 宋体大字标题、主体结构 |
| **朱红**（#D93A22 系） | 叠印色块、重点元素 |

**字体**：中文**宋体**大字，横排或竖排均可，字重要足

**视觉语言（必须体现）**
- 丝网印刷 / 孔版印刷质感
- **半调网点**（halftone dots），不要连续调渐变
- **套印偏移**（misregistration）——色块错开一点点，像手工套色
- **纸纹 / 纤维**质感
- 大块实色 + 大面积留白
- 版画感、高对比、无写实光影

**绝对不要**
- 不要澜沧、不要云南元素
- 不要照片写实感
- 不要 3D、不要发光、不要渐变光晕
- 不要花哨装饰、不要卡通
- 不要多余文字

# 二、六块版（三组双色）

## 第一组：开门 / 生长 —— 对应工作站空间

### 版①「开门」
```
Screen-print poster plate, A4 size.
Subject: an old Chinese wooden door and window of a rural art workstation,
made into a black/white HALFTONE dot pattern. Keep the architectural structure
clear and bold — door frame, lattice window, brick wall texture simplified.
No realistic shading, only halftone dots.
Bottom right: a small circular rainbow-arch logo, tiny.
Palette: paper white background + deep green halftone.
Poster-style, high contrast, printmaking aesthetic, paper grain.
```

### 版②「生长」
```
Overprint layer, same A4 size, designed to be printed ON TOP of plate 01.
Subject: branches and leaves growing through the door and window opening,
extending to a wooden table, a screen-printing frame, and a hanging line
with prints. Simplified flat shapes, no outlines.
Color: VERMILION RED ONLY (flat solid blocks).
Slight misregistration offset, visible paper texture.
This is a separate silk-screen separation layer.
```

---

## 第二组：印台 / 共印 —— 对应现场印制

### 版③「印台」
```
Screen-print plate, A4.
Subject: a screen-printing workstation seen from above —
mesh frame, squeegee, ink cans, wooden table, a few printed sheets.
Rendered as deep-green halftone dots and solid shapes on paper white.
Bold graphic simplification, silkscreen poster language, no gradients.
```

### 版④「共印」
```
Overprint layer for plate 03, A4.
Subject: two hands pushing a squeegee across the mesh —
a wide flat colour block spreads out from the frame and connects
to plant leaf shapes at the edges.
Color: VERMILION RED flat blocks + a YELLOW accent block.
Misregistration offset, halftone texture, paper grain.
Silkscreen separation layer only.
```

---

## 第三组：层积 / 回应 —— 对应视觉探索

### 版⑤「层积」
```
Screen-print plate, A4.
Subject: a portrait reduced to pure black paper-cut silhouettes,
outlines and halftone dot masses — layered, like stacked sheets of paper
forming a face/profile. Inspired by reduction printmaking (绝版木刻).
Black halftone + black solid on paper white, minimal, high contrast.
```

### 版⑥「回应」
```
Overprint layer for plate 05, A4.
Subject: hand-gesture motion trails turning into sound waves,
concentric rings and offset outlines — overlaid around the portrait.
Color: ULTRAMARINE BLUE (群青) flat shapes and thin lines only.
Slight misregistration, paper texture.
Silkscreen separation layer.
```

# 三、规格与输出

| 项 | 要求 |
|----|------|
| 尺寸 | **A4**（210×297mm） |
| 主图区 | 约 **180×240mm**，四周留白 |
| 分辨率 | **300 dpi**（2480×3508 px） |
| 每块版 | **单独输出一张**（共 6 张） |
| 色彩模式 | 黑白制版稿（每色一版）= 正片 |
| 网点 | 调幅网点，**45 LPI** 左右（丝网用） |
| 文字 | 仅主题「井邻｜共印一座村庄」+ 可加小字题签「悲鸿」 |

# 四、组合关系（生图时心里有数）

```
① 开门  ┐
        ├─ 第一组 → 作品一（工作站空间）
② 生长  ┘

③ 印台  ┐
        ├─ 第二组 → 作品二（现场印制）
④ 共印  ┘

⑤ 层积  ┐
        ├─ 第三组 → 作品三（视觉探索）
⑥ 回应  ┘
```

**允许跨组组合**，例如「① 门窗 ＋ ⑥ 手势声波」——让乡村现场与数字回应直接相遇。

**成品形态**：可叠看的小册
- 现场图（①②③④⑤）印在**纸上**
- 回应图（②④⑥）印在**半透明页**上
- 翻页时：枝叶进入空间、手进入家园、动作进入肖像
