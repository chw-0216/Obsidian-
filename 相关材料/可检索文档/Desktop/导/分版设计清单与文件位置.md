# 三、每个分版的详细规格

## S1 / S2 / S3 — 井邻场景三色分版

**共用版式（A4 竖 210×297mm，主图区 180×240mm）**

```
L0  暖白纸（不印）
L1  S1 墨绿网点版 —— 门框、窗格、砖墙结构、木桌沿、网框、刮板、悬挂线
L2  S2 朱红平涂版 —— 穿过门窗的枝叶团块 + 1 个实色重点块
L3  S3 黑网点版（可选）—— 砖纹、木纹、网面网格、手的投影
```

**关键设计**：**左侧门洞处留空**（不印任何内容），作为翻动卡的"空口"。

**输出**
- SVG（可编辑）＋ PDF（1:1 打印）＋ 1200ppi 1bit TIFF（菲林）
- 每张四角带套准十字与裁切线
- 网点：AM 调幅约 **45 LPI**

---

## S4 — 马 两帧分版（新，优先）

**版式**：A4 **横** 297×210mm，两帧并排，各 100×120mm

| 帧 | 内容 |
|----|------|
| **A** | 奔马，四蹄收拢于身下，身体压缩，头低向前，鬃尾后掠 |
| **B** | 同一匹马，四腿伸展——前腿前伸、后腿后蹬，身体拉长，鬃尾飘展；整体比 A 略右移 |

**关键**：头、躯干体量、尾根在两帧中**完全一致**，只变腿部伸展与身体拉伸。

**语言**：木刻/剪纸 —— 平涂黑块 + 负形刻线（肩、胁），最细线 ≥1mm，无内部灰阶。

**输出**：SVG + PDF + 1200ppi 1bit TIFF，中心套准十字 + 100mm 测试线。

# 四、输出规范（所有分版统一）

| 项 | 要求 |
|----|------|
| 菲林 | 1bit 黑白 · **1200ppi** · 实际大小 100%（关闭"适应页面"与二次加网） |
| 打印前 | 量一下 100mm 测试线，确认比例正确 |
| 套准 | 四角十字 + 裁切线；每张版一致 |
| 网点（仅场景版） | AM 调幅 **45 LPI**，角度按色分开（如 45°/75°） |
| 纯形版（动物帧） | **不加网**，纯 1bit |
| 框外内容 | 框外文字、定位十字、测试线**不属作品**，曝光后刷墨前用胶带封住 |
| 白线与眼孔 | 是**无墨区**（镂空）；改手切模板时需另作连接桥 |
