# 微信全量分析：最激进分析判断补丁

> 本补丁负责“分析得更深、判断得更大胆”。它与 `04`、`05` 配合使用：`04` 规定冲刺目标，`05` 提高吞吐，`06` 扩大分析边界和判断力度。当前由用户自行交给 Claude Code 执行，Codex 不运行聊天分析。

> 若同时使用 `07-无上限全量标注理解优先补丁.md`，必须先完成 `07` 规定的标注覆盖门，再运行本文的深层判断。

## 一、什么叫“最激进分析”

最激进不等于武断。它的定义是：

1. **范围最广**：不仅总结聊天内容，还分析自我、关系、社交网络、人生变化、沟通盲点和未来情景；
2. **假设更大胆**：允许提出隐藏需求、互动动机、关系权力、回避与依赖倾向等深层假设；
3. **结论更明确**：不只说“可能有很多原因”，而是给出最可能解释、次可能解释和判断依据；
4. **反证更严格**：每个大胆判断必须主动寻找反例和其他解释；
5. **行动更具体**：最终必须落到关系维护、沟通改变、人生选择和数字分身规则；
6. **不假装读心**：对方真实内心无法从聊天直接确定，只能形成有等级的推断。

允许分析行为和心理倾向，但不做精神疾病、临床心理或医学诊断。

## 二、四级判断强度

每个分析结果必须标记判断等级：

| 等级 | 含义 | 写法 |
|---|---|---|
| L0 事实 | 原文直接出现 | “消息中明确说……” |
| L1 强推断 | 多个独立证据一致，反证很少 | “最可能的解释是……” |
| L2 弱假设 | 有部分证据，但替代解释较多 | “一个值得验证的可能是……” |
| L3 情景预测 | 基于历史模式预测未来 | “如果条件不变，更可能出现……” |

禁止把 L1—L3 改写成对方或本人的确定心理事实。

## 三、所有判断的统一结构

```yaml
judgment_id: 稳定 ID
subject: 本人 | 联系人 | 关系 | 社交网络 | 人生阶段
claim: 明确结论
level: L0 | L1 | L2 | L3
scope: 适用人物、场景和时间范围
evidence_for: [证据消息或事件 ID]
evidence_against: [反证消息或事件 ID]
alternative_explanations:
  - 次可能解释
  - 其他合理解释
confidence: 0-1
confidence_reason: 为什么是这个置信度
cost_if_wrong: 如果判断错误会造成什么影响
validation_question: 用户如何验证
recommended_action: 一项低后悔行动
model_version: null
prompt_version: null
```

没有 `evidence_against` 和 `alternative_explanations` 的深层判断不得进入最终报告。

## 四、最激进的八大分析方向

### A. 深层自我模型

分析蔡浩文在不同阶段和关系中的：

- 核心价值排序和价值冲突；
- 被理解、被认可、自由、掌控、安全、连接、成长等需求的表现；
- 主动争取、等待回应、回避冲突、过度解释、试探和修复倾向；
- 对拒绝、冷淡、赞赏、不确定性和失控的反应；
- 做决定时更依赖逻辑、情绪、关系还是机会窗口；
- 真实自我、理想自我、对外呈现自我之间的差异；
- 自我叙事如何从金融、摄影转向 AIGC 和数字媒体艺术；
- 哪些优势在不同情景会反过来成为负担；
- 反复出现但本人可能尚未意识到的行为循环。

输出不是一个固定人格标签，而是“什么情境触发什么反应”的动态模型。

### B. 单段关系的深层动力

对每个证据足够的联系人分析：

- 当前关系阶段：建立、加深、稳定、降温、疏远、修复或结束；
- 主动发起、回应速度和投入是否长期对称；
- 谁更常提出需求、解释、安慰、让步和修复；
- 双方如何争取注意、确认关系和维护边界；
- 明确需求与隐藏期待是否一致；
- 冲突是被解决、被搁置还是反复重演；
- 关系中的权力来自时间、资源、情感依赖、信息或社交位置；
- 哪些行为显示信任增长，哪些显示防御或撤退；
- 这段关系更可能走向加深、维持、功能化、疏远还是周期性恢复；
- 最值得采取的低后悔行动是什么。

对联系人的判断只代表“聊天中呈现的互动模型”，不能声称掌握其完整人格。

### C. 社交网络全景

把全部联系人放入统一社交网络中分析：

- 核心圈、稳定圈、弱联系、功能联系和沉睡联系；
- 谁连接了不同圈层，谁是信息、情绪或机会的桥梁；
- 哪些关系存在长期单向投入；
- 哪些关系只在需要资源时出现；
- 哪些关系具有真实互惠、共同成长或修复能力；
- 哪些重要关系正在自然衰退；
- 哪些旧关系有较高的重新连接价值；
- 自己是否过度集中在少数关系或长期忽略弱联系；
- 社交资源、情绪支持和创作合作是否过度依赖同一批人。

可以生成关系维度评分，但评分描述的是互动证据，不评价人的道德或“价值”。

建议维度：

```text
current_activity       当前活跃度
initiative_balance     主动性平衡
reciprocity            互动互惠
reliability            承诺可靠性
emotional_support      情绪支持证据
repair_capacity        冲突修复能力
communication_fit      沟通兼容度
growth_alignment       当前成长方向匹配度
interaction_cost       互动成本
trajectory             关系趋势
evidence_strength      证据强度
```

禁止把这些维度简单相加形成“这个人值不值得”的单一总分。

### D. 沟通微行为审计

深入分析：

- 开场是否直接，真实目的出现得早还是晚；
- 一条信息包含多少主题、解释和请求；
- 问句、陈述句、自我披露和对方关注的比例；
- 是否回答了对方真正提出的问题；
- 是否在不确定时连续补充说明；
- 面对延迟回复时如何追问、撤退或改变语气；
- 邀约是否具体，是否给对方容易拒绝的空间；
- 拒绝时是否过度解释或模糊边界；
- 冲突时更偏向证明自己、理解对方、暂时回避还是快速修复；
- 情绪支持时是先分析解决，还是先承接感受；
- 哪些表达经常获得积极回应，哪些之后容易中断；
- 线上承诺是否在现实行动中完成。

将模式分别按朋友、合作、家人、亲密关系、陌生人和群体场景比较。

### E. 盲点、矛盾和自我欺骗风险

主动寻找：

- 口头价值观与长期行为不一致；
- 说想要的关系与实际投入方式不一致；
- 对自己和对方使用不同标准；
- 把没有表达的期待当成对方应该理解；
- 把偶发积极互动解释成稳定关系；
- 把关系降温全部归因于外部原因；
- 对某些人过度解释，对另一些人过早放弃；
- 用分析、幽默、忙碌或创作回避直接表达需要；
- 重复选择相似互动模式，却期待不同结果；
- 用数字分身美化过去，而不是忠实保留矛盾。

每项“盲点”至少需要两个独立场景，或者明确标为 L2 弱假设。

### F. 时间演化与人生转折

按月、季度和年度比较：

- 社交圈变化；
- 表达方式变化；
- 自信、主动性和边界变化；
- 兴趣、职业身份和创作方向变化；
- 哪些人物推动了转折；
- 哪些事件造成收缩、扩张、停滞或重新开始；
- 过去的自己和现在的自己有哪些连续性与断裂；
- 哪些尚未完成的人生主题反复回归。

### G. 未来情景与关系预测

不是算命，而是基于历史模式生成条件预测：

```text
如果保持当前做法，最可能发生什么？
如果改变一项沟通行为，可能出现哪些不同结果？
什么早期信号说明关系正在改善或恶化？
哪种行动即使判断错误，后悔成本也较低？
```

每项预测必须给：基线情景、乐观情景、悲观情景、触发条件、早期信号和可逆行动。

### H. 深层数字分身

数字分身不只模仿口头禅，还要分别建立：

- `actual_self`：历史聊天中真实呈现的自己；
- `confirmed_self`：本人明确认可的事实和价值观；
- `aspirational_self`：本人希望成为的样子；
- `situational_selves`：面对朋友、合作、家人和创作时的不同表达；
- `contradictions`：尚未解决的矛盾和观点变化；
- `shadow_hypotheses`：可能被回避、压抑或未直接表达的需求，仅作为 L2 假设；
- `growth_rules`：数字分身如何随着新聊天和本人反馈更新。

数字分身回答时可选择“历史真实版本”“当前确认版本”或“理想成长版本”，不能把三者混在一起。

## 五、每位联系人的激进判断卡

数据足够时，为每位联系人生成：

```yaml
relationship_stage: 当前阶段
relationship_role: 这段关系在生活中的实际功能
strongest_bond: 最强连接证据
main_tension: 核心张力
initiative_pattern: 主动性模式
reciprocity_pattern: 互惠模式
unspoken_expectations: 可能未明说的期待
power_sources: 关系权力来源
repair_pattern: 冲突后的修复方式
interaction_cost: 互动成本及证据
growth_value: 共同成长证据
trajectory: 加深 | 稳定 | 功能化 | 降温 | 周期恢复 | 不确定
best_action: 深化 | 修复 | 澄清 | 保持 | 降低投入 | 观察
evidence_for: []
evidence_against: []
confidence: 0-1
validation_question: 用户验证问题
```

数据不足时不强行生成确定结论：

- 少于 20 条实质消息：只能做 L0 事实和低置信度初步假设；
- 20—100 条实质消息：可以做情景性模式，不做稳定人格判断；
- 超过 100 条且跨多个时间段：可以形成关系趋势和稳定互动假设；
- 关键关系即使消息很多，也必须按时间分期，不能用早期互动代表现在。

## 六、最终必须回答的尖锐问题

全量分析完成后，生成一份不回避结论的回答，但每项保留证据和反证：

1. 我在人际关系中最稳定的三个优势是什么？
2. 最限制我的三个沟通循环是什么？
3. 我最容易在哪类关系里过度投入、回避或误判？
4. 我真正想从关系中获得什么，但经常没有直接表达？
5. 哪些关系正在自然加深，哪些只是在惯性维持？
6. 哪些联系人值得深化、修复、重新连接、维持轻联系或降低投入？
7. 哪些重要承诺、误解和未完成对话仍在影响现在？
8. 我的职业、创作和身份转型如何改变了社交关系？
9. 我的聊天形象与我希望成为的人有哪些落差？
10. 如果未来一年只改变三个沟通行为，哪三个杠杆最大？
11. 哪些关于自己的故事已经过期，却仍在影响决定？
12. 数字分身最容易把我美化、简化或误读成什么样？

## 七、多模型人格法庭

对重要结论使用五个独立角色：

1. **检察官**：提出最尖锐、最不舒服但有证据的解释；
2. **辩护人**：寻找情境原因、善意解释和反证；
3. **关系研究者**：分析互动结构，不站任何一方；
4. **未来预测者**：分析模式不变和改变后的情景；
5. **证据法官**：只根据原始消息及证据等级形成最终裁决。

最终报告必须同时展示检察官与辩护人的最强论点，再由证据法官给出：

- 当前最合理判断；
- 置信度；
- 判断错误的可能代价；
- 最低后悔的下一步行动；
- 需要本人回答的验证问题。
