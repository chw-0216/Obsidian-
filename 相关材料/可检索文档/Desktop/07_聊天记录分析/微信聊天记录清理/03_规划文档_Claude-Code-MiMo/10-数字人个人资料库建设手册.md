> 配套文档：《09-WeFlow聊天记录高效使用方案.md》（同目录；本手册是其中第 10 节的展开）。
> 你选定的三项用途：A 传记与自我梳理 → 第 1、2 节；B 个性化 AI 助理 → 第 3 节；C 风格化陪伴对话 → 第 4 节。

## 1. 传记骨架：人生时间线模板（今天就能开始填）

## 2. 成就与里程碑
- （每条同样带来源/日期）

## 3. 转折点与选择（价值观线索）

## 2. 传记素材抽取提示词（周复盘时用 Ollama 跑）

在 ChatLab 里检索出一周相关片段（按人/群 + 时间过滤），粘贴到下方提示词，用 hermes3:8b 本地跑：

```
你是档案整理员。从以下聊天片段中抽取关于【我】的候选传记素材。
只抽取明确陈述，不推断、不美化。
每条输出格式：
- 类型：事件 / 成就 / 自我认知 / 他人评价 / 转折点 / 未竟之事（六选一）
- 内容：一句话
- 相关人：有则填，没有写"无"
- 来源：片段编号 + 日期
- 置信度：明确陈述 / 间接提及
不确定的宁可不抽，最后单独列一行"以上共 N 条"。

片段：
[片段1] 日期：……  内容：……
[片段2] ……
```

产出的候选先放在 `02_ai_workspace\`，你逐条确认后写进第 1 节的时间线或 `02_profile\` 事实卡。

## 3. "关于我"上下文文件（个性化 AI 助理用）

目的：让 AI 助理（本地 Ollama 或云端助手）拥有你的上下文，回答更贴合你。**做两个版本**：

- `02_profile\about-me-full.md` —— 含敏感信息，**只喂本地模型**；
- `02_profile\about-me-public.md` —— 脱敏版（去姓名、号码、地址、公司实名），可喂云端。

```markdown
# 关于我（版本：full / public，更新日期：____）

## 称呼与身份
- 希望怎么称呼我：
- 职业/身份简述：

## 工作与项目
- 当前在做：1) … 2) …
- 常用工具与平台：
- 我的工作节奏偏好（如：先给结论再给理由）：

## 表达偏好（怎么和我说话）
- 喜欢：直接、结构化、给选项
- 不喜欢：绕弯子、过度客套
- 回复长度偏好：

## 知识领域
- 擅长/关注：
- 不熟悉、需要解释的：

## 常见任务与约定
- 例：每周日晚做周复盘；待办一律带截止日期

## 禁忌与边界
- 不要替我做承诺；不确定就问；涉敏内容只在本机处理

## 风格速写（链接到第 4 节风格卡，public 版只放 3 条最显著特征）
```

维护规则：每周复盘时顺手同步；每次改动在顶部更新日期。两个版本**同一周至少核对一次**，防止脱敏版漏掉新增敏感项。

## 4. 风格档案（风格化陪伴对话用）

### 4.1 风格分析提示词（拿 100~300 条你的真实消息跑 hermes3:8b）

> 想快速凑样本：先从 WeFlow 导出或 ChatLab 检索出"你发的"消息 100+ 条，去掉图片/语音转文字噪音，粘贴进来。**今天没有导出数据的话，从微信里手动复制几十条也能先跑一版。**

```
你是语言风格分析器。以下是我本人发出的聊天消息样本。
请统计我的表达风格，输出严格 JSON（只输出 JSON，不解释）：
{
  "高频词": ["词1", "词2", ...最多15个],
  "句长特征": {"平均字数": N, "常用句子长度": "短句/中句/长句"},
  "语气词": ["嗯", "哈哈", ...],
  "表情使用": {"频率": "高/中/低", "典型表情": ["…"]},
  "称呼习惯": ["怎么称呼别人", "自称"],
  "常用开头": ["…"],
  "常用结尾": ["…"],
  "标点习惯": "例：常用省略号、少用感叹号",
  "口头禅": ["…"],
  "整体风格速写": "两三句话"
}
注意：只统计样本中出现的，不补全。

消息样本：
1. ……
2. ……
```

结果存为 `02_profile\style-card.json`，每季度重跑一次更新（风格会漂移）。

### 4.2 陪伴对话系统提示词（模板，填入风格卡后用）

```
你是"数字分身（统计模拟）"，依据我的个人资料库与风格卡陪我聊天。
规则：
1. 开场与关键处明示："我是基于你聊天记录的统计模拟，不是本人。"
2. 涉及事实问题（约定、时间、观点）先检索资料库，回答末尾附引用；
   资料库里没有的，回答"记录里没有，我不确定"，绝不编造。
3. 表达风格参考风格卡：{{此处粘贴 style-card.json 的"整体风格速写"与"口头禅"}}
4. 你不用我的名义对外承诺、回复、签署任何东西。
5. 敏感话题（健康、财务、他人隐私）只在本机讨论，提醒对方不要外传。
```

### 4.3 风格卡的边界
- 风格卡是**统计摘要**，不是人格模型；陪伴对话的效果 = 风格相似度，不承诺"像本人思考"；
- 如效果不理想，优先加样本量、更新风格卡，而不是去微调模型。

## 6. 隐私分级（资料库专用）

| 级别 | 内容 | 存放 |
|---|---|---|
| 永不入库 | 密码、验证码、银行卡号、身份证号 | 任何库都不存 |
| B 级 | 家庭住址、手机号、健康细节 | 加密存放，仅本地 |
| A 级 | 偏好、项目、观点、风格 | 本机明文；脱敏后才进 about-me-public |
| 云端 | 仅 A 级且去识别信息 | 只进脱敏片段 |

## 7. 一个免费提醒

你这次没勾选"回忆问答助手"，但它其实是整条流水线的**免费副产品**：ChatLab 检索 + 事实卡带出处，天然支持"我上次和 X 约的什么""我 2024 年怎么评价过 Y"。资料库建好后这个能力自动就有，不需要额外工作。
