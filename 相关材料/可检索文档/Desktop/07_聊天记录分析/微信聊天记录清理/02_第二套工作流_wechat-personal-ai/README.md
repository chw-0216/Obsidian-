# wechat-personal-ai

本地优先的微信聊天多轮分析系统，为数据所有者蔡浩文提供三项能力：

1. **个人记忆系统** — 可检索、可更新、可回到原始证据
2. **沟通教练** — 基于记忆系统的可验证沟通练习
3. **数字分身** — 明确标识为 AI 的授权代理

## 设计原则

- 原始数据只读，任何清洗都生成新层
- 观察、推断和用户确认必须分开
- 每个结论保留时间、片段 ID、证据消息 ID、置信度
- 不做心理/医学诊断，不推断敏感身份
- 不对联系人做"价值评分"，不生成操控策略
- Token 不写入日志或 Git

## 六轮分析框架

| 轮次 | 目标 | 产物 |
|------|------|------|
| R0 | 数据盘点 | 文件/消息/类型/覆盖统计 |
| R1 | 可观察事实 | 对话片段的结构化标注 |
| R2 | 关系模型 | 单联系人的长期互动模式 |
| R3 | 自我模式 | 跨关系的沟通模式（三列分类） |
| R4 | 沟通教练 | 可执行的行为实验 |
| R5 | 数字分身 | 分层记忆 + Persona |

## 运行模式

| 模式 | 说明 | MiMo 调用 |
|------|------|-----------|
| `design_only` | 只生成框架，不读正文 | 否 |
| `pilot` | 少量样本校准 | 是 |
| `standard` | 全量私聊分层处理 | 是 |
| `deep` | 指定人物/时间/问题 | 是 |
| `digital_twin` | 仅用户确认记忆 | 是 |

## 与 WeChat-MiMo-Analyzer 的关系

本系统复用其 `wechat-private-v2.sqlite3` 数据库的 segment_id 和 msg_id 作为证据引用，但有独立的分析数据库。旧系统继续独立运行。
