## 菜单选项

| 选项 | 说明 |
|------|------|
| 1 | **运行 R1 标注** - 推荐，每次处理 10 个批次 |
| 2 | 运行 R0 数据盘点 |
| 3 | 查看当前进度 |
| 4 | **继续 R1** - 断点续跑，自动跳过已标注 |
| 5 | 退出 |

## 参数说明

R1 标注默认参数：
- `--batch-size 4`: 每批 4 个片段
- `--max-batches 10`: 每次运行最多 10 批
- `--budget 0.25`: 每批预算 $0.25

如需调整参数，可直接运行：
```bash
python src/run_r1_standard.py --batch-size 4 --max-batches 20 --budget 0.25
```

## 注意事项

1. **可随时中断**: 按 Ctrl+C 中断，进度自动保存
2. **断点续跑**: 选择选项 4 或重复选项 1，自动跳过已标注片段
3. **Token 消耗**: 每批约 $0.25，10 批约 $2.5
4. **运行时间**: 每批约 1-2 分钟，10 批约 10-20 分钟
