# 现版可接续工程

打开逐镜剪辑表，可按时间码、动作与素材编号找原片。现版无声片段有 15 个；16 行决策中的两行 P13 已合为一个连续镜头。现版镜头顺序.ffconcat 可交给 FFmpeg 读取。原始素材和对应原声可单独替换。上版运镜素材含 16 个可调整镜头、三段独立版本，G01、G02 是旧的视觉重构，仅用于比较。

“复现原版.py”和相邻的配乐脚本按当前文件夹结构重连，输出到项目根目录的新导出。运行需要带 libx264 和字幕支持的 FFmpeg／ffprobe、Python 3、Pillow、NumPy、SciPy 和 OpenCV；现成 MP4 的播放无需这些工具。在新版本制作中可直接沿用真实现场镜头、原始素材和清单，自行选剪辑软件。

基准快速合成只需要 FFmpeg。从项目根目录运行下列命令，输出到新文件：

```powershell
ffmpeg -n -f concat -safe 0 -i "剪辑工程/现版镜头顺序.ffconcat" -i "剪辑工程/声音/现版完整混音.wav" -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -t 70.8 -movflags +faststart "基准复现.mp4"
```

原版再现命令为 `python "剪辑工程/复现原版.py"`。它保留旧版 G01、G02，仅适用于再现 70.8 秒基准。按新要求正式剪时，将这两处回到 P15、P09；P13 原照片重做俯摇。所有工作文件用相对位置查找。
