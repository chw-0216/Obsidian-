# Gesture Synth · 双手成曲

参考原站：https://gesture-synth-weld.vercel.app/

基于 Eric Wei 的公开源码 https://github.com/ericwei97-cloud/gesture-synth 本地改编，原始提交 `7ee25ba8c30f0a0cf544835a2dae199e4b7b9484`。许可证见 LICENSE：个人、教学、非商业使用，保留作者署名；商业使用需要作者许可。

## 启动

双击 `START.cmd`，浏览器打开 http://127.0.0.1:4176 。推荐 Chrome 或 Edge。点击“开启摄像头演奏”并允许本机摄像头；点击“先试试声音”可在不开摄像头时体验同一声音引擎。

停止本地服务：双击 `STOP.cmd`。不需要使用时也请在网页点击“结束演奏”，会立即释放摄像头。

## 保留的原版演奏逻辑

- 左手 1–5 指选 I–V 级，食指＋小指选 VI，再加拇指选 VII；手腕内/外倾切换大/小调。
- 右手 1–4 指选原位、第一转位、大/小七、属/减七和弦。
- 右手拇指伸出降一个八度；手高控制音量、手腕倾斜控制滤波。
- 保持手势持续发声，变换手势切换和弦，握拳或移出摄像头渐弱停音。

## 本地改编

中文引导、单手入门、可选半音偏移、双手互换、骨架与镜像画面、和弦色彩/波纹同步、合成器声音录制/回放、可选录音下载、键盘与鼠标试奏。声音使用原版的三种振荡器音色；没有将合成音伪称为真实弦乐采样。

模型与 WASM 均随应用本地保存，运行时无需访问第三方 CDN；未包含原版的 Clarity/Vercel 统计代码。摄像头只在用户点击后申请，音轨设置为 audio:false。录音只录合成器输出，不包含人声或摄像头视频。显示设置保存在该 localhost 站点的 localStorage 中。

《Yesterday》是用户提供的演奏参考。本应用提供相同类型的自由和弦控制器，不内置其原唱录音或整曲谱面。根据自己已有的和弦谱选择主调并连续改变手势即可练习。

## 适用范围与已知限制

- 不是原站最新版的逐像素镜像：原站比公开仓库新增了部分声音选项。本地版保留公开源码的声音基础和核心手势逻辑。
- 普通摄像头的遮挡、光照和手指弯曲会影响识别。手掌面向镜头、两手分开，不要让一只手遮住另一只。
- 和弦切换稳定窗口约 85 ms，丢手后约 160 ms 淡出；连续音量和滤波另行平滑。未将这些参数当作实测端到端延迟。
- 自动化可以检查和声、停音、界面和声音引擎。真人手势与摄像头体验需由使用者实际演奏检查。
- 录音先存在当前浏览器会话内，刷新页面会丢失；需要保留时点击“保存录音”。浏览器按自己的下载目录保存。

## 开发

已安装 Node.js v24.18.0。依赖只在本项目 node_modules；构建 `npm run build`，验证 `npm test`。公开源码原件保存在 `.upstream`，原仓库 Git 记录也保留。
