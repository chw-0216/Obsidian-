### ★★★ 时间窗推论（本轮最重要的机制发现）

> **任何早于 2024-11 的关系，消息量必然 = 0 —— 不是「没聊过」。**

**直接后果**：预标定把 **首经贸本科同学（2021 届）全部判为「远」**，
而他们其实活在朋友圈里（**65 人消息 0 / 朋友圈互动 > 0**）。

→ **「距离档推不出来」有两重原因**：
① 行为 ↛ 关系性质（已知）② **数据窗口只有 2 年，历史关系被压平**（本轮新增）

## 五、★ 技术坑清单（踩过的，别再踩）

| # | 坑 | 正解 |
|---|---|---|
| 1 | `session_type="私聊"` 用**双引号** → SQLite 当标识符，**静默返回错结果** | 必须用**单引号** `'私聊'` |
| 2 | **同一 cursor 嵌套 `execute`** → 外层循环只跑 1 次，**不报错** | 先 `list(cur.execute(...))` 或另开 cursor |
| 3 | FTS 用 `tokenize='trigram'` | **查询词必须 ≥3 字**；2 字人名（导师/陈晔）改用 `LIKE` |
| 4 | `contact_label` | 只有 52 个**定义**，**映射表不在解密库** |
| 5 | `chatroom_member.member_id` | **= `contact.id`（rowid），不是 wxid**；**SELF = 3641** |
| 6 | Windows 控制台 | 中文/emoji 长输出会截断 → **写文件再读** |
| 7 | 二进制字段 | `pack_info_buf` 解码失败 → `con.text_factory = lambda b: b.decode('utf-8','ignore')` |
| 8 | `sessions` 表列名 | 是 **`talker`**，不是 `session_key`（`messages` 表才叫 `session_key`） |

> **元教训**：**「消息流里没有」≠「数据里没有」** —— 结论要**跨源验证**再下。

## 六、★★★ 三条方法论硬结论（可复用到任何新数据）

1. **距离档不可自动推断**（`05-纠偏层` 三·补·27）
   6 特征全败：消息量 / 时间跨度 / 活跃天数 / 我发占比 / 对价词 / 亲属词。
   根因：他的「中」＝**对价 / 血缘 / 婚恋意图**＝**关系性质**；数据里只有**行为**。

2. **「坑」不留文字痕迹**（`05-纠偏层` 三·补·31）
   全库 `坑` 484 / `骗` 1,063 / `拉黑` 69，**几乎全是公众号文章，无一条真人冲突**。
   → **「关系质量」也不可从文本情感读出**。

3. **朋友圈是独立的第二关系层**（本轮新增）
   朋友圈互动 115 人里 **65 人（57%）消息为 0**；有消息的 1,801 人里只有 **50 人（2.8%）**有朋友圈互动。
   → 与消息量**几乎正交**，必须单独建模。
