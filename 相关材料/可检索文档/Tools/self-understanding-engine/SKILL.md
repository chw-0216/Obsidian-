# 自我理解引擎 · Self-Understanding Engine

> **目的**：让一个刚开机的会话，能在几分钟内达到「接近本人」的读聊天水平。
> **不是**替代本人判断，而是把本人已经想清楚的东西**一次性装上**。

---

## 核心命题（先读这一句）

> **理解 ≠ 读字面。理解 = 用本人的我执去读本人的话，再用人工锚点校准。**

**四层缺一不可**（2026-09-29 补入事件层 · 2026-10-04 补入无人时层）：

| 层 | 文件 | 回答 |
|---|---|---|
| **人格层** | `01` | 他**为什么**这样回（我执 / 三态 / 距离定律） |
| **人际层** | `04` | 他**对谁**这样（98 人距离地图） |
| **事件层** | `07` + `事件库.csv` | 他**何时**经历了什么（2,686 事件 / 5 阶段 / 9 链） |
| **★ 无人时层** | `09` | **没有人在对面时**他是什么样（朋友圈 / 搜索 / 收藏） |

四件都缺会怎样：

| 缺什么 | 会怎样 |
|---|---|
| 缺「我执模型」 | 只读到字面，读不到话背后的驱动 |
| 缺「人工锚点」 | 机器会把性别/关系读反（已发生 2 次，见纠偏层） |
| 缺「距离地图」 | 会把「关系浅」误判成「关系好」 |
| 缺「事件档案」 | 知道他对谁说什么，但不知道那句话背后的**生活现场** |
| 缺「无人时档案」 | 只看到**应机态**（被对方塑形的他），读不到**镜像态**（他自己） |

**加载后必须内化的 6 条铁律**（详见 01 / 05 / 07）：

1. **他的核心驱动是「证明有用」** —— 这是一切关系的底层算法。
2. **距离定律**：关系性伤害 ∝ 1/距离；事务性结清 ∝ 距离；零距离的负面被**重新归因** → 不入账（见 `01` · 4.1）。
3. **「正常」≠ 关系好**，是关系浅到还没检验我执。
4. **人工锚点优先于一切机器推断** —— 关系/性别以 `人际网络标注.csv` 为准。
5. **他的输出＝应机态，独处＝镜像态** —— 聊天里看到的是「表演层」，不是全部。
6. **读事件先定链** —— 孤立一条事件必误读；先问「这条属于哪条链」。

**读他时的三条红线**（详见 `01` · 4.1 / 五·补）：

| # | 红线 | 为什么 |
|---|---|---|
| 1 | 不要逼他承认被家人伤到 | 「我能承受」是他的支撑结构 |
| 2 | 不要把「多线并行」读成缺陷 | 那是**防御装置**；拆之前他还没有别的出口 |
| 3 | 不要建议「先攒钱再谈感情」 | 关系支出 > 现金安全是他的排序（`01` · 五·补·2）；只能**先补现金流入口**，不能砍支出 |
| 4 | 不要把「先玩玩」读成道德问题 | 那是他对**资源约束**的应对（`01` · 五·补·3）；读成道德问题就读不懂他的关系行为 |

## 四类任务路由

### A. 读一个人（「这个人是谁 / 什么意思」）
→ 读 ① + ② + ④ + ⑤ → 输出：**距离半径 / 关系性质 / 结向 / 我执投射空间 / 建议姿态**

### B. 读一段对话（「我该发什么 / 她这句话什么意思」）
→ 读 ① + ② + ③（+ ⑦ 若涉及历史背景）→ 输出：**三态诊断（绿/黄/红）→ 红线检查 → 一句话建议**
（实时场景直接跑 `scripts/understand.py --who X`）

### C. 读经历（「我经历过什么 / 那段时间怎么样 / 帮我复盘」）★新增
→ 读 ① + ② + ③ + ⑦ + `事件库.csv` → 输出：**阶段底色 → 因果链定位（第几环）→ 影响评估（距离×负荷×链）**
（检索用 `事件库.csv`；重建用 `scripts/build_event_layer.py`）

### D. 读结构（「我的关系网络怎么样 / 有什么规律」）
→ 读 ① + ② + ④ + `wechat-data-forensics` skill → 输出：**结构结论 + 可证伪点**

## 输出规范

- **先结论后依据**（他的节奏偏好）
- **口语化、短句**（他日常 21 字/条，长句三段式会「像念稿」）
- **时间线优先**：他理解事件的方式是「按时间排」，不是「按类别排」
- 涉及判断时**标注风险与备选**，不给单一赌注式建议
- 不用「赋能/闭环/抓手」这类空话
- 引用数字必须可溯源（回原始 JSON / CSV），**不引用过期快照**

---

## 与其它技能的关系

- `wechat-data-forensics`：**方法层**（怎么导出、怎么清洗、怎么批量画像、实时 API、事件挖掘）
- 本技能：**理解层**（他是谁、怎么读人、怎么读话、他经历过什么）
- 两者叠加 = 完整的「像本人一样读懂」
