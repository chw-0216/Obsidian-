# 02 · 读人协议（给一个人定性）

> 用于任务：**「这个人是谁 / 什么意思 / 值不值得经营」**

---

## 第一步 · 定距离半径（先做这个）

| 判据 | 半径 |
|---|---|
| 每天物理共处（同住/同室） | **零** |
| 同门/同班/日常同学/亲密线 | **近** |
| 有共同背景但非日常（校友/老同学/朋友/前辈/亲戚） | **中** |
| 单一事务接口（网友/商业/服务/交易/工具） | **远** |

**距离半径决定了读法**：
- 近 → 警惕「伤害」（我执被照出）
- 远 → 只有「事务」（不要解读出情感）
- 零 → 我执不介入，**不要用消息量衡量**

---

## 第二步 · 四级筛（他实际在用的分层系统）

```
第一级：能帮我「证明」吗？   → 高频经营（导师 3,348）
第二级：有对价吗？           → 保留（Eloise 4,686）
第三级：是义务吗？           → 最低限度（蔡黎明/蔡晓梅）
第四级：既不帮也无对价？     → 删/疏远（077 已单删）
```

⚠️ **但第四级要小心**：「她索取」≠「这段关系亏」。必须过**双向核算**。

---

## 第三步 · 双向核算（强制）

| 道 | 问什么 |
|---|---|
| 1. 成本侧 | 他付出多少条 / 多少时间？ |
| 2. **收益侧** | **这段关系能给出什么？（资源/信息/情绪/机会）** |

**计入「负产出」前必须先剔除四类**：

| 类别 | 例 | 为何不算亏 |
|---|---|---|
| 义务性 | 蔡黎明、蔡晓梅 | 不是投入，是必须 |
| 有对价 | Eloise | 成本高但收益也高 |
| 渠道失真 | 父母（同住） | 数字无意义 |
| 主动止损 | 077 | 是成功决策 |

---

## 第四步 · 判结向（不看消息量）

| 结向 | 含义 |
|---|---|
| 现任 / 前任 / 暧昧 / 追求 | 情感线 |
| 可发展 / 可睡 | 备选池（与情感线**并列**，不从属） |
| 正常 / 朋友 | 中性 |
| 疏远 / 无果 / 小人 / 背叛 | 伤害 |
| 欠钱 / 利用 / 应付 | 事务 |
| 无交集 | 无痕（唯一真亏） |

> **铁律：消息量 ≠ 关系价值。** 必须配「结向」字段。陈昶文 6,275 条（未决）＞ 笑一 5,625 条（现任）——投入最大的不是成功的。

---

## 输出格式

```
【距离半径】近 / 中 / 远 / 零
【关系性质】一句话
【结向】现任 / 疏远 / 事务 / …
【双向核算】成本 ___ ｜ 收益 ___ ｜ 净判 正/负/结清
【我执投射空间】大 / 小 / 无
【建议姿态】经营 / 保留设边界 / 最低限度 / 止损
【不确定处】我无法从数据回答的：___
```

**最后一行必须有。** 宁可承认不确定，也不要给一个「听起来完整」的结论。
