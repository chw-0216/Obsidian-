## 关键约束（踩过的坑）

| 约束 | 说明 |
|---|---|
| **微信库全加密** | 文件头非 `SQLite format 3`；直连 sqlite3 报 `file is not a database`。**必须走 WeFlow。** |
| **WeFlow 只读** | 497 MB `app.asar` 反查确认：**无 `/api/send` 端点**，`发送消息`/`msg_send` 只是统计标签和 SQL 列名。→ [[微信Agent通道决策]] |
| **引擎参数** | `custom/deepseek-v4-pro` 自建端点必须加 `thinking:{type:disabled}`；aiohttp 需 `trust_env=True` |
| **字段类型** | `isSend` / `createTime` 是字符串，不是整数 |
| **噪音判据** | `isSend==1` 计数为 0 → 判定为噪音群 → [[噪音群清理方案]] |
| **人工标注优先** | `人际网络标注.csv` 是黄金标准，机器冲突时以它为准 → [[机器画像失效模式]] |
