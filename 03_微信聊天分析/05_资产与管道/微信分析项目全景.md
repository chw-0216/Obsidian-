# 微信消息「自动分析 / 自动收发」项目全景表（2026-09）

> 分类原则：按**技术路径**分组，安全性从高到低排列。
> ⚠️ 除 iLink/ClawBot 官方通道外，其余均属非官方，存在封号风险。

---

## 一、官方通道（iLink / ClawBot）— 最安全

腾讯 2026-03-22 上线微信 ClawBot 插件，开放 **iLink 中继协议**。
链路：`微信 ←→ iLink 云中继 ←→ 本机插件 ←→ Agent`

| 项目 | 能做什么 | 地址 |
|---|---|---|
| **yuuouu/WeChat-Bridge** | 把微信变成 **HTTP 消息通道**。`/api/send`、`/api/send_image`、`/api/webhook`、`/api/ai_analyze`。内置 AI 自动回复（OpenAI/Gemini/Claude/DeepSeek/MiniMax），支持微信内遥控 AI CLI（`/code`、`/switch`）。纯 Python 重写协议，Docker/一行脚本部署 | `github.com/yuuouu/WeChat-Bridge` |
| **weclaw** | 多 Agent 路由器，`/cc` `/gm` `/oc` 切换 Codex/OpenClaw 等后端，支持图片、语音、主动推送 | `github.com/fastclaw-ai/weclaw` |
| **vibe-remote** | 带可视化看板的 Agent 中控台，按频道分配不同 Agent，健康状态监控 | `github.com/cyhhao/vibe-remote` |
| **wechatbot** | 超轻量，直连 iLink 底层，断线自动重连，多模态（文字/图片/语音 SILK+STT） | `github.com/sorrycc/wechatbot` |
| **openclaw-weixin** | 官方侧 OpenClaw 插件，扫码登录，长轮询拉消息 | OpenClaw 生态 |

**限制（官方规则，绕不过）**：必须用户先发消息拿到 `user_id`；24 小时会话窗口；连续 10 条上限。

## 二、只读分析类 — 零封号风险

不发消息、不注入进程，只读本地数据库。

| 项目 | 能做什么 | 地址 |
|---|---|---|
| **wechat-cli** | 微信命令行工具，11 个命令：`sessions`/`history`/`search`/`contacts`/`members`/`stats`/`export`/`favorites`/`unread`/`new-messages`。默认 JSON 输出，专为喂给 AI Agent 设计。**全程本地，不走第三方服务器** | 苍何开源 |
| **WeChatBridge（微信流）** | 一键把选中聊天记录发给 Codex/Claude/豆包等 Agent；支持"场景化"（客户复盘/群聊摘要）；可沉淀到 Obsidian 做个人知识库 | `github.com/freestylefly/WeChatBridge` |
| **WeSight** | 基于 wechat-cli 的桌面端 Agent，群聊分析监控预警、收藏管理、聊天记录导出分析 | 苍何（闭源） |
| **WeFlow**（本机已装） | 导出微信数据：Emojis / Images / Voices / sns_cache（朋友圈缓存）。含 **SenseVoice** 语音转写模型（model.int8.onnx，239MB），可把语音消息转文字 | 本机 `Documents/WeFlow/` |

**推荐组合**：`WeFlow 导出 → wechat-cli 检索 → Agent 分析`。零风险，能力完整。

## 三、Hook 注入类 — 功能最强，风险最高

注入微信进程 / Hook API，**腾讯重点打击对象**，建议只用小号。

| 项目 | 能做什么 | 地址 |
|---|---|---|
| **WeChatFerry (WCF)** | Windows 注入 Hook + RPC，生态最成熟。收发各类消息、群管理、朋友圈、好友操作。多语言 SDK（Python/C#/Go/Java） | `github.com/lich0821/WeChatFerry` |
| **ntchat** | Hook 类 Python 封装，接口友好 | `github.com/wechatpython/ntchat` |
| **chatgpt-on-wechat (CoW)** | 34K+ star，多模型可切（GPT/Claude/文心/讯飞等），接微信/网页/公众号，插件生态丰富 | `github.com/zhayujie/chatgpt-on-wechat` |

## 四、UI 自动化类 — 中等风险

不注入、不改协议，模拟人工操作微信窗口。

| 项目 | 能做什么 | 地址 |
|---|---|---|
| **wxauto** | 操作微信 PC 端窗口，发消息、读消息、加好友。**不注入进程**，相对安全，但微信 UI 改版即失效 | `github.com/cluic/wxauto` |
| **Wechaty** | "对话式 RPA SDK 瑞士军刀"，多语言多平台。协议可选：web（免费，易封）/ **PadLocal（付费 Token，稳）** | `github.com/wechaty/wechaty` |

## 五、平台级方案

| 方案 | 说明 |
|---|---|
| **Dify / n8n / 扣子** | 用 Webhook 桥接。微信侧出消息 → 转发 Webhook → 平台工作流处理 → 回调发送。需要上面某一层做微信适配 |
| **WeCom（企业微信）** | 唯一有官方连接器可用的，机器人推送/文档/日历/会议/通讯录。**不是个人微信** |

## 选型决策树

```
想自动收发 + AI 回复，且在乎账号安全
  └→ yuuouu/WeChat-Bridge（iLink 官方通道）

只想让 AI 读聊天记录做分析
  └→ wechat-cli / WeChatBridge（纯本地只读，零风险）

要在微信里遥控电脑上的 AI Agent
  └→ ClawBot + weclaw

要最全功能（朋友圈、群管理），小号可用
  └→ WeChatFerry / chatgpt-on-wechat

要商业级稳定性，能接受付费
  └→ Wechaty + PadLocal Token
```
