# 五层结构范式

> 来源：[[刘华赞]] 案例。可复制到任何人物。

[[00_方法总览|← 方法总览]]

```
00_原始导出     WeFlow 采集（json/md/txt + 联系人卡片 + 朋友圈）
01_关联证据     相关人会话中的提及（带上下文）
02_结构化分析   统计指标 / 消息表 / 证据链 CSV / 事件时间轴
03_报告         主报告 + 专题报告 + 速查卡
04_朋友圈媒体   朋友圈媒体下载
```

## 示例

[[刘华赞]] 完整走完五层：36 个文件，18 条可回溯证据链。
