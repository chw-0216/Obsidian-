二、常用 SQL（替代 WeFlow 的 API 查询）

连接 C:\Users\wardc\Desktop\_im_tmp\wechat-mcp\index.sqlite（只读）

-- ① 最近活跃会话 TOP15
SELECT session_key, COUNT(*), datetime(MAX(ts),'unixepoch','localtime')
FROM messages GROUP BY session_key ORDER BY MAX(ts) DESC LIMIT 15;

-- ② 关键词全文搜索（messages_fts 秒级）
SELECT session_key, datetime(ts,'unixepoch','localtime'), content
FROM messages_fts WHERE messages_fts MATCH '关键词' LIMIT 20;

-- ③ 某会话双方消息量
SELECT role, COUNT(*) FROM messages
WHERE session_key='wxid_xxx' GROUP BY role;

-- ④ 某会话某天消息
SELECT role, datetime(ts,'unixepoch','localtime'), content FROM messages
WHERE session_key='wxid_xxx'
  AND ts BETWEEN strftime('%s','2026-10-03 00:00:00')
            AND strftime('%s','2026-10-04 00:00:00')
ORDER BY ts;
字段含义
session_key对方 wxid ／ 群 xxx@chatroom ／ 公众号 gh_xxx ／ filehelper
tsUnix 秒
roleme / them / system —— 判发送方必须用这个，不是 sender
content正文

五、故障速查

症状处理
