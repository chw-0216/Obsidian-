04两条新规律

规律一 · 父亲手术与拟录取同周（见链 1）

这不是巧合能被忽略的量级——它解释了 P1 阶段 299 个事件里为什么「焦虑」密度那么高。

规律二 · 事件密度 ≠ 情感密度

导师 94 个事件，高负荷只有 1 条（纯事务接口）；沐茜妍 20 个事件，中高负荷 9 条（45%）。

中距离（师长/人脉）＝ 高事件密度、低情感负荷；近距离（亲密/前任）＝ 低事件密度、高情感负荷。 这与距离定律完全一致，也意味着：判「一段关系对你有多重」，看情感密度，不看消息量，也不看事件数。

07怎么用

# 读一个人（自动带出此人的事件 + 情感密度提示）

# 按人生阶段检索
python scripts/understand.py --stage P1

# 按因果链检索（自动归属到 5 条链之一）
python scripts/understand.py --chain 手术

# 列出 53 人（按距离半径分组）
python scripts/understand.py --list

# 事件源更新后重建事件层
python scripts/build_event_layer.py --events <新事件表>
