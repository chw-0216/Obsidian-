七、★ 技术坑（本轮新增）

坑说明
★★ extra_buffer 的标签字段是 ASCII 文本，不是字节列表field 30 ＝ \xf2\x01 + varint 长度 + "37,107"（逗号分隔的标签 ID 字符串）。误读成字节列表会得到 [51,55,44,49,48,55] —— 看起来像 ID，其实全是 ASCII 码（0x33='3' 0x2c=',' …）。校验法：解析出的 ID 若大量不在 contact_label 字典里 → 一定读错了。
contact.db 在子目录decrypted/contact/contact.db，不是 decrypted/contact.db。
chatroom_member 是数字 ID(room_id, member_id) → 需 join contact.id / chat_room.id，不能按 username 查。
WeFlow JSON 在各自子目录内私聊_XXX/私聊_XXX.json（不是顶层）。
WeFlow JSON 时间字段是 createTime不是 create_time。
sqlite URI 路径必须用正斜杠反斜杠会报 unable to open database file。
