二、三张结构图

1 · 归因转移（零距离专用）

对方发火
  → 归因为「他老了 / 无能 / 病中 / 计较 / 吝啬 / 没事找事」
  → 不是「对我的攻击」
  → 由「我有承受能力」承接
  → 不入伤害账本

2 · 隔离 + 填充（核心防御机制）

一条线出问题
  → ① 隔离：不让这条线的情绪污染其他线
  → ② 填充：空出来的情绪空间，用「对别人有用」的行动占满
  → 结果：多线并行 + 极强承受力 + 不承认受伤

3 · 资源闭环（本轮第一大发现）

缺钱 ──→ 够不到「值得的」（第二档）──→ 只能持有「将就的」（第一档）

  │                                            ↓
更缺钱 ←────── 网贷 ←────── 第一档的关系支出（性 / 泡妞）

不是「一次花超」，是在错误的档位上持续投入。

4 · 兜底是选择性的（Q12）

笔家里知道吗为什么
被骗十万多知道，帮着还他是受害者 → 说出来不丢人
3,000/月 泡妞超支不知道，他自己扛他是主动方 → 说出来丢人
 
被骗     → 受害者 → 不丢人 → 家里知道 → 家里兜底
泡妞超支 → 主动方 → 丢人   → 家里不知道 → 他自己扛

→ 信息隔离的依据不是「金额」，是「面子」 —— 十万（更大）能说，3,000/月（更小）反而不能说。

→ 即：只有「能被同情的」才进得了家里那条线。这是兜底机制的边界条件。
