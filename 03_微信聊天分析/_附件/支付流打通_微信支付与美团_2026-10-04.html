二、两个边界（必须先说清楚，否则数字会被误读）

边界 1：起点是 2025-08-01，不是更早。
公众号历史在微信侧只保留到 2025-08。2025-08 之前没有支付推送 —— 这不是「他没花钱」，是「数据不存在」。 和索引库「只有 2 年」是同一个原因，别重复踩。
边界 2：微信支付推送 ≠ 完整账单。
微信支付公众号只推特定场景：转账、收款、退款、部分商户支付。
扫码付款给个体户、线下小额、部分 App 内支付，多数不推。 所以 1,175 笔不是「他的全部消费」，只是「被推送的那部分」。

五、怎么把缺口补上（完整账单）

微信内推送只是子集。要完整账单，需要你自己在手机里导出一次，我再解析：

① 微信支付账单（最重要 · 含每笔商户名）

  1. 微信 → 我 → 服务 → 钱包 → 右上角 账单
  2. 右上角 常见问题 → 下载账单 → 用于个人对账
  3. 选时间范围（最长可选 1 年，建议分两次：2024-11~2025-10、2025-10~2026-10）
  4. 填一个邮箱 → 微信会发一封带解压密码的通知，压缩包发到邮箱
  5. 把解压出的 .csv 放到桌面文件夹，告诉我路径 → 我解析并入事件库

产出字段：交易时间 / 交易类型 / 交易对方 / 商品 / 收/支 / 金额 / 支付方式 / 当前状态 —— 这是真正的全量。

② 美团账单

  1. 美团 App → 我的 → 钱包（或「美团月付」）→ 账单 → 右上角账单导出
  2. 或「美团月付」→ 账单详情 → 可逐月截图/导出
  3. 导出文件给我 → 我并进来

③ 支付宝账单

  1. 支付宝 → 我的 → 账单 → 右上角 … → 开具交易流水证明 → 用于个人对账
  2. 邮箱收加密压缩包（密码在支付宝通知里）
为什么值得做：微信推送只有 2,207 条且缺商户名；微信账单导出是全量 + 每笔商户名， 能把「消费结构」（吃/交通/购物/学习/人情）真正跑出来 —— 这是目前事件库里唯一还缺的一块。
