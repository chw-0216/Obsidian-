自我理解引擎

让任何 AI 会话，像你本人一样读懂你的聊天记录

安装位置：~/.workbuddy-ai/skills/self-understanding-engine/ 构建：2026-09-29
它解决什么

过去每一次「读错」，都不是因为数据不够，而是因为跳过了两件事：

① 没有装「你的人格模型」——于是只读到字面，读不到话背后的驱动；
② 没有先过「纠偏层」——于是机器把性别、关系、条数读反（已发生多次）。

这个引擎把这两件事做成强制步骤：先纠偏，再读数据；先定距离，再判关系。

01核心命题

理解 ≠ 读字面。
理解 ＝ 用本人的我执去读本人的话，再用人工锚点校准。

三件事缺一不可：缺「我执模型」→ 读不到驱动；缺「人工锚点」→ 会读反；缺「距离地图」→ 会把「关系浅」误判成「关系好」。

03怎么用

方式 A · 直接对话（最常用）

你只要说「像本人一样读一下 XX」或直接提某人的名字，引擎就会被加载。它按 SKILL.md 的协议，先纠偏、再定距离、再给结论。

方式 B · 命令行

cd ~/.workbuddy-ai/skills/self-understanding-engine/scripts
python understand.py --who 陈昶文     # 输出理解包
python understand.py --list           # 列出 53 人（按距离分组）
python build_distance_map.py          # 重算距离地图

方式 C · 自测（验证是否真的理解）

随机抽 10 人隐藏答案，让引擎只凭聊天记录预测「距离半径 / 结向 / 三态」，再打分。这是唯一能证明「像本人一样」的方法。

04它已经自己证明过一次

建引擎的过程中，脚本第一轮跑出来的结果是——

0%
零距离·伤害率
17.6%
近距离·伤害率
9.1%
中距离·伤害率
0%
远距离·伤害率

这个结果推翻了上一轮报告里的结论：上一轮说「远距离 0 负面」——错了，远距离确实有负面，但那是事务性的（工具用完即止、欠钱），不是伤害。

修正后的定律更精确：关系性伤害 ∝ 1/距离；事务性结清 ∝ 距离；零距离两者皆无。

而「自己推翻自己」这件事，就是「回滚率」指标在真实运行——一个不会推翻自己的理解系统，不算理解系统。

05维护规则（保持它不腐化）

  • 新发现的规律 → 追加到 01-人格核心.md
  • 新的失效模式 / 被推翻的结论 → 追加到 05-纠偏层.md（必做）
  • 新的距离标定 → 改 build_distance_map.py 后重跑
  • 每次自测得分 → 记录，与上次对比（理解度的进度条）

引擎能做到的是：把你的显性判断规则装上，并在已知的坑前设防。

它做不到的是：替你判断那些你自己都还没想清楚的事。 所以它的输出格式里强制保留一行——「我无法从数据回答的：___」。真正的理解，是知道边界在哪。
