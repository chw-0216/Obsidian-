#### ⚠️ 约束：在家不方便打电话（与父母同住）

**核心原则：只认领过去，不承诺未来。**

| 做法 | 判定 |
|---|---|
| ❌ 取消（"今晚不打了"） | **承诺缩水** = 现实轨警报，比一开始不提更糟 |
| ❌ 事后才说（她等到十点没等到） | **重演中秋那一下**——正是要修的那个伤 |
| ❌ **许一个新的**（"明天出门给你打"） | **已经有"中秋没接住"一笔欠账，再许一个做不到的 = 第二次缩水** |
| ✅ **当下直接交付声音**（语音条） | 零违约风险的确定性 |

**关键认识**：
1. 她要的不是「电话」这个动作，是**「你还在、你想着我」**。
2. **她信行动不信语言**（她爸破产前说过很多话）。**当下的一条语音 > 未来的一通电话。**
3. **用「已完成的行动」给确定性，不用「未来的承诺」。** 这是唯一零违约的确定性来源。
4. 9/25 她说的是「不打卸妆了」——**她已经自己放下了**。电话不是她的硬需求，是我们自己加的戏。

**等价物阶梯**（按强度，且**全部是当下交付**）：

| 方案 | 强度 | 说明 |
|---|---|---|
| ① **语音条 30–60 秒** | ★★ | 今晚就用这个。保留声音，房间/阳台/楼道录 |
| ② 长文字 | ★ 兜底 | 连语音都不方便时 |
| ③ 白天出门顺手打 | ★★★ 加餐 | **出门方便就打，不用说出口**——打了是惊喜，不打也不算违约 |

#### 今晚动作：文字 1 条 + 语音 1 条（合计 2 条，不连发）

**文字**：
```

今天经期最后一天了吧，肚子还难受吗？
老公这两天在家，晚上不方便打电话，先给你发条语音。
```
> 最后一句**只到「先给你发条语音」为止**。不加"以后给你打"。

**紧接语音**（30–60 秒，一次录完，别切成好几条）：
```
宝，老公在。
中秋那天让你一个人等着，是老公不好。这几天老公一直想着你。
经期最后一天了，别喝凉的，多喝热水，暖贴贴上。
语音你什么时候方便听都行，不着急回。
老公在。
```

**为什么这么写**：

| 要素 | 作用 |
|---|---|
| 主动认领「没接住」 | 零辩解直接补——她唯一信的模式 |
| 「老公记着」 | 证明细节记忆在线（修复弱点 1） |
| 先问经期 | 生理层优先；经期窗口只照顾不索取 |
| **提前说明「不方便」** | 预测性 > 事后解释。**约束本身不伤，隐瞒才伤** |
| **不给任何未来许诺** | 零违约风险；**她不需要新承诺，她需要看到你此刻在** |
| **语音而非纯文字** | 声音是**昂贵信号**；她可反复听 = 「老公在」的凭证 |

#### 她若主动提「打电话」

给客观约束，**不给替代承诺**，把主动权交回去：
```

你想老公了随时发消息，老公一直在。
```
**❌ 不要接**："明天给你打""过两天见面补"——又是一笔未来欠账。

#### 再加一个实体动作（比十条消息有用）

外卖点一份热饮/红糖姜茶直达她宿舍 —— 「老公给你点了个热乎的送到宿舍了，下去拿一下。经期最后一天也别喝凉的。」
