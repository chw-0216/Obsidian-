# 笑一 · 唤醒协议与协同流程

> **一句话**：**你开始和她聊 → 喊一声 → 我出建议。**
> 相关：[[笑一-互动复盘模板与动作库]] · [[笑一-亲密动力学_欲望与给予的恢复路径]] · [[WeFlow更新部署方案]]

---

## 一、你要做的：就一件事 —— **喊一声**

| 唤醒词（任一即可） | 说明 |
|---|---|
| `唤醒` | 最短 |
| `看聊天` / `看聊天记录` | 直观 |
| `LIVE` | 英文 |
| `同步一下` / `更新聊天记录` | 旧习惯，同样识别 |

**不用多说一个字。** 不用告诉我她说了什么（我自己拉），不用说明背景。

---

## 二、我收到后做什么（固定 3 步）

1. 跑 `live.py`（**同步 + 解析 + 指标 + 红线**，一次完成，约 2 秒）
2. 直接给建议
3. 若涉及重要判断（道歉 / 推进 / 见面），自动调阅亲密动力学与复盘动作库

---

## 三、你会看到什么（固定格式）

```
现在发：<可直接复制发送的话>

她最后说了：<原文>
判断：<1-2 行>
⚠️ 别做：<本次红线>

备选：<如果她的反应是 X，就改成 Y>
```

**规则**：
- **第一行永远是「现在发什么」** —— 你不用在分析里找答案
- **≤25 行**
- 话术默认 **≤21 字、口语**（匹配你的语感）
- **只给一个方案 + 一个备选**，不给你菜单

---

## 四、三种场景分别怎么用

| 场景 | 你怎么做 | 我做什么 |
|---|---|---|
| **你主动开聊** | 先想好第一句，或喊我 | 给你**起手式**（最轻的那句） |
| **她先发了** | 喊我 | 读她的语气 → 给**接法** |
| **聊到一半卡住** | 喊我 | 判断当前状态 → 给**下一步** |
| **她不回** | 喊我 | 判断该等还是该补 → 给**时间与话术** |

---

## 五、我做不到的（诚实说）

| 限制 | 说明 |
|---|---|
| **不能自动感知** | 我无法"看到她发消息就主动推给你" —— 平台定时任务最短 **1 小时** |
| **必须你喊** | 所以「喊一声」这一步省不掉。但喊完 2 秒出结果 |
| **不读原文细节** | 我读的是结构化数据（发送方/时间/内容摘要），不是微信界面 |

**每小时自动跑一次**的兜底任务已建（你不看手机时用），但**实时协同靠喊**。

---

## 六、兜底：如果新会话没反应

新会话若没自动进入状态，直接发这一句：

```
唤醒。读 C:\Users\wardc\.workbuddy-ai\skills\wechat-data-forensics\SKILL.md 的「唤醒协议」章节，然后跑 live.py 给我建议。
```

---

## 七、协同流程全景

```
你和她聊天
    │
    ├─ 需要建议 ─→ 喊「唤醒」
    │                 │
    │                 ├─ live.py（2 秒：同步+指标+红线）
    │                 ├─ 判断状态（🟢🟡🔴）
    │                 └─ 输出：现在发什么（≤25 行）
    │
    ├─ 聊完一轮 ─→ 跑「复盘五问」→ 记进 [[笑一-互动复盘模板与动作库]]
    │
    └─ 每周日 ─→ 四项自检（她主动几次 / 我消失过吗 / 欠账推进 / 称呼退化）
```
