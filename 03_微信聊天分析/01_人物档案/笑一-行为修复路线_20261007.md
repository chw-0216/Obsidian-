## 零 · 病灶定论：两件事，顺序不能反

| 顺序 | 修什么 | 解决什么 |
|---|---|---|
| **1** | **让她重新感到「你听见我了」** | **情绪安全感** |
| **2** | **用一次兑现的实际见面，清掉「你说话不算数」** | **关系安全感** |

**修正后的公式**：

```
情绪修复 = 接住她
信用修复 = 兑现承诺
```

> **只做前者** → 她会觉得「**你越来越会哄我了**」，但**未必**觉得「**我可以相信你**」。
> **后者才是下一阶段真正要补回来的。**

### ⚠️ 收紧点 1：今晚不是「说一段完美的接住」，是「让她感觉到你在听」

> **如果你的病是「话说得太好」，那解药不是「说得更好」，是「说得更少」。**
>
> **那段「我后来想想当时没接住你」，不要当开场白 —— 当开场白就又成了一次主动表演。**
> **要在她开口之后，作为回应说出来。**

### 21:30 第一句（就这一句，然后等）

```

```

**不要连发。** 她没回也不要追。

### 她的三种反应 → 三套接法

#### A. 她开始讲（「还是那样」/「我妈又…」）

**三动作：复述事实 → 命名感受 → 站她这边。**

| 她说 | 你回 |
|---|---|
| 「我妈根本听不进去我说话」 | 「嗯，我大概明白你烦的是什么了。不是单纯吵了一架，是你明明想把意思说清楚，她却没在听你说什么」 |
| 「每次都这样，我真的烦死了」 | 「那确实挺消耗人的。尤其你已经很累了，还得一直证明自己到底是什么意思」 |
| 「我说我委屈，她说我在怼她」 | 「你不是在怼她，你是在说『你能不能听我说一句』」 |

**⚠️ 绝不说**：
- 「你妈就是控制欲太强」← **从「理解她」滑到「评价她妈」**
- 「她也是为你好」「你们两个性格都太强」「那你以后少跟她争」← 解决模式

**→ 她讲了之后，才说这段（注意：是"事后补"，不是开场白）**：

```
昨天你跟我说又跟妈妈闹了一顿、自己缓了半天
我后来想想，当时其实没接住你
你那时候不是要我讲道理，就是挺难受的
```

#### B. 她回「还行」「没事」

→ **不追问**。转轻的：「那就好 / 这两天别自己憋着」→ 22:30 前收。

#### C. 她回得很冷（「嗯」）或没回

→ **不追**。22:30 后补一条：「早点睡，老公在」。

### 收尾（她情绪稳定下来时）

```
那今天先不折腾你了
你想说的时候就跟我说，不想说也没关系
我至少现在知道，以后你说难受的时候，我不能再一句"别伤心了"就把你打发过去
```

> ⚠️ **这句只今晚说一次，之后永远不再说。**
> 它本身也是「语言」—— **说第二次就变成又一次透支**。

## 五 · ⚠️ 收紧点 2：不宣告的兑现（口红怎么处理）

**口红是「已经承诺的」，不是新饼 → 必须买。但处理方式要改：**

| ❌ | ✅ |
|---|---|

> 宣告 = 「你看我做到了」｜不宣告 = 「我本来就该做到」。
