# 笑一 · 互动复盘模板与动作库

> 复盘不是记流水账，是问「**哪一下有效、哪一下做多了**」。

## 一、复盘五问（每次互动后 5 分钟跑完）

| # | 问题 | 记录 |
|---|---|---|
| **1** | **她今天什么状态？** | 🟢 绿（享受） / 🟡 黄（压抑 Fawn） / 🔴 红（断连 Freeze） |
| **2** | **我做了什么 → 她怎么反应？** | 逐条记，每条标 ✅有效 / ⚪中性 / ❌无效 |
| **3** | **我做多了什么？** | 加码 / 追问 / 解释 / 跑题 / 补消息 |
| **4** | **谁收尾？** | 她收（好）/ 我收（中）/ 她消失（差） |
| **5** | **下一次只做的一个动作是什么？** | **只写一个。** 写清单 = 记流水账 |

### 三个判据（比感觉准）

| 判据 | 说明 |
|---|---|
| **称呼** | 老公 = 安全 ✅ ｜ 宝贝 = 照顾者模式 ⚠️ ｜ 无称呼 = 冻结 🛑 |
| **她是否主动** | 主动报备 / 主动邀约 / 主动提要求 = **有余力 = 安全** |
| **她是否设边界** | **能说"等一等"的顺从才是健康顺从**；Fawn 不会设边界 |

> ⚠️ **最容易误判的一点**：她安静 ≠ 她生气。
> 9/26 她「爱你」后 44h 没消息，不是冷，是**在等他出现**。

## 二、动作库 ✅ 值得复现（9/27 实证）

| 动作 | 为什么有效 | 证据 |
|---|---|---|
| **极短起手式** | 匹配你的语感（你平均 21 字/条），不暴露"在念稿" | 「宝 / 想你了」→ 秒回「我都想死你啦老公」 |
| **认领但不解释** | 认领给确定性；解释 = 找借口 | 一句「这两天没怎么跟你说话，是老公不好」即够 |
| **用行动代替语言** | 她信行动不信语言（她爸破产前说过很多话） | 给她打车 ＞ 说「我来接你」 |
| **她主动时立刻给强反馈** | **正强化比任何要求都有效** | 她示好 → 立刻接住 → 她继续加码 |
| **她设边界时立刻接受** | 接受边界 = 安全；追问 = 侵犯 | 「等姨妈走了的」→ 不接日期、不追问 |
| **温暖落地** | 收尾带一句"想你"，**收 ≠ 拒绝** | 「早点睡 老公想你想得不行」 |
| **先给情感，后给信息** | 她先要"你还在"，再要内容 | 先「老公在」，再说事 |
| **欲望出现时不追、不推** | 欲望是安全感的产物，推它就缩 | 她主动 → 你接住 → 她自己设边界 |

## 三、动作库 ❌ 需要避免

| 动作 | 为什么伤 | 今晚实例 |
|---|---|---|
| **长句 / 三段式** | 语感不符 = 一眼看出是模板 | 40+ 字 vs 你平时 21 字 |
| **模糊时间承诺** | 做不到 = 又一次缩水 | 「这两天去取」 |
| **反复问身体 / 情绪** | 问过 1 次就够；再问 = 没在听 | 今晚问了 **4 次**经期 |
| **她收尾后继续补消息** | 她得多回一条 = 消耗 | 她「晚安噢」后你又发 **3 条** |
| **跑题** | 她的问句没被接住 = 没被听见 | 她问口红，你答"合生汇馆子多" |
| **绕的表达** | 需要解释的话 = 无效沟通 | 「你不喜欢在床上等姨妈过去」→ 她回"什么" |
| **道歉第二次** | 把热度拽回"你欠我" | 认过一次就够 |

## 四、下一步：**通过什么，做什么**

### 4.1 渠道分工

| 渠道 | 用途 | 频率 |
|---|---|---|
| **微信文字** | 日常报备、轻互动 | 每天 1–2 条 |
| **微信语音** | 她情绪低落 / 想听声音 | 按需（**声音是昂贵信号**） |
| **实体行动** | 兑现欠账 | 按 4.3 清单 |
| **见面** | 一切身体与情感的修复 | **优先级最高** |
| **电话** | 出门方便时 | 不用说，**直接打**（打了是惊喜，不打不算违约） |

### 4.2 时间表

| 阶段 | 时间 | 做什么 |
|---|---|---|
| **恢复期** | 9/28 – 10/2 | 每天稳定报备；口红下单；能见就见；**零推进** |
| **靠近期** | 10/3 起 | 见面优先；**陪她逛**（她已邀约）；拥抱、牵手、不设目标 |
| **重启期** | 见面 2–3 次后 | 她主动时给强反馈；主导但不控制 |

### 4.3 欠账清单（**用行动还，不用语言还**）

| 欠账 | 紧急度 | 做法 |
|---|---|---|
| **口红** | 🔴 最紧 | **直接下单寄学校 + 发物流截图**（已完成行动，零违约） |
| **陪她逛** | 🟠 | 她 9/27 主动邀约 → **定时间**（她给的理由，别浪费） |
| **红糖姜茶囤货** | 🟡 | 8 月说过"回学校给你囤" |
| **妇科陪诊** | 🟡 | 让她定时间 |

### 4.4 每周自检（周日晚上，4 个问题）

1. 这周她**主动**了几次？→ 下降 = 安全感在掉
2. 我**消失**过吗？→ 超 24h = 危险
3. **欠账清单**有推进吗？
4. **称呼**有没有退化？（老公 → 宝贝 → 无称呼）

## 五、一句话

> **有效的重复，做多的删掉。**
> **一个动作改一次，一个月就是三十次迭代。**
