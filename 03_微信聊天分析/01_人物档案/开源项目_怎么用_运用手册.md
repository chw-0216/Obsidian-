## 二、最快见效的 3 个动作

### 🥇 1. 把 `visual-production` MCP 接进 WorkBuddy（10 分钟）

**为什么最值**：它已经装好了，是**印刷级**能力，直接服务植墨和井邻。

**它提供什么**：
| 工具 | 作用 |
|---|---|
| `inspect_image` | 读尺寸 / 格式 / alpha / 色彩空间 / DPI |
| `prepare_photo` | 自动定向、缩放裁切、色调、锐化、格式转换（**不覆盖原图**） |
| `render_svg` | 精确 SVG → PNG/JPEG/WebP/TIFF |
| `make_contact_sheet` | 带标签的评审联络表 |
| `export_print_pdf` | 尺寸化 RGB PDF 页面 |
| `validate_delivery` | **校验尺寸/比例/DPI/alpha/体积/印刷适用性** |

**怎么接**（在 `~/.workbuddy-ai/mcp.json` 加一段）：

```json
{
  "mcpServers": {
    "visual-production": {
      "command": "C:/Program Files/nodejs/node.exe",
      "args": ["C:/Users/wardc/Documents/New project gpt/AI-archive/apps/visual-production-toolchain/mcp/server.mjs"]
    }
  }
}
```

**⚠️ 重要限制**：`export_print_pdf` **只做 RGB 栅格页，不加出血、不加裁切标记、不输出 CMYK/PDF-X**。
真送印前，出血和裁切线要另做——但 `validate_delivery` 能帮你查出来。

---

### 🥈 2. 启动 Docker → WeKnora 上线（你只需点一下）

486 篇笔记变成可问答知识库。配 `mcp-remote` 桥接后，我在对话里就能直接查。

---

### 🥉 3. 装 `ntfy`（5 分钟，解决真实痛点）

你 10-08 还在问「20 号截止是当天晚上还是凌晨」——这类事不该靠脑子记。

`ntfy` 一行命令推送提醒到手机：
```bash
curl -d "中国银行网申今晚24点截止" ntfy.sh/你的私有topic
```
配合 `wechat-db` 自动扫截止日期 → 自动推送。

## 三、需要条件的（别硬上）

| 项目 | 卡在哪 | 出路 |
|---|---|---|
| `Trellis / Hunyuan3D / GVHMR` | **4GB 显存** | 走云端 API（硅基流动 / 混元） |
| `DS4 / Colibri`（本地推理） | 4GB 显存 + 5.3GB 内存 | ❌ 放弃，用 DeepSeek API |

| `Browser Use / OpenHands` | 需常驻环境 | 你已有 `agent-browser` 技能，重复 |
| `WeKnora` | Docker 引擎未启动 | 你双击 Docker Desktop |
