# 笑一 · 沟通原则（2026-10-05 起试行）

> **这份原则的来路**：由外部报告②提炼，但**逐条对照后确认——它讲的基本是体系里已有的原则，只是换了词汇**。
> 所以采纳方式是：**用体系的话执行，不用它的话思考。**
> 理由：**词会改变行为。** 你嘴里说「框架控制」，心里就会把她当对手；说「我来定结构」，你就会自然去做该做的事。

## 一、七条原则（生效中）

### ① 答她的问题，不是许新的愿
- **做法**：她问了 → 立刻答，答得**具体、真实、可落地**；她没问 → **一个字都不许诺**
- **反例**：❌「我以后天天陪你」　✅「今天老公在」
- **来源**：体系（9/27 零承诺）+ 报告②

### ② 框架你给，选项她挑
- **做法**：你定结构（几点 / 去哪 / 吃什么），她定选项
- **依据**：10-03 她婉拒「我来接你吧」（「我还没开始逛呢」）→ 她要的是**你在**，不是**你安排她**
- **反例**：❌「你想干嘛都行」——那是把选择压力推回给她

### ③ 认，不解释
- **机制**：**过度解释 = 踩下她的刹车。** 这是报告②最好的贡献，比「红线」好记
- **做法**：认 → 立刻转行动
- **反例**：❌「昨晚是因为……（三条原因）」　✅「昨晚睡着了，是老公不好。今天补上。」

### ④ 在场即价值，不靠许诺换关注
- 报告②叫「奖品性框架」，体系叫**「不缩水、不表演焦虑」**——**同一件事**
- **做法**：只提供「在场证明」，不填满她所有时间
- **本质**：你的时间与存在本身有价值，不需要靠加码来换她的注意力

### ⑤ 情绪截停，转实体动作
- **做法**：她说「算了」「不用了」→ **不追问为什么** → 给一个低压力实体动作（投喂 / 送东西过去）
- ⚠️ **但不要在心里把它读成「测试」**。她是**情绪退行**，不是博弈。读成测试，你就会开始反击——而她要的只是「你在不在」

### ⑥ 引而不发，先攒现实连接
- **阶段**：靠近期 → 重启期交界
- **做法**：见面第一动作 = **抱**；第一小时**纯情感**，不设目标
- **不接**角色扮演类话题（含「叫爸爸」——报告①提的，**报告②自己否了**）

### ⑦ 生理优先于道理
- 她情绪异常时，第一句不是「你怎么了」，而是：**吃饭了吗 / 昨晚几点睡的 / 是不是姨妈来了**
- **时段纪律**：12:00–15:30 可主导 · 16:00–18:30 只投喂 · 19:00–22:00 可升温 · 22:30 后只哄睡
- **两条铁律**：反嫌弃（亲完不漱口不洗手不消毒）· 经期（零性、零博弈、零推进）

## 二、翻译表：报告的词 → 体系的词

**执行时一律用右列。** 左列的词看着更有力，但会悄悄改掉你的姿态。

| 报告里的词 | 换成体系的话 | 为什么必须换 |
|---|---|---|
| 男性极性 / Alpha | **稳、不缩水** | 「极性」会把你变成一个表演者 |
| 框架控制 | **你来定结构** | 「控制」会把她变成对手 |
| 废物测试 | **情绪退行** | 「测试」会让你反击 |
| 奖品性框架 | **在场即价值** | 意思一样，但不物化她 |
| 激进主导性 | **温柔但坚定** | 「激进」会让你越界 |
| 挑逗性主导话语 | **松弛的玩笑** | 「话语体系」会让你背台词 |
| 间歇性奖赏 | **不把话说满** | 原推论自相矛盾（见纠错文件 §3.4） |

## 三、例外条款（唯一不采纳的部分）

1. **「叫爸爸」及一切未经验证的称谓引导 / 权力交换操演** → **不启用**。
   全库零实证；报告②自己也写了「不直接进入那份报告未经验证的称谓引导」。
2. **一旦发现自己是在「用技巧」而不是「用真心」→ 立刻回退到零技巧模式。**
   依据：9/27 只发一条「宝，老公在」，**28 分钟**后她主动「想让你亲亲抱抱举高高」。
   **她的欲望是被允许的，不是被激活的。**

## 四、今天（10/05）直接用第 ①②③⑤ 条

```
宝，昨晚那句老公看见了，一直记着。        ← ① 答问题 + ④ 在场
今天老公都在。
你想怎么过都行——中午去吃〔她提过的那家〕，或者下午你先睡够，老公去接你随便走走。
挑一个，剩下的交给老公。                  ← ② 框架你给，选项她挑
```

她若提昨晚没回 → **③ 认，不解释**
她若说「算了」 → **⑤ 情绪截停**：「那老公下午给你送点吃的过去」

## 五、复核点：2026-10-12

回头只问三个问题：
1. 哪几条**真的在用**？哪几条只是写着好看？
2. 有没有哪次是「用技巧」被识破的？
3. 有没有因为「主导」而越界（她拒绝过、你推过）？

> **试用期的判据不是"有没有效果"，是"你有没有变成另一个人"。**
