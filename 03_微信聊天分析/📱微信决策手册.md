## 🚀 一键更新（最常用）

```bash
cd "C:/Users/wardc/WorkBuddy AI/2026-09-26-19-38-06/wechat-analysis"

# 增量同步全部私聊（只拉新消息）
python sync_weflow.py

python sync_weflow.py --who 笑一

# 看所有会话列表（不下载）
```

## 🔧 手工调用（curl / PowerShell）

**健康检查**（无需 Token）
```bash
curl "http://127.0.0.1:5031/health"
```

**查会话列表**
```bash
curl -H "Authorization: Bearer wf-04eb74eee9324f5a918832b955384c25" \
  "http://127.0.0.1:5031/api/v1/sessions?limit=100"
```

**按名字搜会话**
```bash
curl -H "Authorization: Bearer $TOKEN" \
  "http://127.0.0.1:5031/api/v1/sessions?keyword=笑一"
```

**拉某会话消息**（`talker` 是 wxid 或 `xxx@chatroom`）
```bash
curl -H "Authorization: Bearer $TOKEN" \
  "http://127.0.0.1:5031/api/v1/messages?talker=wxid_wdnk6ue9kiyn22&limit=100"

# 按时间范围
curl -H "Authorization: Bearer $TOKEN" \
  "http://127.0.0.1:5031/api/v1/messages?talker=wxid_xxx&start=20260901&end=20260930"

# 关键词过滤
curl -H "Authorization: Bearer $TOKEN" \
  "http://127.0.0.1:5031/api/v1/messages?talker=wxid_xxx&keyword=想你"
```

**联系人 / 群成员**
```bash
curl -H "Authorization: Bearer $TOKEN" \
  "http://127.0.0.1:5031/api/v1/contacts?keyword=笑一"

curl -H "Authorization: Bearer $TOKEN" \
  "http://127.0.0.1:5031/api/v1/group-members?chatroomId=xxx@chatroom&includeMessageCounts=1"
```

**实时推送（SSE，新消息到达即推）**
```bash
curl -N -H "Authorization: Bearer $TOKEN" \
  "http://127.0.0.1:5031/api/v1/push/messages?access_token=wf-04eb74eee9324f5a918832b955384c25"
```
> ⚠️ 需先在设置里开 `主动推送`（配置项 `messagePushEnabled` 当前为 **false**）
> 事件类型：`message.new` / `message.revoke`（撤回也能抓到）

## 📋 接口全清单

| 接口 | 作用 |
|---|---|
| `GET /health` | 健康检查（免 Token）|
| `GET /api/v1/sessions` | 会话列表 |
| `GET /api/v1/sessions/:id/messages` | **会话消息（增量首选）** |
| `GET /api/v1/messages` | 按 talker 拉消息（支持时间/关键词过滤）|
| `GET /api/v1/contacts` | 联系人 |
| `GET /api/v1/group-members` | 群成员（可带发言数）|
| `GET /api/v1/push/messages` | SSE 实时推送 |
| `GET /api/v1/sns/timeline` | 朋友圈时间线 |
| `GET /api/v1/media/*` | 访问导出的图片/语音/视频 |

## ⚠️ 已知坑

| 坑 | 说明 | 解法 |
|---|---|---|
| `hasMore` 在恰好拿满时返回 false | 5,625 条但 limit=5000 时说"没有更多" | **别信 hasMore，看返回条数是否 < limit** |
| `since` 和 `offset` 混用会错乱 | 分页会跳 | 增量用 `since`，分页用 `offset`，**不要同时传** |
| 微信库加密 | 文件头非 `SQLite format 3` | **必须走 WeFlow API，不能直读 DB** |
| WeFlow 只读 | 无发送接口 | 能读不能写 → [[微信Agent通道决策]] |
| `-105 锚点漂移` | WeFlow 偶尔报错自愈 | 日志在 `AppData\Local\WeFlow_anchor_repairs.log`，会自己修 |
