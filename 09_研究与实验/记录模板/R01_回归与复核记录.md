# 回归与复核记录

对应[[09_研究与实验/实验/EXP-R01_记忆与纠正回归|记忆与纠正回归]]。复制空白区到一次运行目录；本模板不登记新实验ID，不将示范加入真实成绩。

## 一次运行的空白封面

| 字段 | 本次真实值 |
|---|---|
| run_id 与运行时间及时区 | 留空 |
| 资料与题集版本/哈希 | 留空 |
| 读取方案、工具/模型版本、参数 | 留空 |
| 文本预算与缓存/冷启动条件 | 留空 |
| 原始输入、输出与日志路径 | 留空 |
| 人工判定与复核状态 | 未判定 |

## 逐题记录字段

一行一个题目与方案：`case_id,category,world_as_of,known_as_of,expected_source_ids,actual_source_ids,answer_status,raw_answer_path,expected_constraints,observed_behavior,verdict,failure_type,elapsed_ms,reviewer`。

`verdict` 只用通过、失败、未实现、未执行、待人工核验。漏了接口参数用未实现；还没运行用未执行；不能把二者算为通过。`elapsed_ms` 未测时留空，不能写0。

## 虚构示范

以下仅说明填法，不是工具输出或实验通过证据。

| 字段 | 虚构值 |
|---|---|
| case_id / 方案 | DEMO-T02 / A |
| 输入 | 虚构甲2月获得证书，4月才录入；问3月系统当时是否知道 |
| world_as_of / known_as_of | 2024-02-02 / 2024-03-01 |
| 期望 | unknown；不得泄漏4月录入材料 |
| 假定观察 | 演示答案返回“已获证书”，引用4月才录入的C1 |
| 判定 | 演示失败：知识截止过滤缺失 |
| 证据路径 | 示例占位，未产生真实输出文件 |
| 下一步 | 检查 known_as_of 是否真正传给读取层，再用原题复跑 |

同一失败修复后的运行新增一行，不删除前次记录。若两个人判定不同，保留分歧及理由，先不合并为单一成绩。

## 持久复核事项空白记录

| 字段 | 本次真实值 |
|---|---|
| 队列item_id 与变化event_id | 留空 |
| 变化来源及旧新版本 | 留空 |
| 受影响页与完整依赖路径 | 留空 |
| 实际读到的差异 | 留空 |
| 人工结论 | 保留/修正/替代/信息不足，尚未选择 |
| 人工理由及证据定位 | 留空 |
| 是否需要改原页、由谁维护 | 留空 |

队列被ack仅表示记录了复核决定。原页修订、模型回答重跑及实验完成应分别记录。

## 汇总时保留分母

报告总题数、已执行数、未实现数、待核验数；再对有判定的题汇总。失败题列表、失效建议泄漏数及来源错配优先展示。工程单元测试数与24题问答成绩分别写。
