# 参与式美育变化记录

[[09_研究与实验/00_研究总览|研究总览]] · [[04_工作台/行动/ACT-R04_记录美育现场可核验变化|对应行动]] · [[09_研究与实验/记录模板/R04_变化与贡献记录|变化与贡献记录]]

把“活动做了什么”与“参与者后来有什么可观察变化”分开，判断项目可能贡献了什么，以及还有哪些解释。自主创作、分享方法、发起协作只是候选线索，不能预设活动一定带来改善。

## 用哪些现有材料

[[01_个人信息/项目/井邻乡村美育工作站|工作站原页]]与[[01_个人信息/项目/栗壳纪-植墨ZhiMo|植墨项目]]可以帮助理解活动形式、工艺与已有材料位置。本实验不重新估算历史收入、人数、运营状态或个人贡献，也不把旧活动照片补写成新的参与者变化证据。

起步只需要活动流程、空白变化卡、记录用途说明及一个可以被观察的问题。没有实际活动或自愿参与者时，可完成研究准备；不得虚构访谈填满表格。

## 先把三个层次分开

| 层次 | 可以记录的例子 | 不能直接推出 |
|---|---|---|
| 活动产出 | 完成一张印刷作品、进行了一个演示 | 之后会自主创作或持续参与 |
| 当下感受 | 参与者说喜欢、困难、想再尝试 | 已经提升能力或形成长期习惯 |
| 可观察变化 | 后来独立做了一个新方案，或实际向他人演示方法 | 全由本活动造成、对所有参与者都有效 |

每条变化以“谁在何时做了什么，与之前什么不同”开头；只有活动过程记录时就保留在产出层，不强行升级。

## 前30分钟怎样开始

1. **0至5分钟**：选一个窄问题，例如“参与者之后是否自行调整过图案或工序”。明确记录用于改进活动，不把宣传文案目标当作发现变化的标准。
2. **5至10分钟**：复制[[09_研究与实验/记录模板/R04_变化与贡献记录|变化卡]]，写活动代号、工艺环节和候选观察。身份先留空；不从旧聊天批量建立参与者名单。
3. **10至15分钟**：列三种可能结果：出现预期变化、没有变化、出现意外或负面变化。为每种写能支持它的最小记录，以及仍不能推出什么。
4. **15至20分钟**：写一段简短用途说明和三道中性问题；检查是否可拒绝、不影响正常参加，以及是否必须记录姓名、脸部或音频。默认只用代号和必要笔记。
5. **20至25分钟**：对模板中的虚构样例练习区分观察、参与者说法、项目解释及替代原因，标出一项还需核对的证据。虚构练习不计入实验样本。
6. **25至30分钟**：形成一张现场记录清单和可选后续核对方式。实际活动、邀请和联系时间留待本人安排；本页不代发消息或作出日程承诺。

完成准备后的下一步才是现场观察。优先从自愿成年体验者开始；如实际情境涉及未成年人，由组织方按场景完成必要同意后再决定是否采集，不能直接套用成年人的记录安排。

## 现场和后续怎样记录

现场先记录参与者是否有相关经历、想尝试什么及实际做了什么，不用“提高了多少”诱导回答。活动结束时可问：“今天哪一步是你自己做的决定”“哪一步仍需要帮助”“如果之后还想做，你会先做哪一步”。不想回答或不想继续也是有效记录。

若对方同意后续联系，另约一个双方方便的核对点，而不是自动设定某日回访。后续问“之后有没有做过与今天相关的事情；没有也可以”，并请对方描述具体行为与可用材料。只有意愿没有行动时记录意愿；没有回复记录失访，不解读为没有变化。

材料核对应限于对方自愿提供、与问题相关的作品或叙述。默认不复制通讯录、私人聊天长段或身份信息。身份对应表如确有需要，应独立保存在受控本地位置，研究页只放代号。

## 对照和替代解释

这轮不默认有随机对照组。先比较同一参与者活动前后在同一任务上的行为描述，同时保留原有经验、其他课程、家人协助、可获得材料、空闲时间等解释。不能因为随后发生了变化，就说活动造成了变化。

小型试点可主动保留三种案例：出现变化、未出现变化、变化与预期不同；不能只选择适合宣传的成功案例。如果将来确实能取得相近条件下未参加者的资料，另设计比较方式，不能现在补造对照组。

可邀请知情且未直接负责实施的人核对“一条变化描述是否有依据”；对方看到什么、没看到什么都写清。核对者的认可不是独立实验，也不会自动消除贡献判断中的不确定性。

## 判定和失败处理

| 情况 | 如何处理 |
|---|---|
| 只有照片或满意评价 | 可记活动产出/感受；不记持续行为变化 |
| 有具体行为但只有本人叙述 | 标本人报告，保留日期和可核对边界 |
| 新作品或明确过程记录可回查 | 描述该次观察到的行为，并检查其他解释 |
| 没有变化或对方不愿继续 | 原样保留；核对问题是否过大、任务是否可行 |
| 记录使参与者有负担或不适 | 停止记录，遵守已说明的退出和保留安排，不为补齐样本继续追问 |
| 多个材料都来自同一次讲述 | 记为一个来源根，不按照片、摘要和报告重复计票 |

计划交付三张能区分来源的变化卡、至少一种可信替代解释及下一轮的一个具体调整。三张是起步目标，不是已经取得的样本；如果没有三条可核对变化，就提交已有记录和覆盖缺口，不补造结果。
