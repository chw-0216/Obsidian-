# 可纠正版印肖像

[[09_研究与实验/00_研究总览|研究总览]] · [[04_工作台/行动/ACT-R02_验证数字人解释与纠正|对应行动]] · [[09_研究与实验/记录模板/R02_肖像纠正与观看记录|纠正与观看记录]]

先做能被纠正的回答卡，再决定是否接入3D外观或现场装置。研究问题是观看者能否分清“资料记录”“系统解释”和“未知”，并找到改变答案的入口。版印分层与修订痕迹是候选表达方式，尚未通过作品运行或观看记录检验。

## 已有材料和本次输入

[[01_个人信息/项目/交互数字人-版印肖像|原项目页]]记录已有概念图、模型和网页展示，完整交互尚未确认完成。本轮读取项目记录，不等于复跑或验证网页。最小实验可以用本地静态页面或纸卡，不以已有模型可运行作为启动前提。

准备20条公开或明确虚构的资料记录：5个对象各有旧版和修订版，共10条；另加4条带场景限制、3条明确转述、3条无关资料。这样有5个可核对的修订案例；记录条数不是独立来源数，也不是参与人数。公开网页只引用与问题有关的最小内容，起步优先全部采用虚构对象，不从私人聊天抽取人格语料。

| 输入卡字段 | 用途 |
|---|---|
| `source_id`、`revision`、`supersedes` | 保留身份、版本及替代链 |
| 记录内容、发生时间、录入时间 | 把何时发生与何时知道分开 |
| 来源类别和定位 | 区分本人声明、转述、观察与虚构资料 |
| 适用场景、已知限制 | 阻止局部事实扩写为固定人格 |
| 依赖回答ID | 纠正后知道哪些回答需要更新 |

同时准备四类提问：可直接回答、只能限定回答、存在冲突、资料中不存在。未知不是一个空白回答框，应说明缺哪项信息。

## 前30分钟怎样开始

1. **0至5分钟**：复制[[09_研究与实验/记录模板/R02_肖像纠正与观看记录|记录模板]]，声明资料集“全部虚构”；选一个问题，例如虚构创作者在某次协作中偏好哪种反馈方式。
2. **5至10分钟**：制作4张起步卡：一条旧记录、一条纠正、一条场景限制、一条无关资料。旧记录与纠正使用同一 `source_id` 不同版本，保留旧卡。
3. **10至15分钟**：画出一张回答卡的四个区：简短回答、状态标签、依据与时点、纠正入口。可先用纸卡；标签分别写“资料记录”“系统解释”“未知”，不能只用颜色区分。
4. **15至20分钟**：用同一提问走一次纠正前与纠正后，记录答案ID、依据版本和受影响卡。没有自动接口时明确标“人工演示”，不要称为自动纠正成功。
5. **20至25分钟**：增加一个无资料问题与一个冲突问题，写出应当保留的未知/冲突。若系统仍给确定事实，先保留失败回答，不加3D或语音包装。
6. **25至30分钟**：保存两张对照截图或纸卡照片及数据表，列出一个误导风险和下一步接口。此阶段只做自查，不自动邀请、预约或记录任何人。

起步卡通顺后再扩成20条资料与5条修订案例；四张卡的演示不能冒称已经完成20条测试。

## 功能测试和观看研究分别做

**功能层**：固定问题与输入，逐个触发5条修订。当前回答须绑定新版依据，历史答案能查到旧版但明确标时点；依赖回答若尚未重算，应显示待复核而不是继续当作当前事实。把“同路径仍可访问”与“新内容支持旧答案”分开检查。

**观看层**：A、B使用完全相同的回答内容和修订事实，只改变依据、时点和纠正入口的展示方式。A为简洁回答，B为分层可展开回答；先不要同时更换音色、头像、措辞和动画。可用A先B后、B先A后两种顺序，记录顺序影响；少量试用只用于发现误解，不作总体有效性证明。

自愿成年试用者只需完成三个任务：指出一句话凭什么成立；提交一处纠正；说明纠正后哪些回答应变化。问“你刚才如何判断”并原样记录，而不是问“是不是更可信”。身份用自选代号，默认不录脸和声音；是否记录或公开另行说明。

## 判断标准与停止点

| 观察 | 本轮判定 |
|---|---|
| 5条修订后的当前输出 | 逐条检查旧版确定事实泄漏，任一失败保留复现 |
| 无资料与冲突 | 能明确表达未知/冲突，不猜对象的隐藏动机 |
| 依据定位 | 能打开具体卡及版本；只有来源徽章不算完成 |
| 观看者的解释 | 能否指出依据、限定场景和纠正路径；保留不同理解与困惑 |
| 修订的可见性 | 观看者能否区分“事实变化”“旧记录纠错”“仍无定论” |

功能层未通过先停在回答卡；若观看者把系统解释理解为对象本人声明，修改标识和措辞后重新观察。展示更吸引人、语言更像本人，都不能单独作为“理解了本人”的证据。
