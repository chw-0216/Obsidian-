# 🔒 证件 / 个人文件目录（私密）

> 只记位置,不记号码。建议集中到一个加密私密文件夹。详见 [[证件清单-私密]]

## 证件位置（散落）
| 证件           | 位置                                                       |
| ------------ | -------------------------------------------------------- |
| 🪪 驾照(正面+侧面) | `桌面\驾照\`                                                 |
| 🆔 身份证       | `桌面\材料\`、`桌面\杂\新建文件夹(2)\`                                |
| 📕 护照        | `桌面\杂\新建文件夹(3)\护照信息`                                     |
| 🎓 学历证书/认证   | `桌面\材料\`(学历_格拉斯哥_… / 学历_首经贸_… / 国外学历认证书 / 学位在线验证)        |
| 🪪 证件照/头像    | `桌面\材料\`(原1/51/123.jpg→证件照_蔡浩文)、`桌面\头像\`、`5月17日\`(AI证件照) |
| 🧳 出入境/旅行    | `桌面\材料\出入境记录`、`桌面\杂\__MACOSX\`(保险/机票/酒店)                 |

## ⚠️ 隐私风险
`报名表`、`实习证明` 等文档**明文含身份证号/电话/住址**——建议归入私密文件夹,慎传云盘。
