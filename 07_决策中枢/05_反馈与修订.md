# 🔁 反馈与修订

> **三种反馈分开积累**：选择反馈（选了什么）· 理由反馈（为什么）· 结果反馈（发生了什么 + 你怎么评价）。

## 三行输入
```bash
python tools/decision_hub.py feedback "我选择了…" "我自己的理由…" "实际结果…"
```
