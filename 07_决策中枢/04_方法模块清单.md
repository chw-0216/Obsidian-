# 🛠️ 十个方法模块

> **按需调用**，不是每轮全跑。同一模型顺序执行即可，**不要求启动多个代理**。

## `M01` 来源与覆盖核对  `v1.0`
| 项 | 内容 |
|---|---|
| 调用时机 | 新资料 / 依据冲突 / 决策前刷新 |
| 必需输入 | 来源记录 · 原文定位 · 事件时间 · 别名 · 覆盖状态 |
| 输出 | 证据包 · 冲突 · 覆盖缺口 |
| 停止/降级 | 原文或媒体不可读时记录缺口，不由摘要代替核验 |
| 失效触发 | source_changed / source_unavailable / alias_corrected |
| 实现 | 已接通：读 analysis.sqlite + 索引库 + coverage_cursors |
| 研究引用 | refs: PROV-O · QUMem |

## `M02` 问题与系统边界  `v1.0`
| 项 | 内容 |
|---|---|
| 调用时机 | 目标有实质分歧 / 常规路线反复失效 / 需要改问题 |
| 必需输入 | 本人目标原话 · 时间窗 · 相关人 · 约束 · 可承受损失 |
| 输出 | 决策框架 · 成功条件 · 替代框架 |
| 停止/降级 | 目标与边界足够区分当前方案后结束；新框架保持候选 |
| 失效触发 | goal_changed / constraint_changed |
| 实现 | 已接通：读 decision_cases + decisions |
| 研究引用 | refs: SSM · CriticalSystemsHeuristics · Meadows · DecisionQuality |

## `M03` 当前自我理解  `v1.0`
| 项 | 内容 |
|---|---|
| 调用时机 | 问题需要个性化 / 本人理由或情境变化 / 本人纠正 |
| 必需输入 | 有条件理解 · 选择片段 · 本人理由 · 反例 · 当前资源 |
| 输出 | 当前状态 · 候选解释 · 理解增量 |
| 停止/降级 | 缺本人理由时保留候选；状态不自动升为永久人格 |
| 失效触发 | claim_corrected / new_counterevidence / context_changed |
| 实现 | 已接通：读 self_claims + choice_episodes（含理由覆盖率） |
| 研究引用 | refs: QUMem · StanfordSelfReportAgents · OpenLearnerModel |

## `M04` 现金日历与资源  `v1.0`
| 项 | 内容 |
|---|---|
| 调用时机 | 涉及新增支出 / 到账或到期支付 / 当前现金变化 |
| 必需输入 | 期初现金 · 已确认到账 · 必需支出 · 已核实到期应付 · 未知项 |
| 输出 | 按日期余额或未知 · 现金缺口 · 核查任务 · 预算额度或 null |
| 停止/降级 | 必要金额或日期缺失时输出信息不足，不输出可用约会额度 |
| 失效触发 | cash_changed / receipt_confirmed / payment_changed / due_date_changed |
| 实现 | 已接通：cash_items 按日投影 B(t) |
| 研究引用 | refs: BillCalendar · RobustDecisionMaking |

## `M05` 关系互动理解  `v1.0`
| 项 | 内容 |
|---|---|
| 调用时机 | 联系与见面决策 / 新的对方回应 / 关系目标变化 |
| 必需输入 | 本人目标 · 观察到的消息 · 共同安排 · 关系未知 · 当前约束 |
| 输出 | 可观察的互动状态 · 替代解释 · 条件式下一步 |
| 停止/降级 | 不输出隐藏动机、恋爱成功率或人格定论；无近期资料则状态未知 |
| 失效触发 | new_response / shared_plan_changed / user_goal_changed |
| 实现 | 已接通：按 talker 读索引库真实消息 |
| 研究引用 | refs: SSM · LongitudinalRelationshipQuality |

## `M06` 偏好澄清与信息价值  `v1.0`
| 项 | 内容 |
|---|---|
| 调用时机 | 方案取舍依赖关键未知 / 理解候选冲突 |
| 必需输入 | 候选方案 · 会改变决策的未知 · 已有回答 · 回答成本 |
| 输出 | 一个高价值问题或补证任务 · 条件分支 |
| 停止/降级 | 先查已有资料；未知已答且无新原因不重复问；补不齐就用条件分支 |
| 失效触发 | answer_received / unknown_resolved / options_changed |
| 实现 | 已接通：从 unknowns + learning_questions 排序出「一个」问题 |
| 研究引用 | refs: MAPLE · ValueOfInformation · ActiveInference |

## `M07` 资源组合与策略探索  `v1.0`
| 项 | 内容 |
|---|---|
| 调用时机 | 当前选项受限 / 希望创造新机会 / 需要不同路线 |
| 必需输入 | 已核实资源 · 现有手段 · 约束 · 可承受损失 · 真实合作承诺 |
| 输出 | 不同策略档案 · 新机会候选 · 未核实前提 |
| 停止/降级 | 资源和合作未确认时只提候选；不再产生可执行差异时结束 |
| 失效触发 | resource_changed / commitment_changed / constraint_changed |
| 实现 | 已接通：resource_records → strategy_candidates（文字档案，非算法） |
| 研究引用 | refs: Effectuation · MAP-Elites · POET · OMNI |

## `M08` 情景与反方检查  `v1.0`
| 项 | 内容 |
|---|---|
| 调用时机 | 比较候选 / 条件不确定 / 建议后果重要 |
| 必需输入 | 候选策略 · 硬约束 · 反证 · 情景条件 |
| 输出 | 可行性对比 · 失败条件 · 调整触发 · 最强反对理由 |
| 停止/降级 | 无概率依据则用情景；不把相关性、多模型赞同或单次结果当因果 |
| 失效触发 | assumption_changed / new_counterevidence |
| 实现 | 已接通：对每条 strategy 输出成立/失败/触发 |
| 研究引用 | refs: RobustDecisionMaking · CausalReasoning · DecisionQuality |

## `M09` 决策卡与共享阅读包  `v1.0`
| 项 | 内容 |
|---|---|
| 调用时机 | 需要当前建议 / 更换 harness / 读取改变 |
| 必需输入 | 当前状态 · 证据包 · 选项对比 · 依赖 · 方法版本 · 快照元数据 |
| 输出 | 决策卡 · 预测（可选，独立） · 阅读包 |
| 停止/降级 | 执行条件不满足时输出待核查；预测本人选择与建议行动分别呈现 |
| 失效触发 | dependency_changed / snapshot_stale |
| 实现 | 已接通：card + read_* 五个共享接口 |
| 研究引用 | refs: CoALA · ContextEngineering · AgentSkills · MCP |

## `M10` 反馈与方法修订  `v1.0`
| 项 | 内容 |
|---|---|
| 调用时机 | 本人实际选择与理由 / 现实回应或收支结果 / 重复遗漏或失效 |
| 必需输入 | 实际行为 · 本人理由原话 · 实际结果 · 既往预测 · 建议依赖 · 方法版本 |
| 输出 | 修订候选 · 有条件经验候选 · 受影响对象 · 方法修订候选 |
| 停止/降级 | 模拟不是结果；单次经验先保留候选；本人理由不由系统填写 |
| 失效触发 | outcome_corrected / user_reassessment |
| 实现 | 已接通：feedback 写 action_outcomes → 反查 rec_deps → 标待复核 |
| 研究引用 | refs: ReasoningBank · ACE · MemRL |

## 路由规则
| 路由 | 何时 | 顺序 |
|---|---|---|
| `lookup` | 查询资料 | M01 → M09 |
| `personal_decision` | 当前该怎么办 | M01 → M02 → M03 → M08 → M09 |
| `romance_and_cash` | 现金受限并希望发展关系 | M01 → M02 → M03 → M04 → M05 → M07 → M08 → M09 |
| `new_real_feedback` | 真实选择、本人理由、回应、收支变化 | M10 |
| `new_opportunity` | 需要创造不同选择 | M01 → M02 → M03 → M07 → M08 → M09 |

## 共享读取接口
| 接口 | 模式 | 输出 |
|---|---|---|
| `read_understanding` | 只读 | 当前状态 · 已知 · 未知 · 相关选择 · 变化 · 快照 |
| `read_evidence` | 只读 | 原文定位 · 摘录 · 覆盖 · 来源状态 |
| `read_changes` | 只读 | 变更对象 · 受影响建议 · 陈旧对象 · 游标 |
| `read_decision` | 只读 | 决策卡 · 依赖 · 方法版本 · 执行状态 |
| `read_methods` | 只读 | 模块契约 · 版本 · 限制 |
| `propose_revision` | 仅提案 | 修订提案 · 冲突 · 受影响对象（**未实现自动写回**） |

```bash
python tools/decision_hub.py read understanding
python tools/decision_hub.py read evidence 中秋
python tools/decision_hub.py read methods romance_and_cash
```
