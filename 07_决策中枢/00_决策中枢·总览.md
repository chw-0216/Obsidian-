## 三条循环
| 循环 | 内容 | 落点 |
|---|---|---|
| **理解循环** | 事实 / 本人理由 / 反例 → 有条件理解 → 本人纠正 | `self_claims` · `claim_evidence` · `choice_episodes` · `revisions` |
| **决策循环** | 问题与约束 → 选择 → 行动 → 真实结果 → 下一轮 | `decision_cases` · `strategy_candidates` · `action_outcomes` · `predictions` |
| **方法循环** | 分析哪里遗漏或出错 → 方法修订候选 → 积累后采用 | `method_versions` · `procedures` |

## 十个方法模块（按需调用）
| ID | 模块 | 触发 |
|---|---|---|
| `M01` | 来源与覆盖核对 | 新资料 / 依据冲突 / 决策前刷新 |
| `M02` | 问题与系统边界 | 目标有实质分歧 / 常规路线反复失效 / 需要改问题 |
| `M03` | 当前自我理解 | 问题需要个性化 / 本人理由或情境变化 / 本人纠正 |
| `M04` | 现金日历与资源 | 涉及新增支出 / 到账或到期支付 / 当前现金变化 |
| `M05` | 关系互动理解 | 联系与见面决策 / 新的对方回应 / 关系目标变化 |
| `M06` | 偏好澄清与信息价值 | 方案取舍依赖关键未知 / 理解候选冲突 |
| `M07` | 资源组合与策略探索 | 当前选项受限 / 希望创造新机会 / 需要不同路线 |
| `M08` | 情景与反方检查 | 比较候选 / 条件不确定 / 建议后果重要 |
| `M09` | 决策卡与共享阅读包 | 需要当前建议 / 更换 harness / 读取改变 |
| `M10` | 反馈与方法修订 | 本人实际选择与理由 / 现实回应或收支结果 / 重复遗漏或失效 |

## 五条路由
| 路由 | 何时 | 顺序 |
|---|---|---|
| `lookup` | 查询资料 | M01 → M09 |
| `personal_decision` | 当前该怎么办 | M01 → M02 → M03 → M08 → M09 |
| `romance_and_cash` | 现金受限并希望发展关系 | M01 → M02 → M03 → M04 → M05 → M07 → M08 → M09 |
| `new_real_feedback` | 真实选择、本人理由、回应、收支变化 | M10 |
| `new_opportunity` | 需要创造不同选择 | M01 → M02 → M03 → M07 → M08 → M09 |
