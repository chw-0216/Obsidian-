# 🧩 策略候选档案

> 保留**机制不同**的路线（MAP-Elites 思路），不只留一个赢家。**每类上限 3 条**。

## 关系行动

### `STRAT-ROM-1` 恢复真实交流（不依赖新增支出）
| 项 | 内容 |
|---|---|
| 机制 | 用真实近况或共有经历发起一次普通交流，观察是否自然往返 |
| 成立条件 | ① 有真实共有话题 ② 对方有回复渠道 ③ 不产生支出 |
| 代价 | ¥0 · 时间 每次 5–15 分钟 |
| 可承受损失 | 可承受损失＝0（无金钱投入） |
| 失败条件 | 对方只回单字且不再接话 → 降级为观察 |
| 调整触发 | 对方主动分享近况 / 提出替代时间 → 升级到「约定见面」候选 |
| ★ 最强反对 | 「普通交流」可能被读成试探，反而降低自然度 |
| 状态 | `candidate` |

### `STRAT-ROM-2` 在条件明确后安排一次预算内见面
| 项 | 内容 |
|---|---|
| 机制 | 先核实双方意愿与时间，再选一个低成本的共同活动 |
| 成立条件 | ① 双方都表示愿意 ② 时间明确 ③ 有已知预算上限 |
| 代价 | 待定（依赖 M04 输出） · 时间 半天 |
| 可承受损失 | 可承受损失上限待本人设定 |
| 失败条件 | 预算上限仍未知 / 对方未给出替代时间 → 保持候选不执行 |
| 调整触发 | 预算核实完成 或 对方主动提出时间 → 重新比较 |
| ★ 最强反对 | 预算未知就安排见面，等于用未知承担确定成本 |
| 状态 | `candidate` |

## 新路线

### `STRAT-NEW-1` 让作品与共同兴趣成为交流或收入入口
| 项 | 内容 |
|---|---|
| 机制 | 把摄影 / 艺术实践 / 共同兴趣同时当关系入口与收入入口 |
| 成立条件 | ① 对方对该领域真有兴趣 ② 作品可展示 ③ 活动当前存在且可负担 |
| 代价 | 视活动而定 · 时间 视活动而定 |
| 可承受损失 | 可承受损失上限待定 |
| 失败条件 | 活动已结束 / 对方无兴趣 / 超预算 → 换场景 |
| 调整触发 | 对方回应具体活动或主动提议 → 升级 |
| ★ 最强反对 | 把「共同兴趣」当既定事实，实际未核实 |
| 状态 | `candidate` |

## 现金行动

### `STRAT-CASH-1` 核实一笔已有应收（极狐返款 / 劳务费）
| 项 | 内容 |
|---|---|
| 机制 | 从既有返款或劳务费资料中挑一笔，核对是否仍有未到账款项、金额与缺失手续 |
| 成立条件 | ① 确有未到账款项 ② 有可执行的手续路径 |
| 代价 | ¥0 · 时间 1 次沟通 |
| 可承受损失 | 可承受损失＝0 |
| 失败条件 | 线索已结清 / 对方失联 → 标记 dead，换下一笔 |
| 调整触发 | 确认金额与到账日 → 转入 confirmed_receipt，重算现金日历 |
| ★ 最强反对 | 旧线索可能早已结清，核实本身不产生收入 |
| 状态 | `candidate` |

### `STRAT-CASH-2` 一项能交付的小服务（摄影 / AIGC / 剪辑）
| 项 | 内容 |
|---|---|
| 机制 | 用已有作品整理一项范围清楚、可报价的交付服务 |
| 成立条件 | ① 作品现成 ② 能说清交付物与周期 ③ 有获客渠道 |
| 代价 | ≈¥0（时间成本） · 时间 2–4 小时准备 |
| 可承受损失 | 可承受损失＝一次准备时间 |
| 失败条件 | 无客户承诺 → 不得计入预计收款 |
| 调整触发 | 出现真实客户询价 → 转入机会区并核实付款安排 |
| ★ 最强反对 | 「有作品」不等于「有订单」，作品集需先整理 |
| 状态 | `candidate` |

### `STRAT-CASH-3` 按日核对 30 天缺口，先处理最近一笔到期
| 项 | 内容 |
|---|---|
| 机制 | 用 B(t) 公式排出每日余额，定位最低余额日，优先处理最近到期项 |
| 成立条件 | ① 已核实的到期日与金额 ② 期初现金 |
| 代价 | ¥0 · 时间 30 分钟 |
| 可承受损失 | 可承受损失＝0 |
| 失败条件 | 生活必需支出未知 → 只输出缺口日，不输出约会预算 |
| 调整触发 | 新增到账 / 支出核实 → 重算 |
| ★ 最强反对 | 只算债务到期、不算生活费，会低估真实缺口 |
| 状态 | `candidate` |
