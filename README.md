## 使用与恢复

将本仓库克隆或下载解压后，在 Obsidian 中选择“打开本地仓库”，选中含有“🏠主页.md”的仓库根目录即可。可从“🏠主页.md”和“🤖AI接入说明.md”继续使用。

此归档只包含实际位于 Vault 目录内的文件。笔记中引用的库外照片、视频、微信数据库和分析数据库仍指向原设备位置，未随此次归档上传。GitHub 网页不会完整呈现 Obsidian 的双链、Base 或 Canvas 界面。
