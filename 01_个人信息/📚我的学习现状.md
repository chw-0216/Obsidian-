## 二 · 硬件交互线 · 进度明细

### ✅ 已掌握（10-09 课堂）

| 能力 | 说明 |
|---|---|
| **程序结构** | 全局变量 / `setup()`（跑一次）/ `loop()`（死循环）/ 自定义函数 |
| **数字输出** | `digitalWrite(pin, HIGH/LOW)` —— 只有 5V / 0V 两态 |
| **模拟输出** | `analogWrite(pin, 0–255)` —— PWM 模拟，**仅带 `~` 的脚**（3,5,6,9,10,11） |
| **语法常量** | `HIGH/LOW` · `INPUT/OUTPUT` · `true/false` |
| **引脚常识** | 0/1 是串口（**别接东西**）· 13 自带 L 灯（只做输出测试）· 2/3 外部中断 · A0–A5 可当数字 14–19 |

### ⚠️ 还没跑通（当前卡点）

| 卡点 | 严重度 | 说明 |
|---|---|---|
| **代码还没烧进过板子** | 🔴 | 环境搭好了但没验证 —— **先跑 13 号脚 Blink 确认「电脑→板子」通了** |
| **CH340 串口驱动没装** | 🔴 | 不装的话板子插上 IDE 端口菜单也是空的 |
| **按键接线错了** | 🟠 | 5V+GND 直连 → 按下短路；要改 `INPUT_PULLUP`（见课程笔记第七章） |
| **串口调试 `Serial.print`** | 🟠 | **最大缺口** —— 嵌入式没有屏幕，串口是唯一的"眼睛" |
| **`analogRead` 模拟输入** | 🟡 | 所有传感器（光敏/电位器/压力）的必经之路 |
| **库的用法** | 🟡 | Library Manager + `#include` —— ESP32 项目几乎全是调库 |
