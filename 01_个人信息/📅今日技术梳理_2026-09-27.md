## 三、踩过的坑（技术含量最高的一段）

| 坑 | 解法 |
|---|---|
| `dsh plugin` 找不到 pnpm | 用 DSH 自带 pnpm 做 shim（`_im_tmp\bin\pnpm.cmd`） |
| 插件版本兼容 | dsh-im 声明 `0.1.7-alpha.1`，本机 `0.1.7-rc.2`，**无需豁免**即通过 |
| `!!js` 在 profile patch 里不可用 | overlay 解析器不认，改用**单引号字面路径** |
| 顶层 `id:` 加不了新条目 | 只能改已有条目；新增必须 `- insert: [...]` |
| **FTS5 中文搜不到** | `unicode61` 不支持 CJK 子串 → 换 **`trigram`**（≥3 字） |
| 2 字中文词搜不到 | trigram 最少 3 字 → MCP 对 <3 字查询**自动改走 LIKE** |

### 三个待办（README 里你自己写的）
- [ ] **开机自启**：网关目前手动启动，重启电脑要重跑 Start 脚本
- [ ] **桌面端（19387）没有 IM 面板**：dsh-im 只装在 web profile
- [ ] **白名单只有你**：多人用需加名单

### 一个提醒（安全）
微信背后的 Agent **有本机 pwsh + 文件读写权限，还能读 15 万条聊天记录**。
白名单（`workspaces.json`）是第一道也是最重要的一道闸门——**不要加不认识的人**。
MCP 索引是**只读**的，Agent 查得到、改不了。

### 建议
1. **加开机自启**（最实际的痛点，否则每次重启都要手动拉起）
2. 把 `刷新微信索引.cmd` 加进你的日常流程（索引是快照，不自动更新）
3. 考虑给 MCP 加一个「时间范围」参数默认值，避免 Agent 一次拉太多
