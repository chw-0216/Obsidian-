# 软硬件清单与项目标注（2026-10-22 实测）

> [!important] 一句话
> **一台 Dell G15 5520**（i7-12700H / 16GB / RTX 3050 **4GB** / 512GB，C 盘余 **30.7GB**）+ **荣耀 X60 Pro**（机型级确认，具体容量未实测）。

### 这台机器的能力边界

| 判断 | 内容 |
|---|---|
| ✅ 稳定 | Web 3D 实时（Three.js / WebGL）· 1080×1920 竖屏预演渲染 · Blender 中小场景 · TouchDesigner 实时音画 · 1080p 剪辑与包装 |
| ⚠️ 吃力 | Blender Cycles 大场景 · 4K 长片 · TD 多路高分辨率 · Adobe 全家桶 + 浏览器 + 3D 软件同开（16GB 内存 / C 盘 30GB） |
| ❌ 不要指望 | 本地文生视频 / 大模型推理（4GB 显存）· Unreal 级实时大场景 · 8K 素材长期驻留 C 盘 |
| ☁️ 云端补足 | **Hyper3D**（3D 生成）· 其他 API 生成服务 |

> 经验：视频与素材别放 C 盘；导出前先清 Adobe 缓存。C 盘当前 30.7GB 够一次 20 秒竖屏导出，不够长时间 4K 工程。

### 标注约定（以后新页照这个写）

**状态四档**（只认证据，不认“应该装了”）：

| 标记 | 含义 |
|---|---|
| ✅ 已用并验证 | 有产物、运行记录或截图 |
| 🟡 已装未验证 | 装了，但本轮没有项目使用证据；或配置好了没跑通 |
| ⬜ 计划 / 待装 | 打算用，尚未安装或尚未开始 |
| ❌ 不适用 / 未安装 | 明确没有，或这台机器做不了 |

**页内写法**：项目页 frontmatter 加 `hardware:` / `software:` / `status:`，正文用 `#软硬件` 标签；涉及具体版本时写版本号，别写“最新版”。

**三条红线**：
1. **公开规格 ≠ 本机实测** —— 手机容量、电池健康这类必须标证据等级。
2. **已配置 ≠ 已用** —— Hyper3D 就是例子：OAuth 完成不等于生成过。
3. **不记录序列号、MAC、IP、账号** —— 本页只到机型 / 版本级。
