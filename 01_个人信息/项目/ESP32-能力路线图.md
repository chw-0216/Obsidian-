# ESP32 能力路线图 · 距离评估

> 起点：2026-10-09（中传交互技术课第 3 次课，刚学完数字/模拟输出）
> 用途 → [[交互数字人-版印肖像]]「从屏幕走到装置」· [[朗园-mediapipe_td]] · [[双手成曲-GestureSynth]]

---

## 一 · 结论先说

| 目标 | 距离 | 说明 |
|---|---|---|
| **点亮 ESP32 + 连上 WiFi** | **1 周内** | 环境搭好当天就能做到，不需要任何新知识 |
| **做一个能用的 ESP32 项目**（传感器 → WiFi → 电脑） | **3–5 周** | 主要卡在「串口调试」和「库的用法」 |
| **部署成作品级装置**（长跑稳定、可展） | **2–3 个月** | 难点不在代码，在**供电、外壳、稳定性** |

**核心判断：你比你想的近得多。**
因为 ESP32 项目是「硬件一半 + 软件一半」，而**软件那一半你已经会了** ——
TouchDesigner / MediaPipe / Unity / Python 这套栈，正是 ESP32 最常对接的上位机。

## 二 · 能力盘点（已有 vs 缺口）

### ✅ 你已经有的

| 能力 | 来源 |
|---|---|
| Arduino 程序结构（setup/loop） | 10-09 课堂 |
| 数字输出 / 模拟输出（PWM） | 10-09 课堂 |
| 引脚常识（0/1 别用、13 自带灯、`~` 才 PWM） | 10-09 课堂 |
| **上位机软件栈**（TouchDesigner / Unity / Python / MediaPipe） | 已有项目 |
| 视觉与装置审美（央美训练） | 本行 |

### ⚠️ 缺的三块（按优先级）

| # | 缺口 | 为什么关键 | 补法 |
|---|---|---|---|
| **1** | **串口调试 `Serial.print`** | 嵌入式没有屏幕 —— 串口是**唯一的"眼睛"**。ESP32 项目出问题 90% 靠它定位 | 半小时就能学会，但必须练成习惯 |
| **2** | **库的用法**（Library Manager + `#include`） | ESP32 项目**几乎全是调库**：WiFi.h / WebServer.h / ArduinoJson / FastLED | 会装库 + 会看示例，就够用 |
| **3** | **模拟输入 `analogRead`** | 所有传感器（光敏/电位器/压力）都走这条路 | 课堂上应该就会讲 |
| 4 | 3.3V 电平概念 | ESP32 是 **3.3V**，接 5V 信号可能烧 | 记住一条规则即可（见下） |

## 三 · ESP32 与 Arduino Uno 的真实差异

| 维度 | Arduino Uno | ESP32 |
|---|---|---|
| 逻辑电平 | **5V** | **3.3V** ⚠️ 接 5V 传感器要加电平转换 |
| 核心卖点 | 学接线 | **自带 WiFi + 蓝牙** |
| 引脚 | 20 个 IO | 30+ 个，但**有坑**（见下） |
| 供电 | USB 直接够 | **电流需求大**，电机/灯带要外接电源 |
| 难度定位 | **接线的课** | **联网的课** |

**ESP32 特有的坑（提前知道能省很多时间）**：

1. **只有部分引脚能做 ADC / PWM** —— 不是所有脚都通用（Uno 上没这个问题）
2. **ADC2 与 WiFi 冲突** —— 开着 WiFi 时 ADC2 引脚读不了（要改用 ADC1）
3. **Strapping 引脚**（GPIO 0/2/12/15）上电时电平会影响启动模式 —— 别在这些脚上接会拉低的东西
4. **3.3V** —— 5V 传感器输出直连会烧；反过来 ESP32 输出 3.3V 通常能被 5V 器件识别为高电平（勉强能用）
5. **开发板支持包要手动加 URL** —— Arduino IDE 里默认没有 ESP32，网络不好时会卡住

## 四 · 推荐的第一块 ESP32 项目（直接对标数字人）

> **「物理信号 → 电脑 → TouchDesigner」最小闭环**

```
[传感器] → ESP32 ──WiFi──> [电脑上的 Python/OSC 服务] → TouchDesigner → 视觉反馈
```

**为什么是这个**：
- 它把你**已经会的两半**（物理硬件 + 上位机视觉）第一次连起来
- 做完这一个，你就掌握了 ESP32 项目的**全部骨架**（读传感器 / 联网 / 发数据 / 电脑端接收）
- 之后的任何装置，都是在这套骨架上换传感器、换协议

**极简版路径**：
1. ESP32 读一个电位器 → `Serial.print` 看到数字变化（不联网）
2. 换成 `WiFi.h` → 连上家里 WiFi → 串口打印 IP
3. 电脑开一个 Python UDP/OSC 监听 → ESP32 把数值发过去 → 电脑打印
4. 把 Python 收到的数值喂给 TouchDesigner

## 五 · 硬件清单（需要买）

| 件 | 参考价 | 备注 |
|---|---|---|
| **ESP32 开发板** | ¥20–40 | 推荐 **ESP32-DevKitC** 或 **NodeMCU-32S**；买**双核带 WiFi+BT** 的经典款即可，不要一上来买 S3/C3 变种 |
| USB 数据线 | — | ⚠️ 必须是**数据线**不是充电线（很多人卡在这） |
| 面包板 + 杜邦线 | ¥10 | 已有 |
| 电位器 / 光敏电阻 / 按钮 | ¥5–15 | 练手用 |
| （可选）传感器套件 | ¥30–60 | 温湿度 DHT11/22、超声波、人体红外 |

> ⚠️ **CH340 驱动**：很多国产 ESP32 板也用 CH340 串口芯片 —— 本机**还没装**，
> 不装的话 IDE 端口菜单会是空的。http://www.wch.cn/downloads/CH341SER_EXE.html

## 六 · 建议的推进节奏

| 周 | 做什么 |
|---|---|
| **本周** | ① 跑通 Uno 的 Blink（确认「电脑→板子」这条路通）② 装 CH340 驱动 ③ 把按键按正确接法重接 |
| **下周** | 学 `Serial.print` + `analogRead`（读电位器）—— 这两样是后面一切的基石 |
| **第 3 周** | 买 ESP32；装板支持包；点亮板载 LED + 串口打印 WiFi 扫描结果 |
| **第 4–6 周** | 做上面那个「物理信号 → TouchDesigner」闭环 |
| **之后** | 按项目需要深入（MQTT / WebSocket / 深度睡眠 / 电池供电 / 外壳） |
