## 二 · Arduino 程序骨架（背下来）

每一个 Arduino 程序（叫 **sketch**）都由这四块组成：

```arduino
// ① 全局变量 —— 整个程序哪里都能用
int ledPin = 13;

// ② setup() —— 只运行一次（通电或按复位时）
void setup() {
  pinMode(ledPin, OUTPUT);
}

// ③ loop() —— 死循环，永远重复
void loop() {
  digitalWrite(ledPin, HIGH);
  delay(1000);
  digitalWrite(ledPin, LOW);
  delay(1000);
}

// ④ 自定义函数 —— 把常用代码打包，需要时调用
void blinkOnce() { /* ... */ }
```

**老师的「快餐店」类比**（这是理解 setup/loop 最省力的方式）：

| 代码 | 快餐店 | 说明 |
|---|---|---|
| `setup()` | **开店前的准备** | 打扫卫生、备料、开门 —— **只做一次** |
| `loop()` | **日常营业** | 迎客 → 点单 → 收费 → 等下一个 —— **反复做** |

> ★ 最容易被忽略的一点：`loop()` 跑完最后一行，会**自动立刻跳回第一行**重来，不需要你写任何"循环"语句。

## 三 · 输出：数字 vs 模拟

| | **数字输出 Digital** | **模拟输出 Analog** |
|---|---|---|
| 像什么 | **开关** —— 开 / 关 | **调光旋钮** —— 可大可小 |
| 值域 | 只有两个：`HIGH`(5V) / `LOW`(0V) | 0 ~ 5V **连续**变化 |
| 代码 | `digitalWrite(pin, HIGH/LOW)` | `analogWrite(pin, 0~255)` |
| 可用引脚 | 全部数字脚 0–13 | **只有带 `~` 的脚**：3, 5, 6, 9, 10, 11 |
| 典型用途 | 灯亮/灭、蜂鸣器响/停、警示信号 | LED 调光（呼吸灯）、马达调速 |
| 生活例子 | 卧室吸顶灯：按一下亮、再按一下灭 | 台灯旋钮：微亮 / 半亮 / 全亮 |

**⚠️ 关键真相：Arduino Uno 没有真正的模拟输出。**
它用的是 **PWM（脉宽调制）** —— 让引脚以极高频率**快速开关**（比如亮 0.5ms、灭 0.5ms），
灯泡因为"视觉暂留"看起来就是半亮。所以 `analogWrite` 是**"假装"**出来的模拟输出。

- `analogWrite(pin, 0)` = 全关（0V）
- `analogWrite(pin, 255)` = 全开（5V）
- `analogWrite(pin, 128)` ≈ 半亮

## 四 · 引脚资源全表（避坑用）

Arduino Uno 一共 **20 个可用 IO**：14 个数字（0–13）+ 6 个模拟（A0–A5）。

| 引脚 | 能力 | 注意 |
|---|---|---|
| **0 / 1** | 数字 IO + **串口 RX/TX** | ⚠️ **别接任何东西** —— 上传程序走的就是这两个脚，接东西会导致上传失败 |
| **2 / 3** | 数字 IO + **外部中断** | 按键首选（响应最快） |
| **3, 5, 6, 9, 10, 11** | 数字 IO + **PWM（`~`）** | 需要调光 / 调速时用 |
| 4, 7, 8, 12 | 普通数字 IO | 随便用 |
| **13** | 数字 IO + **板载 L 灯** | 测试首选（不用接线就能看效果）；**别当输入用**（板上自带灯和电阻会干扰读数） |
| **A0–A5** | **模拟输入**（读 0–1023）+ 数字 IO（代码里当 **14–19**） | 接传感器（光敏、电位器、压力…） |

**🔋 电流限制（很重要）**：每个引脚当输出时**绝对最大 40mA**，**安全建议 ≤ 20mA**。
- 带得动：一个小 LED（**必须串电阻**）、小蜂鸣器
- 带不动：马达、继电器、长条 LED —— 这些要另配驱动

## 五 · 语法常量与常用函数

### 常量（"单词本"）

| 常量 | 含义 | 大白话 |
|---|---|---|
| `HIGH` | 高电平（5V / 1） | 通电 |
| `LOW` | 低电平（0V / 0） | 断电 |
| `INPUT` | 输入（高阻态，只"听"不干扰） | 当**耳朵** |
| `OUTPUT` | 输出（能提供 5V / 40mA） | 当**嘴巴** |
| `true` | 真（1） | 对的 |
| `false` | 假（0） | 错的 |

> 小知识：在 Arduino 里**除了 0 是假，其他任何非零数**（1、-1、100…）都算真。

### 常用函数

| 函数 | 作用 | 用在哪 |
|---|---|---|
| `pinMode(pin, mode)` | **定岗位** —— 声明引脚是输入还是输出 | `setup()` |
| `digitalWrite(pin, HIGH/LOW)` | **发指令** —— 输出高低电平 | `loop()` |
| `digitalRead(pin)` | **读状态** —— 读引脚是 HIGH 还是 LOW | `loop()` |
| `analogRead(pin)` | 读模拟电压 → 转成 **0–1023** | `loop()` |
| `analogWrite(pin, 0–255)` | PWM 输出（**仅 `~` 脚**） | `loop()` |
| `delay(ms)` | 等待 N 毫秒（1000 = 1 秒） | 任意 |

> **要不要定义 `pinMode`？**
> - **输出（OUTPUT）：必须写** —— 不写引脚默认是输入，灯不会亮
> - **输入（INPUT）：强烈建议写** —— 引脚出厂默认就是输入，理论上能省，但写清楚更稳、更易读
> - **规矩：只要用到的引脚，全部在 `setup()` 里 `pinMode()` 一遍。**

## 六 · 两个可直接用的代码模板

### 模板 A · Blink（不用接任何线，测板子）

```arduino
int ledPin = 13;              // 13 号脚自带小灯

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH); // 亮
  delay(1000);
  digitalWrite(ledPin, LOW);  // 灭
  delay(1000);
}
```

### 模板 B · 按键控灯（内部上拉，最简接法）

```arduino
const int buttonPin = 2;      // 按键接 D2
const int ledPin    = 13;     // 板载小灯

void setup() {
  pinMode(buttonPin, INPUT_PULLUP);  // 开启内部上拉电阻
  pinMode(ledPin, OUTPUT);
}

void loop() {
  if (digitalRead(buttonPin) == LOW) {  // 按下 = 低电平
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}
```

## 七 · ⚠️ 我的接线错误（必读，别再犯）

### 错在哪

课上我第一次接按键，**把按键两端直接接在 5V 和 GND 上**，结果：

| 问题 | 后果 |
|---|---|
| ❌ **缺少信号线** | 按键没接到数字引脚，Arduino 根本读不到 |
| ❌ **按下就短路** | 5V 和 GND 被按键直接导通 → 可能重启 / 发烫 / **烧板子** |
| ❌ **缺少上拉/下拉电阻** | 引脚悬空 → 读数乱跳 |
| ❌ **按键没跨过面包板中槽** | 4 脚开关同侧两脚内部导通 → 若接在同侧会**永远导通** |

### 正确接法 · 方案一（推荐：内部上拉）

**不用额外电阻，只改 3 处：**

1. **拔掉接在 5V 上的那根红线**（防短路，第一步就做）
2. 按键**跨过面包板中间的凹槽**插好
3. 按键一端接 **GND**，另一端接 **D2**（数字引脚）
4. 代码里写 `pinMode(2, INPUT_PULLUP);`

**原理**：内部上拉 → 平时引脚是 `HIGH`，**按下变 `LOW`**。

### 正确接法 · 方案二（经典：外部下拉）

1. 按键一端接 **5V**
2. 另一端接 **D7**，同时这一端再经一个 **10kΩ 电阻**接 **GND**
3. 代码里写 `pinMode(7, INPUT);`

**原理**：10kΩ 下拉 → 平时引脚是 `LOW`，**按下变 `HIGH`**。

### 4 脚轻触开关的物理常识

> 4 脚轻触开关：**同一侧的两个脚内部是连通的**；左右两侧之间**只有按下时才连通**。
> 所以插在面包板上时**必须跨过中间凹槽** —— 这样左右两侧才落在**不同的行**，成为两个独立节点。

## 八 · 理论延伸：香农（数字电路的鼻祖）

**克劳德·香农（Claude Shannon）** —— 1937 年，21 岁的硕士论文
《继电器与开关电路的符号分析》：

> **电路的「开/关」，正好对应布尔代数的「真/假（1/0）」。**

- 两个开关**串联**（都开才亮）= 逻辑 **AND（与）**
- 两个开关**并联**（开一个就亮）= 逻辑 **OR（或）**

→ 从此电路设计可以用**数学公式**推导，不用再靠经验试错。
→ 这就是 `HIGH/LOW`、`digitalWrite` 背后的理论根基。

> 补充：1948 年他又创立了**信息论**，提出 **bit（比特）** 概念 —— 互联网、5G 的基础。
> 所以他是**"数字电路鼻祖" + "信息论之父"**双重身份。
