## 三、逐个怎么用

### 1️⃣ wechat-db（最值的一个）

**它连了两个库，都是只读**：

| 工具名 | 数据 |
|---|---|
| `execute_sql_wechat` | 微信全量索引 **337,456 条 / 1,821 会话** |
| `execute_sql_analysis` | 分析库 **71,550 条 / 725 会话 / 6,303 片段** |

**安全设置**：`readonly = true`（禁写）+ 最多返回 500 行。**它改不了你的微信数据。**

**怎么用 —— 直接说人话就行**：

```
用 SQL 查一下我和「米雪」最近的 20 条聊天
```
```
在微信数据里统计：我 9 月转了哪些技术类内容
```
```
分析库里有几个会话？各自的片段数是多少？
```

**想自己写 SQL 也行**（它知道表结构）：
```
查 execute_sql_wechat：select display_name, message_count from sessions order by message_count desc limit 20
```

**表结构**（备用）：
- `messages`：id / session_key / ts / time_text / role / sender / type / content
- `sessions`：talker / display_name / session_type / is_channel / message_count / first_ts / last_ts

**⚠️ 注意**：索引是**快照**，不自动更新。要查最新聊天，先双击
`C:\Users\wardc\Desktop\_im_tmp\wechat-mcp\刷新微信索引.cmd`

---

### 2️⃣ context7

**怎么用**：提问时**明说「用 context7 查」**，命中率最高。

```
用 context7 查一下 Next.js 15 的 app router 最新写法
```
```
用 context7 查 React 19 的 use() hook 怎么用
```

**原理**：它去抓**当前版本**的官方文档，而不是靠模型记忆。

---

### 3️⃣ memory

**怎么用**：让它记住东西，或问它记得什么。

```
记住：植墨项目的核心是「植物染料丝网版画 + 怀柔文旅」
```
```
你还记得植墨项目的方向吗？
```

**数据存哪**：本地 JSON 文件（知识图谱结构），**不上传**。

> 💡 适合存「项目结论、长期偏好」；短期任务不用它。

## 四、「清理后才能做」的是什么（简单说）

> [!warning] 已更新（2026-09-27 21:44 实测）
> 下面这段**已过时**。实测发现 **WeKnora 已经部署到配置层**（v0.8.2，compose + 密钥 + 486 篇素材全就绪），
> 真正的卡点不是磁盘，而是 **Docker 引擎未启动**。
> 最新状态见 → **[[🎯我现在能做到什么]]**

### A. WeKnora —— 本地微信知识库

| 项 | 说明 |
|---|---|
| **现状** | ✅ **已部署**（`AI-archive/apps/WeKnora/`），v0.8.2，配置与密钥齐 |
| **素材** | ✅ **486 篇**已导出到 `WeKnora-data/wechat-kb/` |
| **真卡点** | 🔴 **Docker 引擎未启动**（WSL 被沙箱黑名单拦，需手动双击 Docker Desktop） |
| **要多少** | 镜像 3–5GB（C 盘剩 18.5GB，**偏紧**，建议先删 31.8GB 原始导出） |
| **装完能做到** | 486 篇笔记变成可问答知识库 + 自动 Wiki |

### B. Open WebUI —— 本地版 ChatGPT 界面

| 项 | 说明 |
|---|---|
| **是什么** | 本地聊天界面，接 Ollama 用 |
| **要多少** | Docker 镜像 **几个 GB** + 常驻内存 |
| **值不值** | ⚠️ **你只有 5.3GB 可用内存，不建议** |
| **替代** | 直接用 WorkBuddy / DeepSeek 就好 |

> **建议：只做 A（WeKnora），跳过 B。**
