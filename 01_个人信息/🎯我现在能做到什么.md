### 🔥 WeKnora 微信知识库问答

**已经准备好的部分**：

| 项 | 状态 |
|---|---|
| WeKnora v0.8.2 编排文件 | ✅ 齐（compose 1054 行 + .env + config） |
| 密钥 | ✅ 已生成（JWT / AES / DB / Redis） |
| **知识库素材** | ✅ **486 篇 .md**（人物档案 450 / 情感线 6 / 事件库 2 / 方法论 8 / 资产 8 / 个人信息 11 / 主页 1） |
| Ollama 嵌入模型 | ✅ `nomic-embed-text`（RAG 向量化必需） |
| Ollama 对话模型 | ✅ `hermes3` / `gemma4-heretic-e2b`（共 7.8GB） |
| Docker Desktop | ✅ 已安装（29.6.1） |
| **Docker 引擎** | 🔴 **未启动** ← 唯一卡点 |

**卡点真因**：Docker 的 Linux 引擎依赖 WSL2，而 `wsl.exe` 在命令沙箱的程序黑名单里，脚本拉不起来。

**你要做的（约 3 分钟）**：
1. 手动双击 `C:\Program Files\Docker\Docker\Docker Desktop.exe`，等鲸鱼图标变绿
2. 告诉我一声，剩下我来：拉镜像 → `docker compose up` → 灌入 486 篇 → 建索引 → 你就能问答

**装完能做到**：
- 「我和某人的关系是怎么变化的？」→ 跨 450 篇人物档案综合回答
- 「我 2026 年的情感线梳理」→ 基于事件库推理
- 「这个决定和我之前的哪些记录冲突？」
- 自动 Wiki：把 486 篇自动组织成带链接的知识网

**代价提醒**：镜像 3–5GB，而你 C 盘只剩 **18.5GB**。装完剩 ~14GB，**偏紧**。建议先按 [[磁盘梳理与清理方案]] 删掉 `07_WeFlow原始导出_2026-07-24`（**31.8GB**）再装，会舒服很多。

## 三、做不了 / 不建议（认清边界）

| 想法 | 判断 | 原因 |
|---|---|---|
| 本地跑大模型对话 | ❌ 不建议 | RTX 3050 **4GB 显存** + 5.3GB 可用内存，只能跑 4B 以下，3–5 tokens/s |
| Open WebUI | ❌ 跳过 | Docker 镜像几 GB + 常驻内存，你内存不够 |
| 本地跑 7B/14B 模型 | ❌ 不可能 | 显存差一个量级 |
| 自建联网搜索 | ❌ 别做 | 官方 `server-brave-search` 2025-05 已归档；用 Tavily/Exa 或模型自带联网 |
